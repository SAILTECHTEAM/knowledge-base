# LangChain Framework

LangChain is a toolkit for building applications powered by large language models (LLMs).  
It handles prompts, memory, document search (RAG), and tool calling – all integrated with `uv` for fast, reproducible Python environments.

---

## Prerequisites

- Python 3.11 or higher
- `uv` installed ([instructions](https://docs.astral.sh/uv/))
- An OpenAI API key (or other LLM provider key)

---

## Core Architecture

LangChain separates execution, integration, and observability into layers.

| Layer | Domain | Responsibility | Key Components |
|-------|--------|----------------|----------------|
| Orchestration | `LangGraph` | Stateful multi‑agent workflows, loops, human‑in‑the‑loop | `StateGraph`, `MessagesState` |
| Interface Base | `langchain-core` | Execution primitives, LCEL pipe protocol | `Runnable`, `ChatPromptTemplate` |
| Integrations | `langchain-community` | Third‑party models, vector stores, loaders | `Chroma`, `ChatOpenAI`, `PyPDFLoader` |
| Observability | `LangSmith` | Tracing, cost monitoring, evaluation | Automated trace injection |

### Component Roles

| Component | Language | Purpose |
|-----------|----------|---------|
| LCEL Engine | Python / Rust | Unified streaming, batch, async |
| Model I/O | Python | Prompts, configs, token schemas |
| Data Retrieval | Python | Document loading, splitting, embedding |
| Tool Execution | Python | Function‑calling with validation |

## LCEL – LangChain Expression Language

LCEL uses the pipe operator `|` to chain components.

**Execution flow:**  
`Input → Prompt → Model → Parser → Output`

### Runnable Methods

| Method | Async | Behaviour |
|--------|-------|-----------|
| `invoke(input)` | `ainvoke` | Single call, full result |
| `stream(input)` | `astream` | Yields tokens as they arrive |
| `batch([inputs])` | `abatch` | Parallel processing |

### Basic Chain Example

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer: {question}")
])
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
parser = StrOutputParser()

chain = prompt | model | parser
answer = chain.invoke({"question": "What is RAG?"})
```

### Flow Helpers

| Helper | Purpose |
|--------|---------|
| `RunnablePassthrough()` | Pass input unchanged |
| `RunnableLambda(func)` | Wrap any Python function |
| `RunnableParallel(...)` | Execute sub‑chains concurrently |

```python
from langchain_core.runnables import RunnablePassthrough, RunnableParallel

pipeline = RunnableParallel(
    raw=RunnablePassthrough(),
    upper=lambda x: x["text"].upper()
)
```

## RAG – Retrieval-Augmented Generation

RAG allows answering from private documents. Pipeline:

`Load → Split → Embed → Store → Retrieve → Generate`

### Implementation Steps

**1. Load documents**

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader("data/doc.txt")
docs = loader.load()
```

**2. Split into chunks**

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)
```

**3. Embed and store**

```python
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = Chroma.from_documents(chunks, embeddings, persist_directory="./chroma_db")
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
```

**4. Build RAG chain**

```python
from langchain_core.runnables import RunnablePassthrough

def format_docs(docs):
    return "\n\n".join(d.page_content for d in docs)

rag_prompt = ChatPromptTemplate.from_template("""
Context: {context}
Question: {question}
Answer:
""")

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt
    | model
    | StrOutputParser()
)

answer = rag_chain.invoke("What is the loan period?")
```

### Tuning Guide

| Parameter | Recommended | Trade‑off |
|-----------|-------------|------------|
| `chunk_size` | 400–800 tokens | Larger = more context but more noise |
| `chunk_overlap` | 10–20% of size | Prevents broken sentences |
| `k` | 3–5 | More chunks = more variety, risk of distraction |

## Memory & State Management

Memory keeps conversation history across turns.

**Example with buffer memory:**

```python
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

# Store sessions in a dict
store = {}

def get_session_history(session_id):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

# Prompt must include "{history}"
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are an assistant. History: {history}"),
    ("human", "{input}")
])

chain = prompt | model | parser
chain_with_memory = RunnableWithMessageHistory(
    chain, get_session_history,
    input_messages_key="input",
    history_messages_key="history"
)

response = chain_with_memory.invoke(
    {"input": "My name is Alice"},
    config={"configurable": {"session_id": "user123"}}
)
```

## Tools & Agents

Tools let the LLM call external functions. Agents decide when and how to call them.

### Define a Tool

```python
from langchain_core.tools import tool

@tool
def search_catalog(title: str) -> str:
    """Search for a book by title."""
    return f"{title} found on shelf A12."
```

### Create an Agent

```python
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(
    model=model,
    tools=[search_catalog],
    state_modifier="You are a library assistant. Use the search tool when needed."
)

result = agent.invoke({"messages": [("user", "Where is Dune?")]})
print(result["messages"][-1].content)
```

**Agent cycle:** Reason → Act → Observe → Answer (repeat if needed).

## LangGraph – Complex Workflows

LangGraph handles loops, conditional branching, and multi‑agent coordination.

### Simple State Graph

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict

class State(TypedDict):
    question: str
    answer: str

def route(state):
    if "book" in state["question"].lower():
        return {"answer": "I can help with books."}
    return {"answer": "I only answer book questions."}

graph = StateGraph(State)
graph.add_node("router", route)
graph.set_entry_point("router")
graph.add_edge("router", END)
app = graph.compile()
```

### Supervisor‑Workers (Multi‑Agent)

```python
from langgraph_supervisor import create_supervisor
from langgraph.prebuilt import create_react_agent

book_agent = create_react_agent(model, [search_catalog], name="book_helper")
hours_agent = create_react_agent(model, [], name="hours_helper")

supervisor = create_supervisor(
    agents=[book_agent, hours_agent],
    model=model,
    prompt="Route book questions to book_helper, hours to hours_helper."
)
```

## LangSmith – Tracing & Debugging

LangSmith records every execution step – essential for debugging.

### Setup

```python
import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "lsv2_..."
os.environ["LANGCHAIN_PROJECT"] = "my_project"
```

After this, every `.invoke()` is automatically traced. View traces in the [LangSmith dashboard](https://smith.langchain.com).

## Best Practices & Pitfalls

### Safety Rules

1. **Use `temperature=0`** for tool calling and routing.
2. **Set recursion limits** to prevent infinite loops: `recursion_limit=10`.
3. **Never use f‑strings** to build prompts from user input (risk of injection).
4. **Always bound `k` in retrievers**: `search_kwargs={"k": 3}`.

### Common Issues

| Problem | Cause | Fix |
|---------|-------|-----|
| `invoke` returns `AIMessage` | Missing output parser | Add `\| StrOutputParser()` |
| Memory not working | No `{history}` in prompt | Include `{history}` placeholder |
| Agent loops forever | No iteration limit | Set `recursion_limit` |
| High token usage | `chunk_size` too large | Reduce to 400–600 |

### Production Quality Gates

```python
# Safe model settings
llm = ChatOpenAI(model="gpt-4o", temperature=0, max_retries=2, timeout=15)

# Controlled batch concurrency
chain.batch(inputs, config={"max_concurrency": 5})
```
