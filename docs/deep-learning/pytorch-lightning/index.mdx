# PyTorch Lightning Tutorial

PyTorch Lightning is a lightweight PyTorch wrapper that abstracts away engineering boilerplate while keeping full control over research logic. It standardizes the training loop, enables distributed training with a single configuration change, and integrates seamlessly with modern MLOps tools.

This section covers the Lightning philosophy, mental model, and core components. By the end, you will understand how Lightning organizes your PyTorch code and be ready to build, train, and scale models with minimal boilerplate.

## Prerequisites

This tutorial assumes familiarity with native PyTorch:

- Tensors, devices, and autograd
- `torch.nn.Module` and model construction
- `Dataset`, `DataLoader`, and data pipelines
- Optimizers, learning rate schedulers, and loss functions
- Basic training loop implementation

If you need to refresh these fundamentals, start with the [PyTorch Tutorial](../pytorch-tutorial/) first.
