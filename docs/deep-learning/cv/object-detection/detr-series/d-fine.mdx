# D-FINE: Bounding Box Distribution Refinement and Localization Self-Distillation

Across the previous seven installments, end-to-end detectors made continuous breakthroughs in feature reading, query representation, and supervision density: [Deformable DETR](./deformable-detr) restructured feature interaction through local sparse sampling, dissolving the quadratic cost of global attention over multi-scale features; [Conditional and DAB-DETR](./conditional-dab-detr) equipped queries with explicit four-dimensional geometric anchors, overcoming the localization cold-start bottleneck; [DN-DETR](./dn-detr) and [DINO](./dino) eliminated the oscillation of bipartite discrete matching in early training; and [Group DETR](./group-detr) systematically relieved the sparsity of positive-sample supervision while preserving one-to-one outputs at inference.

Along this line of improvement, detection accuracy and convergence speed on COCO improved substantially. Yet when focusing on the underlying representation of **bounding box regression**, a common assumption shared by all DETR models comes into view: **the prediction box output at every decoder layer is always a deterministic point estimate**.

This article focuses on **D-FINE (Peng et al., ICLR 2025 Spotlight)**. The authors point out that a point estimate implicitly assumes object boundaries follow a Dirac $\delta$ distribution, an assumption that erases the localization uncertainty pervading real-world object edges. D-FINE proposes **Fine-grained Distribution Refinement (FDR)** and **Global Optimal Localization Self-Distillation (GO-LSD)**, reshaping multi-layer decoder regression into residual iterative refinement over probability distributions, and substantially raising the ceiling of high-precision localization without adding any inference latency.

## Problem Definition: The Dirac Assumption of Scalar Regression and the High-Precision Localization Bottleneck

Before dissecting D-FINE's core design, systematically review how the bounding box prediction line evolved from the original DETR to DINO.

### Evolution: Sampling and Geometry Improvements Across Detection Heads, and the Retention of Scalar Regression

Previous work saw four key evolutions of the geometric prediction mechanism:

1. **Original DETR (Part 1):** the query vectors of the last decoder layer pass through a shared 3-layer MLP and a Sigmoid function to directly predict the absolute values of normalized coordinates $(x, y, w, h)$. Shallow decoder layers have no explicit spatial geometric reference, and regression at each layer is performed in isolation.
2. **Deformable DETR (Part 3):** the decoder introduces a per-layer iterative bounding box refinement mechanism. The box center predicted by the previous decoder layer directly serves as the reference point $(x, y)$ for attention feature sampling in the next layer, turning geometric prediction into a layer-wise cumulative residual process for the first time.
3. **DAB-DETR (Part 4):** query vectors are explicitly reconstructed as four-dimensional dynamic anchors $(x, y, w, h)$. For numerical stability, the model fine-tunes anchor coordinates with residuals in inverse Sigmoid space, and each layer's predicted geometric offsets directly update the anchor's scale and center.
4. **DINO (Part 6):** the Look Forward Twice mechanism attaches the later layer's predicted box directly to the previous layer's non-detached geometric box, opening the cross-layer geometric gradient path on the box regression branch that was previously cut off by `detach()`.

Each of these four works changed one key interface: some changed the sampling positions of attention, some changed the spatial semantics of queries, some changed the cross-layer gradient path. But **the physical quantity ultimately output by each layer's regression head remained four discrete real numbers**.

### Representation Defect: The Dirac Assumption Ignores Boundary Ambiguity, Saturating Strict-Threshold Localization

In continuous coordinate regression, representing the four box components as continuous scalars is, from a probability-theoretic perspective, equivalent to assuming the target's boundary positions follow a Dirac $\delta$ distribution:

$$
P(x) = \delta(x - x^*)
$$

This distribution means the system assumes a real object's boundary is an absolutely precise physical line with zero ambiguity.

In real-world images, however, this assumption is often severely disconnected from reality. As shown below, the following situations are widespread:

- **Blurry boundaries and low contrast:** for example, reflections in water, distant views shrouded in haze, or foreground and background of nearly identical color;
- **Heavy occlusion and truncation:** part of an object is occluded by other foreground, so the true boundary must be inferred from semantic priors, and the inferred boundary carries a multimodal distribution;
- **Subjective annotation ambiguity:** for example, whether a surfboard's tip includes the spray, or where a skier's pole tip ends — different annotators inherently deviate by several pixels.

![D-FINE FDR framework: refining bounding box distributions across decoder layers](/img/cv_img/detr-series/dfine_fdr_framework.png)

When the network supervises these point estimates with the standard $\ell_1$ loss or GIoU loss, the loss only computes the distance between predicted and ground-truth scalars. When the predicted box differs from the ground-truth box by only one or two pixels, the gradient is very gentle and applied symmetrically in all directions. The network cannot tell "whether this boundary is currently highly certain or a highly ambiguous guess", nor assign a wider probability tolerance to edges with multimodal ambiguity.

This representation defect directly causes a long-standing performance bottleneck: **existing DETR models improve rapidly at lenient IoU thresholds (such as $\text{AP}_{50}$), but tend to saturate at strict IoU thresholds (such as $\text{AP}_{75}$ and higher localization precision)**.

To solve this, the output head's representation must change — that is, the mathematical definition of the output residual must change. In traditional methods, the layer-$l$ regression head outputs coordinate residuals $(\Delta x, \Delta y, \Delta w, \Delta h)$; in D-FINE, the regression head outputs **residuals of the unnormalized log probabilities (logits) over the offsets of the four edge distances**.

## Mechanism One (FDR): Residual Modeling with Edge-Distance Distributions Replacing Point Estimates

To describe positional uncertainty with probability distributions, the traditional center-size representation $(x, y, W, H)$ must first be converted into edge-distance representation, and continuous physical space discretized into a set of candidate bins.

### Geometric Decoupling: From Center-Size to Four-Way Edge Distances

Let the preliminary prediction box obtained by the layer-$l$ decoder from the current reference box be $\mathbf{b}^0 = \{x, y, W, H\}$, where $(x, y)$ is the geometric center and $W$ and $H$ are the box width and height.

The authors reparameterize it into the geometric center $\mathbf{c}^0 = \{x, y\}$ plus an initial reference distance vector from the center to the four edges:

$$
\mathbf{d}^0 = \{t^0, b^0, l^0, r^0\} = \left\{ \frac{H}{2}, \frac{H}{2}, \frac{W}{2}, \frac{W}{2} \right\}
$$

where $t^0, b^0, l^0, r^0$ denote the initial physical distances from the center to the top, bottom, left, and right edges respectively.

Under the traditional $(x, y, W, H)$ parameterization, center displacement and size scaling are tightly coupled; once the prediction target becomes the four edge distances radiating outward, the spatial adjustment of the top, bottom, left, and right edges is geometrically decoupled, and the model can model and optimize the positional uncertainty of each edge independently.

### Relative Offset Binning: Reference-Edge-Based Relative Ratios and Expectation Decoding

In traditional coordinate regression, the regression head outputs a continuous scalar $\Delta d$ to correct a distance. In distribution modeling, the authors instead introduce a set of discrete sampling points (bins) to represent the shape of edge uncertainty.

A common conceptual confusion must first be resolved: **what exactly is being discretized into bins?**

In single-stage detectors (such as Generalized Focal Loss, GFL), the network has no reference box to rely on and must let every point on the feature map directly predict its distances to the four edges. So that regression can be supervised by a classification-style loss, DFL converts these distances into units of the layer's feature stride (output stride) and lays out an equidistant grid over the interval $0$ to $\mathrm{reg\_max}$; with $\mathrm{reg\_max} = 16$, the grid points land on the $17$ integer ticks $0, 1, \dots, 16$, adjacent ticks differ by one feature stride, and a single grid point can express distances up to $16$ strides. A DETR's cascaded decoder already holds a reasonably good reference edge $d^0$ at every layer; copying this stride-based absolute distance grid would place the vast majority of grid points in ranges far from the true edge that are never used.

Therefore, in D-FINE, **binning discretizes not the absolute physical distance $d$, but the relative offset ratio (dimensionless rate of change) with respect to the reference edge**.

The authors define, for each edge, a candidate index set of $N$ discrete sampling points (the paper defaults to $N = 32$):

$$
\mathcal{B} = \{0, 1, 2, \dots, N\}
$$

Each discrete point $n$ corresponds to a preset relative-offset-ratio tick value $W(n)$. This scale is a fixed structural hyperparameter: $W(n)$ increases monotonically with index $n$ from $0$ to $N$, takes zero at the midpoint of the index range, and takes negative and positive values at the two ends. Depending on which side of the midpoint $n$ falls on, the three intervals carry the following physical meanings:

- **Left half ($n < N/2$, $W(n) < 0$):** the edge should shrink inward, predicting a distance shorter than the base distance $d^0$;
- **Midpoint ($n = N/2$, $W(n) = 0$):** the current edge needs no adjustment, keeping the base distance $d = d^0$;
- **Right half ($n > N/2$, $W(n) > 0$):** the edge should expand outward, predicting a distance longer than the base distance $d^0$.

The paper takes $N = 32$, which is even, so the midpoint lands exactly on the integer index $n = 16$ and no unrepresentable midpoint exists.

Under this definition, computing the full physical edge distance during forward inference takes three steps:

1. **Predict the discrete probability distribution:** the decoder's linear prediction head outputs, for a given edge, unnormalized log probabilities (logits) of length $N+1$, normalized by a Softmax operator into a discrete probability vector:
   $$
   \mathbf{Pr}^l = \{ \Pr^l(0), \Pr^l(1), \dots, \Pr^l(N) \}, \quad \sum_{n=0}^N \Pr^l(n) = 1
   $$
2. **Expectation decoding computes the relative offset ratio:** the model computes a continuous estimate $\Delta \hat{d}^l$ of the relative offset ratio by taking the mathematical expectation over this discrete probability distribution:
   $$
   \Delta \hat{d}^l = \sum_{n=0}^N W(n) \Pr^l(n)
   $$
3. **Size scaling and restoration of physical edges:** introduce the reference box's base size $S$ (vertical edges $t, b$ take the scale factor $S = H$; horizontal edges $l, r$ take $S = W$), convert the dimensionless relative offset ratio into pixel-level physical displacement, and add it back to the initial edge distance:
   $$
   \hat{t}^l = t^0 + H \cdot \Delta \hat{t}^l, \quad \hat{b}^l = b^0 + H \cdot \Delta \hat{b}^l, \quad \hat{l}^l = l^0 + W \cdot \Delta \hat{l}^l, \quad \hat{r}^l = r^0 + W \cdot \Delta \hat{r}^l
   $$

Finally, the four continuous physical distances convert losslessly back into a standard center-size prediction box:

$$
\hat{x}^l = c_x^0 + \frac{\hat{r}^l - \hat{l}^l}{2}, \quad \hat{y}^l = c_y^0 + \frac{\hat{b}^l - \hat{t}^l}{2}, \quad \hat{W}^l = \hat{l}^l + \hat{r}^l, \quad \hat{H}^l = \hat{t}^l + \hat{b}^l
$$

Expectation decoding is mathematically a deterministic linear weighted sum, fully continuous and differentiable throughout. Gradients penetrate unimpeded from the geometric distance $d$ back to the probability distribution $\mathbf{Pr}^l(n)$, and further directly update the weights of the linear layer producing the logits in the prediction head.

:::note[Mechanism Clarification: The Three-Layer Relationship Between Four-Edge Distributions, the Reference Center, and Corner Coordinates]
In practice, many readers confuse D-FINE's output form, mistaking $\{t, b, l, r\}$ for corner coordinates, or wonder "where did the box center go — is an extra center branch needed?" Understanding this mechanism requires clarifying three layers of geometric logic:

1. **The center coordinates serve as the baseline throughout and are never regressed separately:** in the initial reference box $\mathbf{b}^0 = \{x, y, W, H\}$ fed into the first decoder layer, the center point $\mathbf{c}^0 = \{x, y\}$ is already given directly by high-quality candidates or priors selected by the encoder. The tensor output by each subsequent FDR head has shape $4 \times (N+1)$ of unnormalized logits, expressing only whether each of the four edges should shrink inward or expand outward relative to the base distance; it never outputs coordinates directly. The new center $(\hat{x}^l, \hat{y}^l)$ is passively composed purely from the asymmetric difference of opposite edge offsets ($\frac{\hat{r}^l - \hat{l}^l}{2}$ and $\frac{\hat{b}^l - \hat{t}^l}{2}$).
2. **Conversion between edge distances and corner coordinates:** the physical distance vector $\mathbf{d} = \{t, b, l, r\}$ is a relative scale radiating outward; its geometric correspondence with absolute corner coordinates $(x_1, y_1, x_2, y_2)$ is:
   $$x_1 = c_x - l, \quad x_2 = c_x + r, \quad y_1 = c_y - t, \quad y_2 = c_y + b$$
   The center point always naturally satisfies $c_x = \frac{x_1 + x_2}{2}, c_y = \frac{y_1 + y_2}{2}$.
3. **No independent center branch:** D-FINE strictly inherits the DETR family's prior mechanism based on object queries and spatial reference points. Unlike dense detectors such as FCOS or CenterNet, it requires no independent center heatmap or center-ness quality head. The center coordinates are an intrinsic part of the box's native representation.
:::

### Non-Uniform Grid: Curvature Weighting with High Center Resolution and Wide-Range Ends

With bins established as relative offset ratios, the next core question is: **how should the tick values $W(n)$ be arranged?**

The most intuitive scheme is a uniform equidistant arrangement like a histogram (uniform bins), for example spacing $W(n)$ evenly over $[-a, a]$. But this design poorly fits the working conditions of a DETR's cascaded decoder:

1. The initial reference box $\mathbf{b}^0$ output by earlier layers has already roughly circumscribed the object's region;
2. The main task of subsequent decoder layers is sub-pixel fine-tuning within a tiny neighborhood of the existing reference box; only the few outliers caused by false detections or heavy occlusion need large-range edge corrections;
3. With uniform binning, under the limited budget of $N = 32$ bins, the tick spacing near the reference edge ($W=0$) is too coarse to provide the high resolution needed for fine localization.

To balance "high-density fine-tuning of the edge's core region" with "long-range correction capability for large-deviation samples", the authors designed the following **non-uniform weighting function $W(n)$**:

$$
W(n) = \begin{cases}
-2a, & n = 0 \\
c - c \left( \frac{a}{c} + 1 \right)^{\frac{N - 2n}{N - 2}}, & 1 \le n < \frac{N}{2} \\
-c + c \left( \frac{a}{c} + 1 \right)^{\frac{-N + 2n}{N - 2}}, & \frac{N}{2} \le n \le N - 1 \\
2a, & n = N
\end{cases}
$$

where $a$ and $c$ are fixed hyperparameters controlling, respectively, the maximum offset-ratio range and the curvature of the function. In D-FINE's standard configuration, the authors set $a = 0.5$ and $c = 0.25$.

The function's geometric behavior has three notable characteristics:

- **Flat center, high near-end resolution:** when the index $n$ is near the midpoint $N/2$, the slope of $W(n)$ is tiny and the curve is very flat. The physical offset difference between adjacent bins near the center is extremely small, so the model achieves sub-pixel precision simply by shifting the center of mass of the probability distribution;
- **Steep ends, large far-end steps:** as the index $n$ approaches the two ends ($n \to 0$ or $n \to N$), the exponential term rapidly increases the curvature and the curve becomes very steep. The physical span between adjacent bins widens significantly, giving the network the large-range corrective ability to pull a mispredicted edge back into the correct region;
- **Extreme-value truncation extension:** at the endpoints $n=0$ and $n=N$, the tick values jump to $-2a$ and $2a$ respectively, providing ample search boundaries for extreme edge cases.

By introducing this non-uniform curvature, D-FINE concentrates the vast majority of probability resolution on the core fine-tuning interval where true object edges most likely appear, while keeping the low computational cost of $N=32$.

### Cross-Layer Transfer: Accumulating Residuals in Logit Space

Once the single-layer probability representation is fixed, the way probability distributions pass between the cascaded decoder layers is also fundamentally restructured. In a conventional DETR architecture, coordinate-value residuals ($\Delta \mathbf{b}^l$) pass between layers. In D-FINE, the quantity transferred and accumulated rises to **unnormalized log probability space (logit space)**.

Let the unnormalized logits output by layer $l-1$ be $\textit{logits}^{l-1}(n)$. After extracting the current layer's cross-attention and self-attention features, the layer-$l$ decoder predicts, through its linear regression head, the residual log probabilities $\Delta \textit{logits}^l(n)$. Layer $l$'s final logits are the sum of the previous layer's logits and the current layer's residual, followed by Softmax to obtain layer $l$'s normalized probability distribution:

$$
\mathbf{Pr}^l(n) = \text{Softmax}\left( \textit{logits}^l(n) \right) = \text{Softmax}\left( \textit{logits}^{l-1}(n) + \Delta \textit{logits}^l(n) \right)
$$

This residual connection at the logit level brings two advantages:

1. **Continuous evolution of the distribution shape:** the probability distributions output by shallow decoder layers tend to be flat with large variance (reflecting high localization uncertainty). Deeper layers need not refit the distribution from scratch; they only apply residual corrections on top of the prior logits, progressively suppressing probability peaks in wrong intervals and making the distribution sharper and more concentrated layer by layer;
2. **Avoiding the distortion of direct probability addition and renormalization:** directly linearly interpolating or weight-summing probability vectors after Softmax destroys the geometric convexity of the distribution and causes multimodality. Addition in logit space is equivalent to pointwise multiplication of unnormalized measures (a log-linear model), naturally ensuring smooth convergence of probability confidence.

## Training Supervision: A Dual Closed Loop of Micro Distribution Shape and Macro Geometric Overlap

With the forward data flow clarified, the next key question is: how do the discrete probability distributions receive supervision from continuous real-valued ground-truth boxes?

In the training flow, the roles of the geometric entities are clearly divided: the weighting function $W(n)$ is a fixed hyperparameter scale, and the physical distance $d$ is an intermediate variable computed in the forward pass; neither requires gradient updates. **What backpropagation actually trains is the weights of the linear regression heads in the decoder responsible for outputting logit residuals.**

### Label Reconstruction: Continuous Coordinate Projection and Two-Point Soft Labels over Adjacent Bins

The ground-truth annotations in the dataset remain standard continuous geometric coordinates $(x^{GT}, y^{GT}, W^{GT}, H^{GT})$. When a query slot matches a ground-truth target at the current decoder layer, the model computes the corresponding ground-truth physical edge distances $\mathbf{d}^{GT} = \{t^{GT}, b^{GT}, l^{GT}, r^{GT}\}$.

For any one of these edges, the dimensionless relative-offset ground truth with respect to the initial reference edge is defined as:

$$
\phi = \frac{d^{GT} - d^0}{S}
$$

where $S$ is the corresponding base size (height $H$ or width $W$). Since $\phi$ is a continuous real number, it usually does not land exactly on a discrete tick $W(n)$ but between two adjacent discrete sampling points:

$$
W(n_\leftarrow) \le \phi \le W(n_\rightarrow), \quad \text{where } n_\rightarrow = n_\leftarrow + 1
$$

Inspired by the Distribution Focal Loss (DFL), the authors decompose the continuous real number $\phi$ into a convex combination of two adjacent bins:

$$
\phi \approx \omega_\leftarrow W(n_\leftarrow) + \omega_\rightarrow W(n_\rightarrow)
$$

By linear interpolation, the interpolation weights of the two discrete points are determined directly by the geometric distances between the continuous value and the opposite sampling points:

$$
\omega_\leftarrow = \frac{| \phi - W(n_\rightarrow) |}{| W(n_\leftarrow) - W(n_\rightarrow) |}, \quad \omega_\rightarrow = \frac{| \phi - W(n_\leftarrow) |}{| W(n_\leftarrow) - W(n_\rightarrow) |}
$$

At this point, $\omega_\leftarrow + \omega_\rightarrow = 1$. This produces, on the discrete grid of length $N+1$, a **two-point soft label** with non-zero weights only at $n_\leftarrow$ and $n_\rightarrow$.

### Distribution Constraint: The IoU-Modulated Fine-Grained Localization Loss (FGL)

With the two-point soft labels in place, the network's predicted discrete probability vector $\mathbf{Pr}^l(n)$ on each edge can be explicitly constrained through weighted cross-entropy (CE).

To further sharpen the localization focus on high-confidence samples, the authors propose the **Fine-Grained Localization Loss (FGL)** over the multi-layer, multi-candidate targets:

$$
\mathcal{L}_{\text{FGL}} = \sum_{l=1}^L \left( \sum_{k=1}^K \text{IoU}_k \cdot \left( \omega_\leftarrow \cdot \mathbf{CE}\left( \mathbf{Pr}^l(n)_k, n_\leftarrow \right) + \omega_\rightarrow \cdot \mathbf{CE}\left( \mathbf{Pr}^l(n)_k, n_\rightarrow \right) \right) \right)
$$

Here $\text{IoU}_k$ is the IoU between the current predicted box and the ground-truth box. By introducing $\text{IoU}_k$ as a dynamic modulation coefficient, the FGL loss suppresses the interference of poorly overlapping outlier candidates on the distribution gradients, and strongly drives high-quality candidates with high overlap to rapidly converge and sharpen their probability mass toward the narrow interval on both sides of the true edge.

### Macro Closed Loop: Continuous Differentiability Through Expectation Decoding and Joint GIoU Supervision

During training, D-FINE builds a dual supervision closed loop of micro distribution and macro geometry:

1. **Explicit distribution shape supervision (FGL loss):** acts directly on the post-Softmax distribution vector $\mathbf{Pr}^l(n)$, forcing probability mass to gather on the two discrete bins adjacent to the true edge, directly constraining the predicted uncertainty shape;
2. **Macro geometric overlap supervision (GIoU loss):** the continuous physical box $(\hat{x}^l, \hat{y}^l, \hat{W}^l, \hat{H}^l)$ restored from the predicted distribution $\mathbf{Pr}^l(n)$ via expectation decoding computes the standard GIoU loss $\mathcal{L}_{\text{GIoU}}$ against the ground-truth box.

Because expectation decoding is mathematically a fully continuous, differentiable linear projection, the gradients backpropagated from the GIoU loss flow losslessly through the expectation decoding formula into the probability distribution $\mathbf{Pr}^l(n)$. The GIoU loss provides global-scale overlap awareness, while the FGL loss provides independent gradient guidance for each edge at the micro level; working together, they fundamentally overcome the gradient scarcity of single point-estimate regression under tiny perturbations.

## Mechanism Two (GO-LSD): Self-Distillation from Top-Layer Distributions to Shallow Decoders

In a cascaded decoder, the layers closer to the top (such as layer 6) undergo more rounds of self-attention feature interaction and FDR residual refinement. Visualizations show that the probability distributions predicted by top layers are significantly sharp, with clear peaks tightly fitting the ground-truth edges, while the distributions of the first decoder layers (such as layers 1 and 2) remain relatively flat and dispersed.

This raises a natural idea: **can the high-quality distribution obtained by the top layer through multiple refinement rounds be used as "soft labels" that flow back to supervise the shallow decoders?**

This is D-FINE's second core component: **Global Optimal Localization Self-Distillation (GO-LSD)**.

![GO-LSD: top-layer distributions distilled back to shallow decoder layers](/img/cv_img/detr-series/dfine_go_lsd.png)

### The Matching Obstacle: Cross-Layer Slot Misalignment Under Auxiliary Supervision

In knowledge distillation for traditional classification or dense detectors, the output spaces of teacher and student are usually fixed and aligned (for example, the same pixel or a preset anchor). In the DETR framework, however, self-distillation faces a serious structural obstacle: **the cross-layer dynamic misalignment of bipartite matching**.

As analyzed repeatedly in Parts 2 and 6, DETR runs Hungarian bipartite matching independently at every decoder layer for auxiliary deep supervision. This means:

- The query slot index that matches target $k$ at layer 1 is $\sigma^1(k)$;
- The query slot index that matches target $k$ at layer 6 may be $\sigma^6(k)$;
- The two indices are often unequal ($\sigma^1(k) \ne \sigma^6(k)$).

Distilling directly by slot index (forcefully making query $i$ at layer 1 imitate query $i$ at layer 6) would mislead shallow queries with completely wrong supervision signals. This is the core reason why many earlier attempts at feature imitation or logit distillation on DETR failed or even collapsed performance.

### Cross-Layer Alignment: The Global Optimal Union Set and the Decoupled Distillation Focal Loss (DDF)

To solve the cross-layer matching misalignment, GO-LSD proposes the **Global Optimal Union Set** mechanism:

During training, the system first independently runs Hungarian matching for all $L$ decoder layers and aggregates the query indices judged positive in any layer. For each ground-truth target, it collects the candidate slots hit at each layer, forming a global high-quality matching set.

With the correspondence of targets unified, the probability distribution $\mathbf{Pr}^L(n)$ predicted by the top decoder layer (layer $L$) serves as the teacher signal, guiding the corresponding distributions of the first $L-1$ layers through the Kullback-Leibler divergence:

$$
\mathbf{KL}\left( \mathbf{Pr}^l(n) \parallel \mathbf{Pr}^L(n) \right) = \sum_{n=0}^N \Pr^L(n) \log \left( \frac{\Pr^L(n)}{\Pr^l(n)} \right)
$$

Furthermore, the authors note a key phenomenon: because classification still performs strictly one-to-one exclusive matching, some candidate slots in the global union set have **extremely precise box localization** (high IoU with the ground truth) yet possibly low classification confidence. Distilling all of them indiscriminately makes classification and localization gradients work against each other.

The authors therefore propose the **Decoupled Distillation Focal Loss (DDF)**:

$$
\mathcal{L}_{\text{DDF}} = T^2 \sum_{l=1}^{L-1} \left( \sum_{k=1}^{K_m} \alpha_k \cdot \mathbf{KL}\left( \mathbf{Pr}^l_k, \mathbf{Pr}^L_k \right) + \sum_{k=1}^{K_u} \beta_k \cdot \mathbf{KL}\left( \mathbf{Pr}^l_k, \mathbf{Pr}^L_k \right) \right)
$$

where $T$ is the temperature coefficient smoothing the probability distributions (a hyperparameter; experiments show $T=5$ is best). The authors split candidates into the layer's matched set ($K_m$) and the unmatched candidate set ($K_u$), and design the weight factors $\alpha_k$ and $\beta_k$ in a decoupled way:

$$
\alpha_k = \text{IoU}_k \cdot \frac{\sqrt{K_m}}{\sqrt{K_m} + \sqrt{K_u}}, \quad \beta_k = \text{Conf}_k \cdot \frac{\sqrt{K_u}}{\sqrt{K_m} + \sqrt{K_u}}
$$

- For queries that already claimed a ground truth via Hungarian matching at this layer, the weight is modulated directly by their geometric quality $\text{IoU}_k$, encouraging shallow layers to quickly learn the deep layer's fine edges;
- For queries unmatched at this layer but belonging to the global candidates, the weight is modulated by their classification confidence $\text{Conf}_k$, avoiding injecting meaningless localization priors into pure background slots;
- The factor $\frac{\sqrt{K}}{\sqrt{K_m} + \sqrt{K_u}}$ dynamically balances the total gradient contribution of the two candidate classes in terms of magnitude.

Through GO-LSD, shallow decoders receive fine-grained geometric feedback from deep layers early in training and complete coarse localization sooner, while deep decoders are freed from heavy coarse-adjustment tasks and concentrate on refining sub-pixel residuals within extremely narrow intervals — a bidirectionally reinforcing optimization loop.

## Architectural Analysis: Four Essential Differences Between FDR and Single-Stage Distribution Focal Loss (GFL/DFL)

Because D-FINE uses formulas similar to projecting continuous edges onto discrete bins, many readers jump to the conclusion: *isn't this just moving YOLOv8 or Generalized Focal Loss (GFL/DFL) into DETR?*

That reading sees only the surface-level borrowing of mathematical tools and ignores the fundamental differences in architectural topology, optimization objective, and data flow.

| Comparison dimension | Traditional single-stage detectors (GFL / YOLOv8) | D-FINE (FDR) |
| :--- | :--- | :--- |
| **Base skeleton** | Dense anchors / convolutional feature maps (Anchor-based / Anchor-free CNN) | End-to-end Transformer cascaded decoder (object queries) |
| **Regression paradigm** | **One-shot direct prediction** | **Iterative residual refinement layer by layer** |
| **Distribution prediction target** | **Global absolute distances** from a center point to the four edges | **Relative offset logit residuals** with respect to the previous layer's reference box |
| **Bin spacing strategy** | **Static uniform equidistant bins** | **Non-uniform curvature bins ($W(n)$: flat center, steep ends)** |
| **Supervision and knowledge flow** | Static ground-truth supervision only, each pixel optimized independently | **Explicit FGL supervision + cross-layer dynamic GO-LSD self-distillation** |
| **Deduplication** | Strongly depends on post-hoc NMS to remove redundant distributions | **End-to-end set output, naturally NMS-free** |

:::note[Core Insight: One-Shot Estimation vs. Cascaded Refinement]
In GFL, every feature-map pixel must guess the target's edge position in one shot over a uniform discrete interval from 0 to 16 (or higher). Because the distance span is huge, the bin granularity is necessarily limited.

In D-FINE, decoder layer 1 already produces a rough edge. Layers 2 through 6 do not re-guess the object's absolute size; they **update the residual logits of the probability distribution within a tiny local neighborhood**. Combined with the non-uniform weighting function $W(n)$, D-FINE pours the vast majority of probability resolution into the millimeter-level neighborhood of the true edge — a multi-layer progressive contraction that no single-stage CNN can achieve.
:::

## Deployment and Validation: Low-Latency Operator Conversion and Strict-Localization Gains

As a detector aimed at real-time deployment, D-FINE faces another hard constraint: **inference latency and compute budget**. A mechanism that excels in theory loses industrial value if deployment introduces complex custom operators or heavy memory overhead.

### Deployment Optimization: Expectation Decoding as Low-Overhead Softmax Plus GEMM

Will the discrete distribution prediction introduced by FDR become a latency bottleneck at inference?

Examine the expectation decoding operation from the computation-graph perspective:

$$
\Delta \hat{d} = \sum_{n=0}^N W(n) \cdot \text{Softmax}(\textit{logits}(n))
$$

When the model is exported to ONNX or a TensorRT engine:

1. The weight vector $\mathbf{W} = [W(0), W(1), \dots, W(N)]^T$ is a completely fixed constant tensor;
2. The entire expectation computation is effectively a standard Softmax operator followed by a **bias-free $1 \times (N+1)$ convolution or matrix multiplication (GEMM)**;
3. For mainstream inference engines (TensorRT, OpenVINO, ONNXRuntime), both Softmax and GEMM are highly optimized mature operators with no unsupported or unfusable custom operators.

In measurements, replacing the continuous 4-dimensional scalar output with a $4 \times 33$ distribution prediction added only a few thousand parameters per detection head, and the measured end-to-end inference overhead on an NVIDIA T4 GPU increased by less than 0.05 ms — entirely negligible.

Moreover, at the tensor interface of whole-network inference, after D-FINE refines through all decoder layers and completes expectation decoding, the native predicted-box tensor output is still the normalized center-size format $(c_x, c_y, w, h)$ common to the DETR family, whose first two components directly correspond to the box center. In actual deployment (exporting ONNX, TensorRT engines, or calling downstream SDKs), the absolute corner boxes $(x_1, y_1, x_2, y_2)$ usually seen externally are merely the product of a coordinate conversion (`cxcywh -> xyxy`) performed in post-processing to fit conventional detection evaluation formats. When downstream business needs center coordinates, read the first two dimensions of the native output or average the corner pairs directly — no change to the model's internal computation graph is required.

### Experimental Attribution: Significant AP75 Gains and Plug-and-Play Across Architectures

To verify the pure benefit of FDR and GO-LSD, the paper ran detailed component-wise ablations in a controlled setting.

Starting from the real-time baseline RT-DETR-HGNetv2-L (53.0 AP, 9.25 ms T4 latency), the authors performed a series of restructurings. The table below summarizes the actual gains of each component along the D-FINE-L evolution path:

| Evolution step | COCO AP | #Params | Latency (T4 FP16) | Compute (GFLOPs) | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RT-DETR baseline** | 53.0 | 32M | 9.25 ms | 110 | Original benchmark |
| Remove decoder projection layer | 52.4 | 32M | 8.02 ms | 97 | Lower compute, accuracy drops |
| + Target Gating layer | 52.8 | 33M | 8.15 ms | 98 | Restore cross-layer decoupled features |
| Encoder CSP replaced with lightweight GELAN | 52.8 | 31M | 8.01 ms | 91 | Trim redundant encoder parameters |
| Scale-aware non-uniform sampling + training recipe tuning | 53.0 | 31M | 7.90 ms | 91 | Operator optimization and training alignment |
| **+ FDR (fine-grained distribution refinement)** | **53.5 (+0.5)** | 31M | 8.07 ms | 91 | Notable accuracy jump, latency nearly unchanged |
| **+ GO-LSD (self-distillation)** | **54.0 (+0.5)** | 31M | 8.07 ms | 91 | Shallow layers fully benefit, final version |

The architecture was first slimmed and latency reduced by 13% (from 9.25 ms to 8.07 ms); on that basis, FDR and GO-LSD alone pushed accuracy up by a full **1.0 AP**.

More convincing is the breakdown of the metrics:

- On **$\text{AP}_{75}$**, which represents strict localization precision, D-FINE achieved the largest gains over the baseline (more than 1.0 to 1.5 percentage points on multiple models);
- In plug-and-play generalization tests, attaching FDR and GO-LSD directly to traditional non-real-time DETR models:
  - **Deformable-DETR (12-epoch):** 43.7 AP $\to$ **47.1 AP (+3.4 AP)**;
  - **DAB-DETR (12-epoch):** 44.2 AP $\to$ **49.5 AP (+5.3 AP)**;
  - **DINO (12-epoch):** 49.0 AP $\to$ **51.6 AP (+2.6 AP)**.

This directly proves that **continuous coordinate point estimation was indeed a hidden shortcoming that had long constrained the localization precision of DETR models**. By modeling edge uncertainty with probability distributions and feeding deep-layer optimal distributions back to shallow layers, D-FINE fully activates the cascaded decoder's fine geometric localization potential without breaking the one-to-one inference architecture.

### Remaining Limitation: Positive-Sample Supervision Sparsity Persists After Per-Sample Localization Breakthrough

D-FINE successfully raised the per-sample localization representation ceiling, but it did not change how training-time supervision signals are distributed along the sample-count dimension:

1. Per image, only the few query slots successfully matched to ground-truth targets still receive effective FGL gradients and self-distillation signals;
2. Early in training, when target instances are heavily occluded or extremely small, the geometric alignment between initial queries and targets remains fragile, easily producing low-quality matches.

How to further multiply the positive-sample supervision signal at nearly zero compute cost while preserving the purity of end-to-end one-to-one output, with a loss specifically restructured for low-quality matches? This is the core question explored in the next installment, [DEIM: Dense Matching and Matching-Quality Constraints](./deim).
