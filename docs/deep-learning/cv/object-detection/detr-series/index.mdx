# Overview

Before DETR (Detection Transformer, Carion et al., 2020), modern object detection was dominated by the dense-candidate paradigm. Whether anchor-based detectors such as Faster R-CNN and RetinaNet, or anchor-free detectors such as FCOS and CenterNet, the underlying logic was nearly identical: place thousands of candidate points or boxes on the dense spatial positions of an image feature map, and let the network predict, at each candidate location, whether an object exists and its corresponding offsets.

The dense prediction paradigm carries two long-standing engineering burdens: **one-to-many label assignment** and **Non-Maximum Suppression (NMS)**. DETR's core contribution is a first-principles reformulation of detection: **treating object detection directly as a direct set prediction problem**. Instead of dense sliding-window scanning, DETR maintains a fixed-capacity set of object queries, aligns the $N$ predictions to the $M$ ground-truth objects through one-to-one bipartite matching, and removes NMS from the pipeline entirely.

The original DETR, however, exposes two severe bottlenecks that define the mainline of subsequent research: slow convergence driven by global attention and unstable bipartite matching, and the quadratic computational cost of dense attention, which restricts the model to a single low-resolution feature scale. This series follows the chain of constraints rather than the paper release history — each part examines how one problem was posed, rewritten, and pushed back by new constraints.

## Series Map

### [Part 1: DETR — Network Architecture and Forward Pass](./detr-v1-architecture-forward-pass)

Analyzes the conflict between variable-length unordered sets and fixed-shape computation graphs, and dissects the CNN backbone, two-dimensional positional encoding, Transformer encoder, and object query mechanism.

### [Part 2: DETR — Bipartite Matching and Set Loss](./detr-v1-bipartite-matching-set-loss)

Examines permutation invariance, optimal matching via the Hungarian algorithm, the construction of matching cost and set loss, and how one-to-one matching internalizes NMS.

### [Part 3: Deformable DETR — Sparse Sampling and Multi-Scale Attention](./deformable-detr)

Analyzes local sparse sampling, multi-scale deformable attention, the reference point interface, and the restructuring of the feature reading mechanism. Sparse sampling over reference points replaces global dense attention, enabling high-resolution multi-scale features and roughly a 10× faster convergence.

### [Part 4: Conditional and DAB-DETR — Spatializing the Query](./conditional-dab-detr)

Analyzes the spatial meaning of the object query and contrasts conditional spatial queries with the explicit 4D dynamic anchor box $(x, y, w, h)$ design, making the addressing target of cross-attention explicit.

### [Part 5: DN-DETR — Query Denoising and Early Matching Stabilization](./dn-detr)

Dissects the oscillation mechanism of one-to-one matching, and details target-level denoising query construction, attention mask design, and the training acceleration principle. The denoising bypass supplies deterministic gradients that bypass Hungarian matching instability.

### [Part 6: DINO — Joint Design Across Three Interfaces](./dino)

Analyzes the coordinated design of contrastive denoising, mixed query selection, and the look-forward-twice mechanism across three interfaces.

### [Part 7: Group DETR — Training-Time Query Grouping](./group-detr)

Analyzes the positive-sample sparsity caused by one-to-one matching, and explains multiple query groups, group-isolated self-attention, and independent within-group matching, plus the asymmetric training-inference implementation.

### [Part 8: D-FINE — Bounding Box Distribution Refinement and Localization Self-Distillation](./d-fine)

Replaces per-layer point estimates with discrete distributions over box boundaries, analyzing layer-wise interval shrinking, expectation-based decoding, and global-optimal localization self-distillation.

### [Part 9: DEIM — Denser Matching and Matchability-Aware Loss](./deim)

Analyzes the low-quality matches introduced by densified one-to-one matching, and breaks down dense one-to-one sample construction and the matchability-aware loss. Denser positives raise the utilization of each ground-truth object during training while preserving end-to-end inference.

### [Part 10: RT-DETR and RT-DETRv2 — Latency Budgets and Deployment Constraints](./rt-detr)

Decomposes end-to-end latency and its measurement, and covers the hybrid encoder (AIFI and CCFM), uncertainty-minimal encoder query selection, scalable decoder depth, and v2's per-scale sampling-point allocation and deployable discrete sampling. With these designs, Transformer detectors match or surpass advanced YOLO detectors in both speed and accuracy while keeping the NMS-free advantage.
