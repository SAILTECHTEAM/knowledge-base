# YOWO

**Paper title:** You Only Watch Once (YOWO): A One-Stage Network for Real-Time Spatio-Temporal Action Detection.

![YOWO pipeline overview with 2D spatial branch, 3D temporal branch, and fusion](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image1.jpeg)

**Paper link:** https://arxiv.org/pdf/1911.06644.pdf

**Authors:** Okan Kopuklu, Xiangyu Wei, Gerhard Rigoll.

## Problem Background

![Single-frame classification versus spatiotemporal action detection](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image2.jpeg)

The name YOWO (You Only Watch Once) extends the idea of YOLO (You Only Look Once) from images to video.

- YOLO: one-stage object detection on a single image.
- YOWO: one-stage action detection over a video clip.

### What Is Spatio-Temporal Action Detection

Traditional video classification takes a whole video and outputs one action label, such as running or swimming. It answers what happened but cannot say who did it or where it happened, which is insufficient for multi-person scenes.

Action detection combines two tasks:

```text
Action Detection = Localization + Classification
```

It answers where and what at the same time: which person is doing what action in the current frame.

### Why Previous Methods Were Not Ideal

Before YOWO, most methods used a two-stage pipeline similar to Faster R-CNN: generate candidate regions first, then classify and refine them.

```text
Proposal generation -> classification -> box regression
```

This design has three costs.

**Problem 1: The pipeline is complex.** Training and inference pass through proposal filtering, classification, and regression as separate steps.

**Problem 2: The parameter count is large.** The model must represent space and time together, and the extra detection stage adds further parameters.

**Problem 3: Inference is slow.** Video volumes scale with time, height, and width ($T \times H \times W$), so two-stage methods struggle to run in real time.

YOWO adopts the one-stage idea of YOLO and processes the clip in a single pass. The goal is to keep competitive accuracy while reaching real-time speed.

## Core Idea

The network completes spatial localization and action classification together in one forward pass.

### Key Difficulty

Behavior cannot be read from a single frame.

![Ambiguous single frame versus the clarifying motion in neighboring frames](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image3.jpeg)

Behavior combines appearance with motion:

```text
Behavior = spatial appearance + temporal motion
```

One still image can be ambiguous. Neighboring frames supply the continuous movement needed to disambiguate the action. Temporal modeling across frames is therefore the harder half of the task.

## Overall Architecture

![YOWO architecture: YOLO-like 2D branch, 3D ResNeXt branch, and CFAM fusion](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image4.jpeg)

YOWO keeps a 3D CNN for temporal modeling, uses a light 2D detector backbone for spatial detail, and fuses the two streams with a channel fusion and attention module (CFAM) before box regression.

- The lower 2D branch localizes people from the key frame.
- The upper 3D branch models motion and action content from the clip.
- CFAM merges the two feature types, and a final layer predicts boxes and scores.

## Spatial Modeling With a 2D CNN

The key frame is the most recent frame of the input clip. This causal choice means the 2D backbone (Darknet-19, the backbone of YOLOv2) needs no separate data loader. Its output has shape $[C'' \times H' \times W']$, where $H'$ and $W'$ match the spatial size of the 3D branch output.

During training, every frame can serve as the key frame of its own window. A window $[t-7, t]$ predicts frame $t$, the next window $[t-6, t+1]$ predicts frame $t+1$, and so on. Each prediction still concerns the last frame of its window.

:::note[Long-term feature bank breaks causality]
At inference time the paper optionally averages 3D features from neighboring clips in a long-term feature bank to strengthen classification. That variant uses future clips and is therefore no longer causal, unlike the base model.
:::

## Temporal Modeling With a 3D CNN

An ordinary 2D CNN models only $H \times W$. A 3D CNN adds the time axis and processes $T \times H \times W$, which captures motion at the cost of heavier computation.

The default 3D backbone is 3D ResNeXt-101 pretrained on Kinetics. All layers after the last convolution are removed. The input clip has shape $[3 \times D \times H \times W]$, where $D$ is the frame count and the leading 3 is the RGB channel count. The last convolution outputs $[C' \times 1 \times H' \times W']$, where $C'$ is the output channel count (for example 2048), the depth is reduced to 1, and $H' = H/32$ and $W' = W/32$. The volume is then squeezed to $[C' \times H' \times W']$ so it aligns spatially with the 2D branch.

## Attention Module (CFAM)

![Channel fusion of 2D and 3D features before attention](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image5.jpeg)

Features from 2D and 3D networks come from different distributions, so plain addition is unreliable. YOWO concatenates them along channels, mixes them with $1 \times 1$ and $3 \times 3$ convolutions into a fused feature $B$, and then applies attention across channels.

### Input Features

Two sources enter the module: the single key frame through the 2D branch and the multi-frame clip through the 3D branch.

:::info[Fusion rule used here]
Features from the same source are added, as in residual connections. Features from different sources are concatenated, as in this fusion step.
:::

![Channel attention computation inside CFAM](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image6.png)

First, the fused map $B$ of shape $C \times H' \times W'$ is flattened to $F \in \mathbb{R}^{C \times N}$ with $N = H'W'$. Each row is one channel, and each column is one spatial position.

Next, the channel Gram matrix is computed:

$$
G_{ij}=\sum_{k}F_{ik}F_{jk}
$$

Each entry measures how correlated channel $i$ is with channel $j$. Unlike a transformer, this step uses no separate linear projections for queries and keys. It treats each channel simultaneously as the item sought, the item held, and the content carried.

The attention weights are the row-wise softmax of $G$:

$$
M = \mathrm{softmax}(G)
$$

so each row sums to 1 and expresses how much one channel attends to all others. In code the maximum of each row is subtracted before the exponential, which is a standard numerical stabilizer and does not change the result.

The enhanced feature is then:

$$
F' = MF
$$

which has shape $C \times N$ and is reshaped to $C \times H' \times W'$. A learnable scalar $\alpha$ controls a residual blend with the input:

$$
F_{out} = F + \alpha F''
$$

where $F''$ is the reshaped attention output. The module closes with a $3 \times 3$ convolution (with normalization and LeakyReLU) followed by a $1 \times 1$ linear projection. These convolutions mix the two backbone distributions at entry and exit and complete the CFAM block.

## Bounding Box Regression

Regression follows YOLO. A final $1 \times 1$ convolution produces the prediction volume. Each spatial cell predicts 5 anchors obtained by k-means on the dataset. Each anchor carries 4 box coordinates, 1 confidence score, and one score per action class. With $N_{cls}$ classes and a grid of $H' \times W'$, the output has:

$$
H' \times W' \times [5 \times (4 + 1 + N_{cls})]
$$

entries. The leading 5 counts anchors, and the inner 5 in the common shorthand $N_{cls} + 5$ counts 4 coordinates plus confidence.

## Heatmap Interpretation of Attention Points

![Heatmaps comparing 2D focus on people with 3D focus on moving regions](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/YOWOimg/image10.jpeg)

Panel (a) shows the 3D branch attending to moving regions rather than every person, for example the actor performing the action instead of bystanders. Panel (b) shows the 2D branch attending to all person-like regions in the key frame regardless of motion. The paper uses this contrast to argue that the two branches are complementary: the 2D branch supplies spatial localization while the 3D branch supplies motion, and CFAM is needed to combine them.
