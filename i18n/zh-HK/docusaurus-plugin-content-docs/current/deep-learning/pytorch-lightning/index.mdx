# PyTorch Lightning 教學

PyTorch Lightning 是一個輕量級的 PyTorch 包裝器，它抽象了繁瑣的工程樣板程式碼，同時保留了對研究邏輯的完全控制。它標準化了訓練迴圈，只需更改一行配置即可啟用分散式訓練，並與現代 MLOps 工具無縫整合。

本節涵蓋了 Lightning 的核心理念、心智模型和核心組件。學完之後，您將了解 Lightning 如何組織您的 PyTorch 程式碼，並準備好以最少的樣板程式碼構建、訓練和擴展模型。

## 預備知識

本教學假定您熟悉原生的 PyTorch：

- 張量 (Tensors)、設備 (devices) 和自動求導 (autograd)
- `torch.nn.Module` 和模型構建
- `Dataset`、`DataLoader` 和數據管道
- 優化器、學習率排程器和損失函數
- 基本的訓練迴圈實現

如果您需要複習這些基礎知識，請先從 [PyTorch 教學](../pytorch-tutorial/) 開始。
