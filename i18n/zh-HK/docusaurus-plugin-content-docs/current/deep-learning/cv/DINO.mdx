# DINO：從無標籤自蒸餾到視覺基礎模型

> **名稱說明：** 本文件介紹的是 Meta 的自監督 DINO 系列；它與名為 **DINO** 的物件偵測器（*DETR with Improved DeNoising Anchor Boxes*）無關。

## DINO v1：無標籤自蒸餾

### 自監督學習

自監督學習不需要人手標註的類別標籤，而是從資料本身建立學習訊號。在 DINO 中，同一張影像經不同資料增強後得到的視圖，會分別送入學生模型與教師模型。教師模型的機率分布會成為學生模型的軟目標。

自監督目標常被概略分為 **對比式** 與 **非對比式**；這是一個有用的高層分類方式，但並非窮盡所有方法的分類法。

#### 對比式目標

對比式目標會把同一張原始影像的兩個增強視圖視為 **正樣本對**，把來自其他原始影像的視圖視為 **負樣本對**。

例如：

- 貓 A₁ ↔ 貓 A₂：正樣本對
- 貓 B₁ ↔ 貓 B₂：正樣本對
- 狗 C₁ ↔ 狗 C₂：正樣本對
- 貓 A₁ ↔ 貓 B₁：負樣本對，即使兩者都是貓

訓練時會拉近正樣本對的表示，並推遠負樣本對的表示。負樣本對有助於防止模型崩潰，但其中可能含有 **偽負樣本**：兩張影像在語義上相近，卻仍被推遠。

#### 非對比式目標

像 DINO 的非對比式方法，不會明確地把不同影像的表示推遠。相反地，學生模型會匹配教師模型對同一張原始影像另一個視圖的輸出。

只移除明確的負樣本，**不足以** 防止模型崩潰。DINO 結合了以下機制：

- 以指數移動平均（EMA）更新的動量教師；
- 教師端的停止梯度；
- 對教師 logits 進行置中；
- 使用較低教師溫度進行銳化；
- 多裁切訓練。

論文的消融實驗顯示：置中與銳化配合動量教師使用時，是防止崩潰的關鍵機制。不能只用 EMA 與停止梯度來完整解釋其穩定性。

### 什麼是模型崩潰？

模型崩潰是指自監督模型找到了一條沒有意義的捷徑：無論輸入甚麼影像，它都輸出幾乎相同的表示或機率分布。

例如：

```text
貓影像 → [0.5, 0.5, 0.5]
狗影像 → [0.5, 0.5, 0.5]
汽車影像 → [0.5, 0.5, 0.5]
```

雖然輸入不同，它們的表示幾乎沒有可區分的資訊。因此，這些特徵無法有效用於分類、檢索或分割等下游任務。

當學習目標只要求同一張影像的兩個增強視圖輸出相似結果時，就可能出現這個問題。模型只要對所有影像都輸出同一個常數，就能完美滿足該規則：

```text
影像 A，視圖 1 → X
影像 A，視圖 2 → X  ✓

影像 B，視圖 1 → X
影像 B，視圖 2 → X  ✓
```

即使模型沒有學到任何有用資訊，訓練損失仍可能很低。因此，崩潰被稱為 **平凡解**。

對比式學習透過負樣本對來防止這個情況：不同影像的表示會被推遠，因此所有影像都輸出相同結果會受到懲罰。DINO 不使用明確的負樣本對；它透過動量教師、停止梯度、置中、銳化及多裁切訓練的共同作用來防止崩潰。

### 監督式學習與自監督學習

在監督式學習中，每個輸入都配有外部提供的目標，例如影像類別或翻譯後的句子。DINO 的預訓練不提供語義類別標籤；其目標是教師模型從同一張影像另一個視圖產生的分布。

### 動機與湧現特性

原始 DINO 工作探討：自監督預訓練能否令 Vision Transformer 學到比一般影像級監督訓練更豐富的視覺表示。

主要觀察包括：

1. 自監督 ViT 最後一層 `[CLS]` 的自注意力圖，常會對齊顯著物體及其邊界，即使訓練時沒有使用分割標註。
2. 凍結的 DINO 特徵配合簡單的加權 k 最近鄰分類器已經表現良好。ViT-S/8 在沒有微調、沒有學習式線性分類器、也沒有測試時資料增強的情況下，於 ImageNet 取得 **78.3% top-1 準確率**。

![DINO 注意力圖顯示的物體區域](/img/cv_img/DINOimg/image-1.png)

> 注意力圖可以顯示類似物體的區域，但不代表 DINO 直接完成了語義分割或為物體賦予類別名稱。仍需要下游方法把特徵或注意力轉換成指定任務的預測。

## 核心 DINO 訓練方法

### 教師—學生自蒸餾

![DINO 教師—學生架構](/img/cv_img/DINOimg/image-1.png)

兩個網路使用相同架構，但參數不同：

1. 為一張影像產生多個經資料增強的視圖。
2. 將所有視圖送入學生模型，但只將兩個全域視圖送入教師模型。
3. 以溫度縮放 softmax，將兩個網路的 logits 轉成機率分布。
4. 對教師 logits 進行置中及銳化，並停止教師輸出的梯度。
5. 最小化教師模型對某一視圖的分布，與學生模型對另一視圖的分布之間的交叉熵；不匹配完全相同的視圖。
6. 以梯度下降更新學生模型。
7. 以學生模型參數的 EMA 更新教師模型。

對教師視圖 `(x)` 與不同的學生視圖 `(x')`，損失包含：

$$
H\left(P_t(x), P_s(x')\right).
$$

教師目標是 **軟偽目標**，並不是一般有標註資料意義下的真實標籤。

### 骨幹網路與投影頭

網路可以寫成：

$$
g = h \circ f,
$$

其中 `(f)` 是骨幹網路，`(h)` 是 DINO 投影頭。對 ViT 而言，投影頭會套用在最終 `[CLS]` token 上。在常見設定中，投影頭會將骨幹表示映射到高維輸出空間，通常為 `(K=65,536)` 維，然後才進行溫度 softmax 及交叉熵計算。

這個輸出不應被理解為 65,536 個語義類別。它是一個供自蒸餾目標使用的學習式投影空間；下游任務一般使用骨幹網路的特徵，而不是投影頭的機率。

### 多裁切輸入

![DINO 多裁切輸入](/img/cv_img/DINOimg/image-2.png)

標準設定會產生：

- 兩個 `224 × 224` 全域裁切，同時送入學生與教師；
- 多個 `96 × 96` 局部裁切，只送入學生。

這會鼓勵 **局部對全域的對應關係**：學生模型必須讓局部裁切的結果，與教師模型看到的較完整全域視圖一致。

### 動量教師（EMA）

教師模型由學生模型初始化，並以下式更新：

$$
\theta_t \leftarrow m\theta_t + (1-m)\theta_s,
$$

其中動量 `(m)` 在訓練期間依 cosine schedule 從約 `0.996` 逐步趨近 `1.0`。

因此，教師模型可視為近期學生狀態的平滑集成，提供較穩定的目標；教師模型不接收梯度更新。

### 置中與銳化

教師機率計算如下：

$$
P_t(x) = \operatorname{softmax}\left(\frac{g_t(x)-c}{\tau_t}\right),
$$

其中 `(c)` 是從教師 logits 以 EMA 更新得到的中心值，`(\tau_t)` 是教師溫度。

- **置中（Centering）** 可避免少數輸出維度在整個 batch 中持續主導，但單獨使用會傾向產生均勻分布。
- **銳化（Sharpening）** 使用較低溫度來降低輸出熵，但單獨使用可能使輸出過度集中而崩潰。
- **兩者結合** 可平衡這兩種失敗模式。

![DINO 崩潰消融實驗](/img/cv_img/DINOimg/image-3.png)

熵本身並非通用的崩潰偵測器。在這個特定分析中，極高熵與均勻輸出相關，而極低熵可能代表輸出過度集中。右圖使用教師與學生輸出之間的 KL divergence；若它迅速降至零，可能表示兩個網路都收斂至相同的平凡輸出。

## DINOv2

DINOv2 將這個方法擴展為通用視覺特徵提取器。其訓練配方結合了影像級 DINO 自蒸餾、patch 級 iBOT 遮罩影像建模、KoLeo 正則化、策展資料集、訓練穩定化方法及模型蒸餾。

![DINOv2 訓練架構](/img/cv_img/DINOimg/image-4.png)

### 訓練目標

1. **DINO loss：** 對齊學生與教師在不同視圖上的 `[CLS]` 輸出。
2. **iBOT loss：** 遮罩部分學生模型的 patch token，並要求其輸出匹配教師模型對應未遮罩 patch token 的分布。它預測的是教師特徵／分布，而不是 RGB 像素。
3. **KoLeo regularization：** 透過懲罰 batch 內過小的最近鄰距離，鼓勵嵌入向量分散。相比「讓所有向量均勻分布」，它更適合被理解為特徵擴散或熵正則化。

![DINOv2 損失函數](/img/cv_img/DINOimg/image-5.png)

DINOv2 也加入四個 **register tokens**，以減少 patch token 特徵圖中的高範數偽影。

### 高解析度適應

在預訓練接近結束時，DINOv2 將輸入解析度從 `224 × 224` 提升到 `518 × 518`，而不是 `416 × 416`。這段短暫的高解析度訓練，比從一開始全程以高解析度訓練更省成本，同時能改善像素級任務。

![DINOv2 解析度比較](/img/cv_img/DINOimg/image-6.png)

### 模型擴展

- DINO v1 的實驗包括 ViT-S 與 ViT-B；ViT-B 的骨幹網路約有 **85–86M 參數**。
- DINOv2 最大的教師模型是 ViT-g/14，約有 **1.1B 參數**。
- 較小的 ViT-S/14、ViT-B/14 及 ViT-L/14 均由大型教師模型蒸餾而來。

### LVD-142M 資料策展

DINOv2 的流程從約 **1.2B 張未策展影像** 開始，最後產生約 **142M 張影像** 的 LVD-142M 策展資料集。

簡化流程如下：

1. 從多個既有資料集建立一個策展種子集，並準備未策展的網路影像池。
2. 使用預訓練的自監督 ViT-H/16，為兩個資料池計算嵌入。
3. 對未策展影像池進行去重。
4. 以策展種子集作為查詢，從未策展影像池中進行最近鄰檢索。
5. 對檢索結果進行取樣，形成在視覺分布上受策展來源引導的多樣化資料集。

![LVD-142M 資料策展流程](/img/cv_img/DINOimg/image-7.png)

這是 **以檢索為基礎的視覺資料策展**，而不是一般的監督式分類。策展種子集定義了應被涵蓋的視覺特徵空間區域。

### 蒸餾較小模型

訓練完 ViT-g/14 後，DINOv2 會把其表示蒸餾到較小的模型，讓較輕量的骨幹網路也能受益於大型教師模型較強的特徵。

![DINOv2 蒸餾結果](/img/cv_img/DINOimg/image-8.png)

## DINOv3

DINOv3 進一步擴展自監督視覺預訓練的規模，並處理長時間訓練時稠密 patch 特徵退化的問題。

### 規模

- 最大的 ViT 教師模型約有 **6.7B 參數**，通常四捨五入為 7B。
- 主要策展資料集 **LVD-1689M** 包含約 **1.689B 張影像**。
- 論文描述了來自更大原始資料池的訓練。除非來源明確支持，否則不應寫成所有原始影像均來自 Instagram。

![DINOv2 與 DINOv3 模型比較](/img/cv_img/DINOimg/image-9.png)

### 稠密特徵退化

在延長的 DINO 類訓練中，影像級表現可能持續提升，但 patch 特徵的空間一致性可能變差，從而損害分割與深度估計等稠密任務。DINOv3 引入 **Gram anchoring** 來保留 patch 特徵之間有用的關係。

![DINOv3 稠密特徵退化](/img/cv_img/DINOimg/image-10.png)

![DINOv3 patch 相似度演變](/img/cv_img/DINOimg/image-11.png)

### Gram anchoring

Gram anchoring 使用一個凍結的較早期模型作為參考。它比較目前學生模型的 patch 特徵之間的成對相似度，與參考模型中對應特徵之間的相似度。

若 `(X_S)` 與 `(X_R)` 分別是學生及參考模型的正規化 patch 特徵矩陣，則其簡化形式為：

$$
\mathcal{L}_{\text{Gram}}
=
\left\|X_SX_S^\top-X_RX_R^\top\right\|_F^2.
$$

其中 `(X_SX_S^\top)` 與 `(X_RX_R^\top)` 是 **Gram matrices**；`(X_S)` 與 `(X_R)` 本身則是特徵矩陣，不是 Gram matrix。此外，錨點是凍結的參考模型，而不是當前的 EMA 教師模型。

參考階段的目標可概括為：

$$
\mathcal{L}_{\text{Ref}}
=
w_D\mathcal{L}_{\text{DINO}}
+\mathcal{L}_{\text{iBOT}}
+w_{DK}\mathcal{L}_{\text{DKoLeo}}
+w_G\mathcal{L}_{\text{Gram}}.
$$

Gram anchoring 是在較後期的訓練階段套用，而不是在整個基礎預訓練期間持續使用。

### 高解析度 Gram anchoring

在高解析度適應中，參考模型會處理高解析度視圖；其 patch 特徵會先在空間上進行池化或下採樣，以對齊學生模型較低解析度的 token 網格，再計算 Gram loss。這提供了更強的空間參考，而不需要從一開始就以高解析度訓練整個模型。

## 版本摘要

| 版本 | 核心概念 | 重要新增項目 | 最大 ViT 約略規模 |
| --- | --- | --- | --- |
| DINO v1 | 非對比式教師—學生自蒸餾 | EMA 教師、置中、銳化、多裁切 | 主 ViT 實驗中的 ViT-B，85–86M |
| DINOv2 | 大規模通用視覺特徵 | iBOT、KoLeo、register tokens、LVD-142M、蒸餾、高解析度適應 | ViT-g/14，約 1.1B |
| DINOv3 | 擴展規模並保留稠密特徵 | LVD-1689M、約 7B ViT、Gram anchoring、高解析度 anchoring | ViT-7B，約 6.7B |
