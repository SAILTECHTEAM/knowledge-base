# 時間移位模組（TSM）

**論文：** Ji Lin, Chuang Gan, Song Han, TSM: Temporal Shift Module for Efficient Video Understanding, ICCV 2019.

**論文連結：** https://openaccess.thecvf.com/content_ICCV_2019/papers/Lin_TSM_Temporal_Shift_Module_for_Efficient_Video_Understanding_ICCV_2019_paper.pdf

**程式碼：** https://github.com/mit-han-lab/temporal-shift-module

![TSM 總覽：把一部分通道在時間上移位，再做 2D 卷積](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image1.png)

2D CNN 一次只從一幀提取空間特徵，3D CNN 同時對空間和時間建模，能抓住更豐富的時空結構。

**3D 卷積**

![在空間和時間上做的 3D 卷積](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image2.png)

**2D 卷積**

![在單幀上做的 2D 卷積](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image3.png)

3D 卷積在時間維度上增加了計算，代價和參數量隨之上升，在即時或資源受限的場景下難以部署。這裡的問題是：

> 能否在保持 2D CNN 效率的同時，加上時間建模能力？

## 解決方法

### TSM 把一部分通道在時間上移位

特徵有四個維度，其中 $C$ 是通道維度，$T$ 是時間維度。

![通道沿時間維度的移位](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image4.png)

核心操作是把一小部分通道沿時間前移或後移。移位之後，每一幀都帶有一部分相鄰幀的通道，接下來的普通 2D 卷積在混合這些通道時就混入了時間資訊，而計算本身仍然是二維的。

### 移位的作用

![離線雙向移位與在線單向移位的對比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image5.png)

以圖（b）為例，當前幀從 $t-1$ 幀和 $t+1$ 幀各取來一部分移位通道。論文在每個方向上只移動一幀。

- 圖（b）的離線移位是雙向的。整個影片已經在手，當前幀可以用過去和未來的資訊。
- 圖（c）的在線移位是單向的。未來幀還沒有出現，通道只能從過去傳到現在。這個操作只改變資料的存放位置，不增加 FLOPs，也不增加參數。

### 核心思想

先移位，再卷積。移位之後，2D 卷積負責把混在一起的通道融合起來。哪些通道在時間上更重要，留給網路自己學，因為不同層、不同任務的答案不一樣。

重的運算仍然是 2D 卷積，所以可以沿時間做批量並行。移位提供時間混合，後面的卷積完成融合。

## 移多少、在哪裡移

![不同移位比例下的延遲開銷和準確率](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image6.png)

圖（a）是資料搬運帶來的延遲開銷。移動全部通道在 CPU 上帶來約 13.7% 的額外延遲，不容忽視。只移動例如 1/8 的通道，開銷降到約 3%。所以論文只移動一部分通道。

圖（b）是準確率對比。殘差移位在各種比例下都好於原地移位。移得越多，時間推理先變好，當前幀的空間表達隨後變差，準確率先升後降。殘差移位的峰值出現在移動四分之一通道處。

:::tip[預設設置]
論文預設使用四分之一通道的殘差移位：離線雙向建模裡，1/8 前移，1/8 後移。
:::

### 模型設計：殘差 TSM 與原地 TSM

![殘差塊之前的原地移位，與殘差分支內部的移位之對比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image7.png)

原地移位把操作插在卷積層或殘差塊之前。被移走的通道把資訊帶離了當前幀，當前幀就拿不到這些通道原來攜帶的內容。移動的通道越多，主幹表達當前畫面的能力退化越嚴重。

殘差移位把操作放在殘差分支內部。恆等路徑仍然完整傳遞當前幀的激活，時間資訊是加上去的，原來的內容並沒有被拿走。即使分支裡的通道全部移位，shortcut 也保住了空間表達能力。這就是殘差移位在論文的 Kinetics 對比裡全面好於原地移位的原因。

## 離線 TSM 影片模型

![帶雙向時間交換的離線 TSM 影片模型](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image8.png)

離線推理面對的是已經錄好的完整影片，未來幀是可見的。模型把一部分通道前移、一部分後移，實現雙向的時間資訊交換。影片採樣先得到各幀，早期的普通 ResNet 卷積提取空間結構，後面的 2D 卷積融合移位後的混合特徵。移位本身沒有參數，所有的學習都發生在後面的卷積裡。

## 在線時間移位

在線推理用不到未來幀，所以移位是單向的。

![帶特徵快取的在線單向 TSM 流程](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image9.png)

![在線移位的細節：快取的過去通道替換當前幀的一部分](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image10.png)

對每一幀、每個殘差塊，模型把前 1/8 的特徵圖存入記憶體。下一幀到來時，它的前 1/8 被快取的內容替換。這樣每一層處理的是 7/8 的當前幀加上 1/8 的過去幀。這種設計有三個實際好處：

- 推理延遲低：每幀只做一次小規模的替換和快取，每幀延遲接近 2D 基線。
- 記憶體佔用小：只快取一小部分特徵（論文報道 ResNet-50 只多用約 0.9 MB）。
- 時間融合發生在每一層：同樣的操作在網路的各個階段重複，時間混合貫穿始終。

1/8 這個數字直接來自離線的結論。離線雙向移位總共移動 1/4：

```text
離線雙向 TSM：總共 1/4 = 前移 1/8 + 後移 1/8
在線單向 TSM：總共 1/8 = 只用過去幀
```
