# 目標檢測解構（5）：分類置信度與 Detection Head

按分類分數從高到低排，分數 $0.95$ 的框常常卡在前面那兩個人中間，誰都沒套住；遠處那塊牌的分數可能只有 $0.15$，初篩就被丟掉。

這反映了目標檢測預測頭長期面對的兩大矛盾：在密集的候選空間裏，純背景區域的數量遠遠壓倒真實目標，微弱的目標信號極易被海量簡單負樣本的累積梯度淹沒；而分類分支給出的高置信度分數，根本無法代表這個框在幾何定位上到底畫得有多準。

預測頭（Head）是檢測網絡中直面損失函數、直接產出預測結果的末梢。它必須在每個候選位置上回答兩個問題：這裏存在什麼類別的物體，以及物體的幾何邊界究竟在哪裏。這兩個子任務在底層的表徵需求與優化方向上處處存在排斥。

## 爲什麼分類分數不能當定位質量用

在純粹的圖像分類任務中，模型追求平移不變性。無論一隻貓出現在畫面的左上角、正中央還是右下角，分類器都希望深層特徵能夠激活“貓”這一類別的高響應。

但目標檢測不僅要識別物體的語義屬性，還要輸出具體的幾何邊界框座標 $[x, y, w, h]$。檢測頭對空間幾何位置具有天然的平移敏感性：只要目標在畫面中平移了兩個像素，或者預測框向外擴張了三個像素，網絡輸出的邊界座標偏移量就必須產生相應的數值變化。

當系統直接拿分類分支計算出的得分作爲衡量整個檢測框優劣的唯一依據時，隱患就此埋下。

回到畫面中央那兩位重疊的行人。當一個預測框恰好卡在兩人中間時，該位置對應的特徵感受野同時覆蓋了左側行人的頭部輪廓與右側行人的軀幹邊緣。對於專門尋找判別性紋理的分類分支而言，這個感受野內部包含了極其濃烈的人體視覺模式。分類卷積層並不關心這些特徵究竟屬於同一個人還是兩個人，只要確認視野內存在大量符合人體特徵的結構，就會給出接近 1.0 的極高置信度。

但在空間幾何層面，這個預測框與真實標註框之間的交併比（IoU）極其糟糕。它既沒有對準左邊的行人，也沒有包住右邊的行人，與兩者的交併比甚至都低於 0.3。

相反，在某一位行人的精確邊界周圍，可能存在另一個預測框，它的四條邊嚴密貼合了行人的身體輪廓，交併比高達 0.9。然而，生成這個框的特徵網格恰好位於行人的邊緣輪廓或者光照較暗的外衣褶皺處。這裏的局部特徵缺乏全局的典型性，導致分類分支給它打出的置信度只有 0.45。

在依賴分類分數排序的後處理中，那個交併比只有 0.3 的畸形框會憑藉 0.95 的高分排在最前；而交併比高達 0.9 的精準預測框反而會因低分排在末尾，甚至在初篩階段被直接剔除。

分類頭只對局部特徵的語義豐富度負責，不對邊界框的幾何重合度負責。要讓檢測頭正常工作，必須先解決海量背景帶來的梯度失衡，再化解分類與定位在特徵表示與優化目標上的內在衝突。

## 一千比一的背景淹沒：從 Objectness 到 Focal Loss

在一張 $640\times 640$ 的輸入圖像上，現代密集預測檢測頭通常會在不同下采樣倍率的特徵圖上鋪設預測點。假設網絡使用步長爲 8、16 和 32 的三層特徵圖：

- 步長 8 的特徵圖尺寸爲 $80\times 80$，提供 6400 個預測位置；
- 步長 16 的特徵圖尺寸爲 $40\times 40$，提供 1600 個預測位置；
- 步長 32 的特徵圖尺寸爲 $20\times 20$，提供 400 個預測位置。

三層特徵圖累加在一起，單張圖像就會生成 $6400 + 1600 + 400 = 8400$ 個候選網格。

在這 8400 個位置中，真正包含目標的網格極其稀少。街景盡頭那塊 $16\times 16$ 的小路牌在步長 8 的圖上最多隻佔 $2\times 2$ 共 4 個網格；中央的兩個行人加起來也只佔據數十個網格。整張圖像中能夠被劃歸爲正樣本的網格通常不足數十個，而剩下的 8300 多個網格全部是純粹的背景——大片的天空、平整的瀝青路面、建築物的空白牆面。

在密集預測場景中，正負樣本的比例極易達到幾十比一乃至一千比一以上。

早期的檢測器爲了應對這種懸殊差距，嘗試在類別預測之前引入一個名爲 objectness 的獨立分支。objectness 的本義是“目標存在性”，它是一個二分類標量，專門評估某個候選區域到底是一塊包含物體的區域，還是純粹的背景。在早期單階段檢測算法中，最終的類別置信度被拆成 $P(\mathrm{Class}_i) = P(\mathrm{Object}) \times P(\mathrm{Class}_i \mid \mathrm{Object})$。第一項由 objectness 分支輸出，代表該位置存在物體的先驗概率；第二項由類別分支輸出，代表在已知存在物體的前提下屬於第 $i$ 類的條件概率。

這種拆分在概念上將“有沒有”與“是什麼”分開了，但並沒有從數學底層解決梯度淹沒的問題。因爲無論是 objectness 還是多分類分支，只要損失函數沿用標準的二值交叉熵（Binary Cross-Entropy），海量背景帶來的累積效應就會壓垮訓練過程。

對於標準的二值交叉熵損失，單個樣本的損失和與標籤對齊的概率 $p_t$ 寫成：

$$
\begin{aligned}
\mathrm{CE}(p, y) &= \begin{cases} -\log(p) & \text{當 } y = 1 \\ -\log(1 - p) & \text{當 } y = 0 \end{cases} \\
p_t &= \begin{cases} p & \text{當 } y = 1 \\ 1 - p & \text{當 } y = 0 \end{cases}
\end{aligned}
$$

其中 $y \in \{0, 1\}$ 是真實標籤，$p \in [0, 1]$ 是模型預測該位置爲正樣本的概率。交叉熵因此可以簡寫爲 $\mathrm{CE}(p_t) = -\log(p_t)$。

在這一公式下審視那 8300 多個背景網格。絕大多數背景區域極易判斷，比如大片純淨的藍天，卷積網絡能夠輕易給出 $p = 0.01$ 的預測，即 $p_t = 1 - 0.01 = 0.99$。單個簡單背景的損失是 $\mathrm{CE}(0.99) = -\log(0.99) \approx 0.010$。單獨看這一個數值確實微小。然而，當 8300 個簡單負樣本同時進行反向傳播時，它們所產生的損失累加起來就會達到 $8300 \times 0.01 \approx 83$。

再看街道盡頭那塊 $16\times 16$ 的小路牌。由於路牌極小、邊緣模糊，網絡給出的正樣本預測概率可能只有 $p = 0.2$（即 $p_t = 0.2$）。這個困難正樣本產生的單個損失是 $\mathrm{CE}(0.2) = -\log(0.2) \approx 1.61$。單個難樣本的損失雖然比單個易分樣本大了上百倍，但在數千個簡單背景樣本的絕對數量優勢面前，負樣本累加產生的梯度總和依然佔據了統治地位。在反向傳播的過程中，優化器的更新方向完全被海量的簡單背景推着走，網絡參數被不斷調整去壓低那些早已分類正確的天空與路面，而真正需要模型集中精力攻克的小路牌正樣本信號，直接被淹沒在背景梯度的噪聲海洋裏。

爲了打破這種數量懸殊帶來的干擾，Focal Loss 改變了損失函數的加權機制。它在標準交叉熵的前面增加了一個基於置信度的調製項：

$$
\mathrm{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t)
$$

公式中的 $\gamma \ge 0$ 是論文給定的調製超參數（在通用實踐中通常固定取 $\gamma = 2$）。

:::tip[Focal Loss 的調製機制]
調製項通過預測概率 $p_t$ 的高低，動態抑制已經學好的樣本貢獻的梯度權重。易分樣本（如大片天空背景，$p_t = 0.99$）的調製項 $(1 - 0.99)^2 = 0.0001$，原本 0.01 的損失被削弱上萬倍，梯度幾乎不再更新；難樣本（如小路牌，$p_t = 0.2$）的調製項 $(1 - 0.2)^2 = 0.64$，損失被大部分保留。檢測頭在極端樣本失衡下仍能將更新方向集中在少數難分辨的真實目標上。
:::

## 特徵衝突：耦合頭與解耦頭

海量背景帶來的梯度失衡被壓制之後，檢測頭內部的物理結構差異成爲了影響精度的關鍵。

早期單階段檢測器普遍採用耦合頭（Coupled Head）：來自特徵金字塔的特徵圖直接送入兩到三層共享卷積層，隨後在末端引出兩個並行的 $1\times 1$ 卷積，分別輸出類別預測分數與邊界框座標偏移量。

這種結構隱含了一個底層假設：在深層表徵中，用於語義分類的特徵與用於幾何定位的特徵是高度重合且完全通用的。

然而在特徵分析中，分類與定位對特徵表徵的需求在本質上是相互排斥的：

1. **分類任務要求語義抽象與平移不變性**。分類分支希望卷積核忽略空間上的微小擾動，專注於提取人臉、肩膀、軀幹等高階語義。即便部件在特徵圖上輕微平移，分類分支也希望深層特徵保持穩定的強激活。
2. **定位任務要求空間精細與平移敏感性**。邊界迴歸分支需要極其精確地確定目標外圍邊緣所在的絕對座標。它唯一關心的是物體的邊緣輪廓在哪一個像素點發生階躍。如果特徵圖過度平滑並抹去了高頻空間細節，迴歸分支就無法確定邊緣的精確截斷位置。

當兩項任務共享卷積層時，反向傳播的梯度在共享層內發生拉扯。分類損失要求擴大感受野以聚合人體輪廓；定位損失則要求死守邊緣像素的高頻跳變。共享層被迫折中，分類梯度直接打在用於框迴歸的特徵提取通道上，影響了邊界迴歸的精度。

爲了終結這種內耗，解耦頭（Decoupled Head）成爲了現代檢測頭的標準設計。左側是耦合頭：分類和定位共用卷積，只在最後 $1\times 1$ 處分叉。右側是解耦頭：特徵一進頭就分成兩條私有卷積。

![耦合頭與解耦頭的結構對比：耦合頭共享卷積只在末端分叉，解耦頭在入口處即分流爲分類與定位兩條私有支路](/img/cv_img/object-detection/coupled-vs-decoupled-head.png)

在解耦頭架構中，輸入特徵圖進入預測頭後立即分流至兩條獨立的物理支路：分類分支使用私有卷積提取高階語義，定位分支使用私有卷積保留空間邊緣細節。

解耦之後，分類損失的反向傳播梯度被限制在分類分支內部，定位損失的梯度也只在定位分支中流動。分類梯度不再直接打到框迴歸特徵上，定位分支得以專心保留行人邊緣的細微像素變化，分類分支也可以放開手腳去聚合判別性語義。

解耦頭消除了梯度層面的內耗，但也帶來了新的結構性斷層。

## 解耦後的斷層：兩條分支各自爲政

當分類分支與定位分支在物理上被完全拆開後，它們各自在獨立的軌道上運行，彼此失去了溝通的途徑。

分類分支獨立計算，只看分類特徵並輸出置信度分數 $s$；定位分支獨立計算，只看定位特徵並輸出座標（對應交併比 $\mathrm{IoU}$）。分類分支打分時不知道定位分支把框畫成了什麼形狀，定位分支微調邊界時也不知道當前位置的分數高低。

這種各自爲政的狀態，直接加劇了開頭提到的“高分低質”現象：

1. **高分低質框**：在兩名行人交錯的核心區域，特徵豐富，分類分支給出 $s = 0.95$ 的高分。但定位分支受雙重輪廓干擾，迴歸出的邊界框卡在兩人中間，與真實目標的交併比只有 $\mathrm{IoU} = 0.35$。
2. **低分高質框**：在單側行人的邊緣網格，分類特徵不夠典型，分類分支給出 $s = 0.40$ 的低分。但此處外側邊緣清晰，定位分支迴歸出了與真實目標重合度極高的框，交併比達到 $\mathrm{IoU} = 0.90$。

在現有的推理管線中，後處理篩選機制只能依賴分類分數 $s$ 降序排列候選框。排序的結果顯而易見：那個 $s = 0.95$ 但 $\mathrm{IoU} = 0.35$ 的破損框排在最前；而 $s = 0.40$ 但 $\mathrm{IoU} = 0.90$ 的精準框因分數過低排在末尾甚至被直接抹殺。

:::note[解耦的代價]
物理上的解耦治好了反向傳播時的梯度衝突，卻在正向預測時撕裂了分類與定位的協同性。如果分類分數不能反映定位好壞，解耦頭就只是把矛盾從特徵層轉移到了決策層。
:::

## 任務對齊：讓頭產出反映定位質量的分數（TOOD）

要解決解耦後的割裂問題，檢測頭產出的分類分數必須能夠與定位質量保持步調一致。

任務對齊（Task Alignment，指在檢測頭內部建立分類與定位的協同機制，使分類置信度與定位交併比緊密關聯）這一概念正是在這種背景下被引入檢測頭設計的。在任務對齊單階段目標檢測網絡（Task-aligned One-stage Object Detection, 簡稱 TOOD）中，核心思路是在保持解耦的前提下，讓兩項任務在特徵層進行動態交互，並重塑分類分數的優化目標。

TOOD 對檢測頭進行了兩個關鍵改造：

第一，**任務對齊預測頭（Task-Aligned Head）**。網絡不再讓分類與迴歸分支處於完全孤立的狀態，而是設計了輕量級的跨任務交互機制。分類分支在輸出最終特徵之前，會通過注意力機制讀取定位分支的空間分佈特徵；定位分支在計算邊界偏移之前，也會引入分類分支的語義激活信息。通過特徵層面的相互感知，分類分支能夠提前獲知當前位置在空間幾何上的邊界可信度。

第二，**顯式的對齊度量指標**。爲了讓網絡在訓練時有據可依，TOOD 提出了一個統一衡量分類與定位綜合質量的度量 $t = s^\alpha \times \mathrm{IoU}^\beta$。各項的含義如下：

- $s \in [0, 1]$ 是分類分支針對某個真實類別預測出的置信度分數；
- $\mathrm{IoU} \in [0, 1]$ 是當前位置迴歸出的預測邊界框與真實標註框之間的交併比；
- $\alpha$ 和 $\beta$ 是調節兩者相對重要程度的超參數。

這個度量公式採用嚴格的乘法邏輯：只有當分類置信度 $s$ 極高，**並且** 預測框與真實框的重合度 $\mathrm{IoU}$ 也極高時，綜合對齊度量 $t$ 纔會逼近 1.0。任何一項出現短板，在乘法的作用下，$t$ 的數值都會被大幅拉低。

獲得這個對齊度量 $t$ 之後，TOOD 做出了一個決定性的優化改動：**它廢棄了傳統分類訓練中非 0 即 1 的離散硬標籤，直接將標量 $t$ 歸一化後作爲分類分支優化的軟目標標籤。**

在任務對齊機制下，分類分支的學習目標被直接替換成了動態計算出的 $t$：

- 如果某個網格預測出的邊界框畫得非常粗糙，哪怕它內部的語義紋理再豐富，由於其計算出的 $\mathrm{IoU}$ 極低，$t$ 的目標值可能只有 0.2。分類分支在損失函數的拉扯下，就會主動降低該位置的置信度，不再給它虛高的分數；
- 只有當定位分支逐漸學會收緊邊界，將預測框的 $\mathrm{IoU}$ 逐步推高到 0.85 以上時，對齊度量 $t$ 纔會上升到 0.85，分類分支才被允許向更高的分數學習。

這一機制改變了分類分數的物理含義。經過任務對齊訓練後的檢測頭，其輸出的“分類分數”不再僅僅是局部像素屬於某個類別的概率，而是演變成了一個**綜合了類別屬性與幾何定位質量的可靠評估指標**。

在兩個行人交錯的重疊區域，那個卡在兩人中間的畸形框由於 $\mathrm{IoU}$ 極低，其分類分數會被系統性壓制；而在行人清晰邊緣處生成的精準框，由於同時具備合格語義與極高交併比，其分類分數被順暢推向高位。推理階段的後處理排序由此恢復正常。

需要指出的是，TOOD 這裏的對齊度量 $t$ 不僅在檢測頭內部重塑了分類分數的損失目標，它還爲後續挑選正負樣本提供了依據。至於這個分數如何進入代價矩陣挑選網格，屬於更爲宏大的動態分配機制，必須交由專門的[第 3 篇：Label Assignment](./label-assignment)來展開。檢測頭在這一步的使命，是確保輸出端給出的每一個分數都經得起幾何精度的檢驗。

## 檢測頭就位之後：爲何仍需多尺度特徵調度

回顧檢測頭的演進：通過 Focal Loss 壓制簡單背景的累積梯度，使稀缺的小目標能夠被正常學習；通過解耦頭拆分分類與定位通道，避免兩類任務在特徵提取上的梯度干擾；通過任務對齊機制將定位質量引入分類目標，使輸出分數能夠反映定位優劣。

然而，這些機制的前提是輸入檢測頭的特徵圖本身保留了必要的信息。

回到街道盡頭那塊 $16\times 16$ 像素的小路牌：在卷積網絡的逐層下采樣中，當特徵圖壓縮到 stride 32 時，整張圖只剩 $20\times 20$ 個點，小路牌在數學上甚至佔不到一個完整的像素點，其空間輪廓早在主幹網絡的深層就被下采樣徹底抹平了。

如果在到達預測頭之前，淺層的定位邊緣無法快速輸送給深層，深層的豐富語義無法順暢倒灌回淺層，那麼特徵圖本身就會淪爲殘缺不全的信息碎片。面對一塊在特徵圖上已經徹底丟失了位置信息或者根本不具備辨識特徵的網格，無論檢測頭的損失函數設計得再精妙、解耦結構再合理、對齊度量再嚴密，也根本無從落筆打分。

特徵圖究竟該如何在不同分辨率之間搭建起無損流動的橋樑，讓淺層擁有看懂物體的語義、讓深層保留定位邊緣的精度，這並不是檢測頭單兵作戰能夠解決的問題，而是屬於負責在骨幹與檢測頭之間調度信息的特徵中樞——[第 6 篇：多尺度特徵與 Neck 架構](./neck-architecture)。
