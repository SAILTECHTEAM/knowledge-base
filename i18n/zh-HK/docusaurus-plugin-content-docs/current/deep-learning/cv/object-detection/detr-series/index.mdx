# 概述

在 DETR（Detection Transformer，Carion 等人，2020）出現之前，現代目標檢測領域幾乎被基於密集候選（Dense Candidates）的範式所壟斷。無論是基於錨框（Anchor-based）的 Faster R-CNN、RetinaNet，還是無錨框（Anchor-free）的 FCOS、CenterNet，它們的底層邏輯高度一致：在圖像特徵圖的密集空間位置上鋪設成千上萬個候選點或候選框，讓網絡去預測每一個候選位置上是否存在目標以及對應的偏移量。

密集預測範式帶來了兩個長期存在且難以根除的工程包袱：**一對多正負樣本分配（One-to-Many Label Assignment）** 與 **非極大值抑制（NMS，Non-Maximum Suppression）**。DETR 的核心貢獻，在於從第一性原理出發，徹底重構了目標檢測的建模方式：**將目標檢測直接定義為一個直接集合預測（Direct Set Prediction）問題**。DETR 不在特徵圖上做密集滑動掃描，而是維護一組固定容量的 Object Query，通過一對一二分圖匹配把 $N$ 個預測與 $M$ 個真實目標精確對齊，從而在整條流水線中移除 NMS。

原版 DETR 在工程實踐中暴露出兩個嚴重的瓶頸，也構成了後續 DETR 改進研究的主線：一是注意力全局掃描與二分圖匹配震盪帶來的慢收斂，二是密集註意力的二次方計算複雜度將模型限制在單一低分辨率特徵尺度上。本系列順着約束鏈而不是論文版本史展開，逐篇追一個問題被提出、被改寫、又被新的約束頂回來的過程。

## 系列文章規劃

### [第 1 篇：原版 DETR——網絡架構與前向流程](./detr-v1-architecture-forward-pass)

解析變長無序集合與定長網絡矛盾、CNN 主幹、二維位置編碼、Transformer 編碼器與 Object Query 的工作機制。

### [第 2 篇：原版 DETR——二分圖匹配與集合損失](./detr-v1-bipartite-matching-set-loss)

深入剖析排列不變性、匈牙利算法最優匹配、匹配代價與集合損失函數的構建，以及一對一匹配如何內化 NMS。

### [第 3 篇：Deformable DETR——稀疏採樣與多尺度注意力](./deformable-detr)

解析局部稀疏採樣機制、多尺度可變形注意力、Reference Point 接口及特徵讀取機制重構。參考點上的稀疏採樣取代全局稠密注意力，使 DETR 直接使用高分辨率多尺度特徵圖，收斂速度加快了近 10 倍。

### [第 4 篇：Conditional 與 DAB-DETR——查詢空間化](./conditional-dab-detr)

分析 Object Query 的空間含義，對比 conditional spatial query 與顯式 4D 動態錨框 $(x, y, w, h)$ 設計，使交叉注意力的尋址目標明確化。

### [第 5 篇：DN-DETR——查詢去噪與早期匹配穩定化](./dn-detr)

剖析一對一匹配的震盪機理，詳解目標級去噪查詢構造、注意力掩碼設計與訓練加速原理。去噪訓練旁路繞過匈牙利匹配的不穩定性，直接提供確定性梯度。

### [第 6 篇：DINO——三處接口的聯合設計](./dino)

解析對比式去噪（Contrastive DeNoising）、混合查詢選擇（Mixed Query Selection）與 Look Forward Twice 機制的三接口協同。

### [第 7 篇：Group DETR——訓練期查詢分組](./group-detr)

剖析一對一匹配造成的正樣本稀疏，解析多組查詢、組間隔離自注意力與組內獨立匹配，以及訓練與推理的不對稱實現。

### [第 8 篇：D-FINE——邊界框分佈細化與定位自蒸餾](./d-fine)

把逐層的點估計換成邊界距離的離散分佈，解析逐層區間收縮、期望解碼與全局最優定位自蒸餾。

### [第 9 篇：DEIM——密集匹配與匹配質量約束](./deim)

分析增密一對一匹配帶來的低質量匹配，拆解密集一對一的樣本構造與可匹配性感知損失（Matchability-Aware Loss）。密集化正樣本在保留端到端推理的同時，提高了訓練期每個真值對應的正樣本利用率。

### [第 10 篇：RT-DETR 與 RT-DETRv2——延遲預算與算子約束](./rt-detr)

端到端延遲的構成與測量口徑、混合編碼器（AIFI 與 CCFM）、不確定性最小的編碼器查詢選擇、可伸縮的解碼器層數，以及 v2 的按尺度分配採樣點數與可部署的離散採樣。到這一步，Transformer 檢測器在兼顧無 NMS 優勢的同時，已經在推理速度與精度上匹敵甚至超越先進 YOLO 系列。
