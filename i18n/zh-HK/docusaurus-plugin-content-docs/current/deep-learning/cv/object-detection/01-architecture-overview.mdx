# 目標檢測解構（0）：架構拆解與核心部件

在計算機視覺中，目標檢測（Object Detection）的核心訴求是在圖像中同時完成“定位”（找出物體的邊界）與“分類”（識別物體的屬性）。這一任務看似直接，但在實際場景中，網絡必須面對極端懸殊的尺度跨度、複雜的空間重疊遮擋、以及海量背景噪聲的干擾。

經過十數年的演進，目標檢測已經分化出兩階段、單階段、Anchor-based、Anchor-free 以及 Transformer Query 等多種看似迥異的架構流派。然而，如果退回到底層機制，所有檢測體系本質上都是由**五個可以獨立替換的核心部件**裝配而成的系統：

1. **預測載體（Prediction Carrier）**：網絡在最底層向外界交出候選預測的基本載體，決定了每一個潛在猜測與圖像幾何空間如何綁定。
2. **特徵採樣（Feature Sampling）**：檢測頭從主幹網絡提取的空間特徵圖中提取具體特徵表示的操作方式。
3. **Label Assignment（樣本匹配）**：在訓練階段將真實標註框指派給特定預測載體的數學協議，決定正負樣本的歸屬，並在推理端直接決定是否需要非極大值抑制（NMS）。
4. **框與類別的編碼**：預測頭輸出數值的物理意義，以及座標迴歸與分類判別的具體形式。
5. **多尺度融合**：在骨幹網絡與檢測頭之間搭建的特徵金字塔管道，負責在不同分辨率與語義深度之間調度信息。

不同的網絡體系在這五個核心部件上做出了不同的技術選擇，形成了各自獨特的行爲模式。理解了這五個部件的作用和相互關係，就能看懂一個目標檢測網絡的設計邏輯，理論上的優缺點和行爲偏好。

這是整個系列文章的第 0 篇。本篇的目標是建立一張覆蓋主流檢測體系的定位座標圖，釐清各個核心部件之間的裝配邏輯。整個系列的閱讀順序爲：本篇 → [第 1 篇：預測載體](./prediction-carrier) → [第 2 篇：特徵採樣](./feature-sampling) → [第 3 篇：Label Assignment](./label-assignment) → [第 4 篇：邊界框表示與迴歸損失](./bbox-regression-loss) → [第 5 篇：分類置信度與 Detection Head](./classification-head) → [第 6 篇：多尺度特徵與 Neck 架構](./neck-architecture)。

## 四套檢測體系的部件裝配

爲了看清五個核心部件如何具體決定一個檢測系統的運作行爲，下表列出了四個具有代表性的經典檢測體系在各個部件上的具體選擇與機制推論：

<div className="wide-table">

| 檢測體系 | 預測載體 | 特徵採樣 | Label Assignment（含 NMS 推論） | 頭輸出（框表示 / 分類頭） | 多尺度融合 | 機制推論 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **YOLOv1** | $S\times S$ 離散空間網格（單尺度，如 $20\times 20$ 網格，每格承載固定數量候選框） | 全連接層全局展平映射（Dense FC Readout） | 目標中心落點幾何硬分配（單網格負責單目標，多框競爭；因全圖密集網格多重響應，推理依賴 NMS） | 網格內相對偏移歸一化座標 $(x, y, w, h)$ + 全局條件類別概率與框置信度乘積 | 無特徵金字塔（僅依賴單張 stride 32 深層特徵直接映射） | 空間網格硬綁定導致單網格多目標容量鎖死，全連接採樣破壞了空間平移不變性，缺乏淺層特徵支持導致小目標無法有效召回。 |
| **Faster R-CNN** | 滑動窗口錨框模板（RPN 階段）與二階段候選區域（RoI Proposal） | 局部區域特徵截取與重採樣（RoI Pooling / RoIAlign） | 基於 IoU 閾值的靜態一對多重疊匹配；由於同個目標被大量鄰近錨框重複激活，推理階段必須使用 NMS 抑制冗餘 | 相對先驗錨框的尺度對數偏移變換 $(\Delta x, \Delta y, \Delta w, \Delta h)$ + 獨立全連接層 Softmax 類別分佈 | 早期無跨尺度融合，後續引入自頂向下單向特徵金字塔（FPN） | 二階段 RoI 採樣徹底解耦了局部特徵與全圖空間，密集錨框帶來高召回率但製造了嚴重的背景負樣本冗餘，一對多分配決定了必須依賴 NMS 清理重疊框。 |
| **FCOS** | 金字塔多層特徵圖上的密集像素點（三層金字塔共約 8400 個逐點觀測站） | 全卷積密集滑動逐點採樣（全圖共享卷積核在各空間位置局部提取） | 空間點落入真實邊界框內部判定結合多尺度距離分流（一對多分配）；因目標內部大量像素點同時被激活，推理階段必須依賴 NMS | 四向絕對邊界物理距離 $(l, t, r, b)$ + 中心度標量（Centerness）與逐類別二值分類（BCE / Focal Loss） | 自頂向下特徵金字塔（FPN）結合跨層最大回歸距離硬約束 | 剝離了人工預設的錨框尺寸超參數，將幾何迴歸簡化爲像素距離測量，多尺度分流化解了空間重疊衝突，但其密集空間綁定與一對多分配依然保留了 NMS 負擔。 |
| **DETR** | 固定數量（如 100 或 300 個）全局可學習目標查詢向量（Object Queries） | Transformer 解碼器跨注意力機制（Cross-Attention）從全圖特徵中全局尋址採樣 | 基於二分圖匹配（Hungarian Algorithm）全局最小代價的嚴格一對一分配；推理端天然不需要 NMS | 整圖歸一化絕對中心座標與長寬 $(c_x, c_y, w, h)$ + 包含背景空類別（$\varnothing$）的全局類別分佈 | 早期僅使用單層特徵展平自注意力，後續演進爲多尺度可變形注意力或混合編碼結構（AIFI+CCFM） | 預測載體與像素網格徹底解綁，一對一匹配在訓練目標函數中從源頭杜絕了多重響應，使檢測網絡首次擺脫了對手工設計 NMS 後處理的依賴。 |

</div>

從這張表中可以看出，每一個具體檢測器的特性，並不是某種模糊的風格，而是它在五個核心部件上所做技術選擇的聯立解。改變其中某一個部件的選擇，整個系統的輸入輸出協議和性能邊界就會隨之重構。

## 錨框與非極大值抑制不是綁定的概念

在閱讀檢測文獻時，一種常見的誤解是將錨框與非極大值抑制（NMS）視爲不可分割的孿生結構，甚至推導出無錨框（Anchor-free）就等於擺脫了 NMS 的錯誤結論。

事實恰恰相反。錨框與 NMS 分屬於完全不同的兩個部件：錨框是**預測載體**這一部件中的幾何參數化模板，用來解決局部空間容量與長寬比例先驗的問題；而 NMS 則是**Label Assignment**這一部件在選擇了一對多分配協議之後的必然推論。

回顧四套體系的組合便能看清兩者的獨立性：

- **YOLOv1** 是典型的無錨框設計，它只使用空間網格和無模板的偏移預測，但在推理時依然必須運行 NMS。因爲全圖相鄰的網格在面對同一目標時，依然會在邊界處產生多個高分預測框。
- **FCOS** 徹底拋棄了錨框，改用純粹的特徵像素點作爲預測載體。然而在 Label Assignment 階段，只要一個特徵點落在真實目標的幾何內部，該點就會被標記爲正樣本。對於中央那名大尺寸行人，其包圍盒內部可能包含數百個特徵像素點，這意味着網絡在訓練時命令這數百個點同時對同一個行人發出正向預測。到了推理階段，這數百個點自然會交出數百個高度重合的檢測框，必須依靠 NMS 強行壓制，只保留中心得分最高的一個。
- 真正能夠移除 NMS 的，是 **DETR** 以及後續的 **YOLOv10**。DETR 通過匈牙利二分圖匹配，在損失計算前強制規定：畫面中的每一個真實目標，在全網所有候選槽位中只能且必須匹配唯一一個損失最小的槽位，其餘槽位一律按背景懲罰。由於網絡在訓練時就受到了單目標單響應的強約束，推理時各個查詢向量之間通過自注意力互相排斥，輸出的集合中天然不存在重疊預測。YOLOv10 則是在逐點密集預測的基礎上，引入雙 Label Assignment 機制，在推理分支採用一對一匹配，同樣達成了無 NMS 推理。

:::note[決定 NMS 存廢的唯一因素]
決定推理流程中是否存在 NMS 的唯一因素，是 Label Assignment 協議究竟採用了一對多還是一對一。預測載體採用錨框、網格還是像素點，與 NMS 的存廢沒有直接因果關係。
:::

## 不要把 YOLO 當作脫離體系的獨立路線

工業界和部分初學者常將目標檢測劃分爲三條互不相干的流派：二階段網絡、YOLO 系列以及 Transformer 檢測器。這種按項目代碼庫來割裂體系的視角，掩蓋了底層機制的演變規律。

YOLO 從來不是一條擁有獨立物理法則的技術路線。拆解 YOLO 從初代到最新版本的演變，其本質是在五個基礎部件之間進行組合遷移：

- **YOLOv1** 佔據的是密集網格預測載體、全局展平特徵採樣、靜態幾何分配與無多尺度融合的原始組合。
- **YOLOv2 到 YOLOv7** 整體遷移並深耕於密集錨框預測載體、全卷積局部特徵採樣、特徵金字塔多尺度融合（自頂向下 FPN 與自底向上 PANet 的結合），以及基於 IoU 的動態一對多 Label Assignment（例如 OTA 與 SimOTA）。在這個漫長的階段中，網絡骨幹更深、特徵融合拓撲更密集、動態正樣本分配策略更平滑，但五個部件的根本組合形式始終停留在密集錨框加一對多分配的區間內。
- **YOLOv8 與 YOLOv9** 做出的最核心結構調整，是將預測載體部件中的預設錨框模板剔除，換成了與 FCOS 類似的逐點回歸與分佈式邊界表示（Task-Aligned Assigner 與 DFL 機制）。這一步標誌着該系列在預測載體部件上全面轉向無錨框。
- **YOLOv10** 則進一步向 Label Assignment 部件動刀，引入一致性雙重分配策略，在保留一對多訓練引導的同時，讓推理分支運行在一對一分配協議下，從而切掉了推理後處理中的 NMS。

## 預測載體的選擇決定了檢測系統的整體設計

在目標檢測系統的各個模塊之間，存在明確的依賴關係：**預測載體如何與空間座標關聯，決定了後續特徵提取與樣本匹配的具體形式。**

如果預測載體與特徵圖的空間網格直接綁定（無論是基於網格、錨框還是特徵點），特徵採樣就必須採用與之對應的局部窗口卷積，Label Assignment 就需要在空間鄰域內按幾何規則或動態指標挑選正樣本，並處理密集採樣帶來的背景樣本冗餘，推理階段也需要依賴 NMS 抑制重疊檢測框；如果預測載體與空間網格解綁，採用目標查詢向量（Query），特徵採樣就需要藉助全局注意力機制聚合上下文，Label Assignment 則通過二分圖匹配實現一對一預測，從而省去 NMS 後處理。
