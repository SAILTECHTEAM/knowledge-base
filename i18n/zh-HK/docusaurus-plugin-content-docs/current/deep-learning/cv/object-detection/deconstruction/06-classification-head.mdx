# 目標檢測解構（5）：分類置信度與 Detection Head

在密集預測的排序輸出中，經常出現兩類錯位：分類分數高達 $0.95$ 的預測框與真實目標的重合度很低，而與真實目標精確對齊的預測框分類分數只有 $0.15$，在閾值篩選階段就被丟棄。

這反映了檢測頭長期面對的兩類問題：在密集的候選空間中，背景區域的數量遠多於真實目標，少數困難正樣本的梯度容易被大量簡單負樣本的累積梯度淹沒；分類分支輸出的高置信度分數無法代表預測框在幾何定位上的準確程度。

檢測頭（Head）是檢測網絡中直接連接損失函數、輸出預測結果的模塊。它必須在每個候選位置上回答兩個問題：這裏存在什麼類別的物體，以及物體的幾何邊界在哪裏。這兩個子任務在特徵表示需求與優化方向上存在衝突。

## 爲什麼分類分數不能代表定位質量

在圖像分類任務中，模型追求平移不變性。無論目標出現在圖像的左上角、中央還是右下角，分類器都希望深層特徵給出穩定的類別響應。

但是目標檢測不僅要識別物體的語義屬性，還要輸出具體的幾何邊界框座標 $[x, y, w, h]$。檢測頭對空間位置具有平移敏感性：目標在圖像中平移兩個像素，或者預測框向外擴張三個像素，網絡輸出的邊界座標都應當產生相應的數值變化。

當系統直接使用分類分支的得分作爲衡量檢測框整體質量的唯一依據時，錯位就會出現。

考慮空間上相互靠近的兩個目標。當一個預測框落在兩個目標之間時，該位置對應的感受野同時覆蓋了兩個目標的局部結構。對於分類分支，只要感受野內存在充足的類別判別性紋理，分類卷積就會輸出接近 $1.0$ 的置信度，而不關心這些特徵是否屬於同一個物體實例。

但是在空間幾何層面，這個預測框與兩個真實標註框的交併比（IoU）都很低，可能都低於 $0.3$。

相反，另一個預測框的四條邊與某個真實目標的輪廓精確對齊，交併比達到 $0.9$。但是生成這個預測框的特徵位置恰好處於目標邊緣或者光照、紋理變化較大的區域，局部特徵缺乏典型性，分類分支給出的置信度只有 $0.45$。

在依賴分類分數排序的後處理中，交併比只有 $0.3$ 的預測框會憑藉 $0.95$ 的高分排在前面，而交併比高達 $0.9$ 的精確預測框會因爲分數偏低排在後面，甚至在閾值篩選階段被直接丟棄。

分類分支只反映局部特徵的語義豐富程度，不反映邊界框的幾何重合程度。要使檢測頭正常工作，必須先解決背景樣本帶來的梯度失衡，再解決分類與定位在特徵表示與優化目標上的衝突。

## 背景樣本的數量優勢：從 Objectness 到 Focal Loss

在一張 $640\times 640$ 的輸入圖像上，密集預測檢測頭通常在多個下采樣倍率的特徵圖上設置預測點。假設網絡使用步長爲 $8$、$16$ 和 $32$ 的三層特徵圖：

- 步長爲 $8$ 的特徵圖尺寸爲 $80\times 80$，提供 6400 個預測位置；
- 步長爲 $16$ 的特徵圖尺寸爲 $40\times 40$，提供 1600 個預測位置；
- 步長爲 $32$ 的特徵圖尺寸爲 $20\times 20$，提供 400 個預測位置。

三層特徵圖累加在一起，單張圖像生成 $6400 + 1600 + 400 = 8400$ 個候選位置。

在這 8400 個位置中，真正包含目標的位置很少。通常只有數十個位置能夠劃歸爲正樣本，其餘 8300 多個位置全部是背景。

在密集預測場景中，正負樣本的比例很容易達到幾十比一甚至上千比一。

早期的檢測器爲了應對這種數量差異，嘗試在類別預測之前引入名爲 objectness 的獨立分支。objectness 表示目標存在性，它是一個二分類標量，用於判斷某個候選區域包含物體還是純背景。在早期單階段檢測算法中，最終的類別置信度被拆成 $P(\mathrm{Class}_i) = P(\mathrm{Object}) \times P(\mathrm{Class}_i \mid \mathrm{Object})$。第一項由 objectness 分支輸出，表示該位置存在物體的概率；第二項由類別分支輸出，表示在存在物體的條件下屬於第 $i$ 類的條件概率。

這種拆分在概念上將是否存在物體與屬於哪個類別分開，但是沒有從根本上解決梯度被背景主導的問題。無論是 objectness 分支還是多分類分支，只要損失函數沿用標準的二值交叉熵（Binary Cross-Entropy），大量背景樣本的累積效應都會主導訓練過程。

對於標準的二值交叉熵損失，單個樣本的損失和與標籤對齊的概率 $p_t$ 寫成：

$$
\begin{aligned}
\mathrm{CE}(p, y) &= \begin{cases} -\log(p) & \text{當 } y = 1 \\ -\log(1 - p) & \text{當 } y = 0 \end{cases} \\
p_t &= \begin{cases} p & \text{當 } y = 1 \\ 1 - p & \text{當 } y = 0 \end{cases}
\end{aligned}
$$

其中 $y \in \{0, 1\}$ 是真實標籤，$p \in [0, 1]$ 是模型預測該位置爲正樣本的概率。交叉熵因此可以簡寫爲 $\mathrm{CE}(p_t) = -\log(p_t)$。

在這一公式下分析 8300 多個背景位置。多數背景區域容易判斷，網絡能夠給出 $p = 0.01$ 的預測，即 $p_t = 1 - 0.01 = 0.99$。單個簡單背景的損失是 $\mathrm{CE}(0.99) = -\log(0.99) \approx 0.010$。單獨看這個數值很小，但是當 8300 個簡單負樣本同時反向傳播時，它們產生的損失累加起來達到 $8300 \times 0.01 \approx 83$。

再看一個困難正樣本。假設網絡對該位置的預測概率只有 $p = 0.2$（即 $p_t = 0.2$），單個損失是 $\mathrm{CE}(0.2) = -\log(0.2) \approx 1.61$。單個困難樣本的損失雖然比單個簡單背景樣本大上百倍，但是在數千個簡單背景樣本的數量優勢面前，負樣本累加產生的梯度總和依然佔據主導。在反向傳播過程中，優化器的更新方向主要由大量已分類正確的背景樣本決定，真正需要學習的困難正樣本信號被淹沒。

爲了緩解這種數量差異帶來的影響，Focal Loss 改變了損失函數的加權機制。它在標準交叉熵前面增加了一個基於置信度的調製項：

$$
\mathrm{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t)
$$

公式中的 $\gamma \ge 0$ 是調製超參數（在通用實踐中通常取 $\gamma = 2$）。

:::tip[Focal Loss 的調製機制]
調製項根據預測概率 $p_t$ 的高低，動態降低已經學習充分的樣本所貢獻的梯度權重。容易區分的樣本（如均勻背景區域，$p_t = 0.99$）的調製項 $(1 - 0.99)^2 = 0.0001$，原本 $0.01$ 的損失被削弱四個數量級，梯度幾乎不再更新；困難樣本（如 $p_t = 0.2$）的調製項 $(1 - 0.2)^2 = 0.64$，損失得到大部分保留。檢測頭在樣本數量極端失衡的情況下，仍能將更新方向集中在少數難以區分的真實目標上。
:::

## 特徵衝突：耦合頭與解耦頭

背景樣本帶來的梯度失衡得到緩解之後，檢測頭內部的結構差異成爲影響精度的主要因素。

早期單階段檢測器普遍採用耦合頭（Coupled Head）：來自特徵金字塔的特徵圖直接送入兩到三層共享卷積層，隨後在末端引出兩個並行的 $1\times 1$ 卷積，分別輸出類別預測分數與邊界框座標偏移量。

這種結構隱含了一個假設：在深層表示中，用於語義分類的特徵與用於幾何定位的特徵是高度重合並且可以共用的。

然而在特徵分析中，分類與定位對特徵表示的需求存在實質衝突：

1. **分類任務要求語義抽象與平移不變性**。分類分支希望卷積核忽略空間上的微小擾動，關注目標整體的語義結構。即使目標的局部結構在特徵圖上輕微平移，分類分支也希望深層特徵保持穩定的激活。
2. **定位任務要求空間精確與平移敏感性**。邊界迴歸分支需要確定目標邊緣所在的準確座標，關注物體的邊緣輪廓在哪個像素位置發生變化。如果特徵圖過度平滑並且丟失了高頻空間細節，迴歸分支就無法確定邊緣的準確位置。

當兩類任務共享卷積層時，反向傳播的梯度在共享層內相互干擾。分類損失要求擴大感受野以聚合整體語義，定位損失則要求保留邊緣像素的高頻變化。共享層被迫在兩者之間折中，分類梯度直接影響用於邊界迴歸的特徵通道，降低了邊界迴歸的精度。

爲了解決這種內部干擾，解耦頭（Decoupled Head）成爲現代檢測頭的標準設計。左側是耦合頭：分類和定位共用卷積，只在最後 $1\times 1$ 處分叉。右側是解耦頭：特徵進入檢測頭後分爲兩條獨立卷積支路。

![耦合頭與解耦頭的結構對比：耦合頭共享卷積只在末端分叉，解耦頭在入口處即分流爲分類與定位兩條獨立支路](/img/cv_img/object-detection/coupled-vs-decoupled-head.png)

在解耦頭架構中，輸入特徵圖進入檢測頭後分流到兩條獨立的支路：分類分支使用獨立卷積提取高階語義，定位分支使用獨立卷積保留空間邊緣細節。

解耦之後，分類損失的反向傳播梯度限制在分類分支內部，定位損失的梯度也只在定位分支中流動。分類梯度不再直接影響邊界迴歸的特徵提取，定位分支能夠保留目標邊緣的像素級變化，分類分支也可以集中聚合判別性語義。

解耦頭消除了梯度層面的相互干擾，但是帶來了新的結構性問題。

## 解耦後的分離：兩條分支獨立運行

當分類分支與定位分支在結構上完全分開後，它們在各自的支路上獨立運行，相互之間缺少信息交換。

分類分支獨立計算，只根據分類特徵輸出置信度分數 $s$；定位分支獨立計算，只根據定位特徵輸出座標（對應交併比 $\mathrm{IoU}$）。分類分支打分時不知道定位分支輸出的邊界形狀，定位分支調整邊界時也不知道當前位置的分類分數。

這種相互獨立的狀態加劇了開頭提到的高分低質現象：

1. **高分低質框**：在目標密集或者相互靠近的區域，局部特徵豐富，分類分支給出 $s = 0.95$ 的高分。但是定位分支受到多個相鄰目標輪廓的干擾，迴歸出的邊界框落在目標之間，與真實目標的交併比只有 $\mathrm{IoU} = 0.35$。
2. **低分高質框**：在目標邊緣特徵清晰但是語義典型性不足的位置，分類分支給出 $s = 0.40$ 的低分。但是該位置的外側邊緣清晰，定位分支迴歸出了與真實目標重合度很高的預測框，交併比達到 $\mathrm{IoU} = 0.90$。

在現有的推理流程中，後處理篩選只能依賴分類分數 $s$ 降序排列候選框。排序結果是確定的：$s = 0.95$ 但 $\mathrm{IoU} = 0.35$ 的預測框排在前面，而 $s = 0.40$ 但 $\mathrm{IoU} = 0.90$ 的精確預測框因爲分數過低排在後面甚至被直接過濾。

:::note[解耦的代價]
結構上的解耦解決了反向傳播時的梯度干擾，但是在正向預測時割裂了分類與定位的協同。如果分類分數不能反映定位質量，解耦頭只是把矛盾從特徵層轉移到了決策層。
:::

## 任務對齊：使輸出分數反映定位質量（TOOD）

要解決分支解耦後的分離問題，檢測頭輸出的分類分數必須與定位質量保持一致。

任務對齊（Task Alignment，指在檢測頭內部建立分類與定位的協同機制，使分類置信度與定位交併比相互關聯）這一概念正是在這種背景下引入檢測頭設計的。在任務對齊單階段目標檢測網絡（Task-aligned One-stage Object Detection，簡稱 TOOD）中，核心思路是在保持分支解耦的前提下，使兩類任務在特徵層面進行交互，並重新定義分類分數的優化目標。

TOOD 對檢測頭進行了兩個關鍵改造：

第一，**任務對齊預測頭（Task-Aligned Head）**。網絡不再讓分類與迴歸分支完全孤立，而是設計了輕量級的跨任務交互機制。分類分支在輸出最終特徵之前，通過注意力機制讀取定位分支的空間分佈特徵；定位分支在計算邊界偏移之前，也引入分類分支的語義激活信息。通過特徵層面的相互感知，分類分支能夠提前獲得當前位置在空間幾何上的邊界可信度。

第二，**顯式的對齊度量指標**。爲了讓網絡在訓練時有明確的優化依據，TOOD 提出了一個統一衡量分類與定位綜合質量的度量 $t = s^\alpha \times \mathrm{IoU}^\beta$。各項的含義如下：

- $s \in [0, 1]$ 是分類分支針對某個真實類別預測出的置信度分數；
- $\mathrm{IoU} \in [0, 1]$ 是當前位置迴歸出的預測邊界框與真實標註框之間的交併比；
- $\alpha$ 和 $\beta$ 是調節兩者相對重要程度的超參數。

這個度量公式採用乘法形式：只有當分類置信度 $s$ 較高，並且預測框與真實框的重合度 $\mathrm{IoU}$ 也較高時，綜合對齊度量 $t$ 才接近 $1.0$。其中任何一項偏低，在乘法作用下 $t$ 的數值都會明顯下降。

獲得這個對齊度量 $t$ 之後，TOOD 做出了一個關鍵的優化改動：**它不再使用傳統分類訓練中非 $0$ 即 $1$ 的離散硬標籤，而是直接將標量 $t$ 歸一化後作爲分類分支優化的軟目標標籤。**

在任務對齊機制下，分類分支的學習目標被替換成動態計算出的 $t$：

- 如果某個位置預測出的邊界框不夠準確，即使它內部的語義紋理豐富，由於其計算出的 $\mathrm{IoU}$ 較低，$t$ 的目標值可能只有 $0.2$。分類分支在損失函數的約束下，會降低該位置的置信度，不再給出虛高的分數；
- 只有當定位分支逐漸收緊邊界，將預測框的 $\mathrm{IoU}$ 推高到 $0.85$ 以上時，對齊度量 $t$ 纔會上升到 $0.85$，分類分支才被允許輸出更高的分數。

這一機制改變了分類分數的含義。經過任務對齊訓練後的檢測頭，其輸出的分類分數不再僅僅是局部像素屬於某個類別的概率，而是綜合了類別屬性與幾何定位質量的評價指標。

在目標重疊區域，落在目標之間、定位質量較差的預測框由於 $\mathrm{IoU}$ 較低，其分類分數會被系統性壓低；而在目標邊緣清晰處生成的精確預測框，由於同時具備語義響應與較高的交併比，其分類分數會被推向高位。推理階段的後處理排序因此恢復正常。

需要指出的是，TOOD 的對齊度量 $t$ 不僅在檢測頭內部重新定義了分類分數的損失目標，它還爲後續選擇正負樣本提供了依據。這個分數如何進入代價矩陣並參與樣本選擇，屬於動態匹配機制的內容，由[第 3 篇：Label Assignment](./label-assignment)展開。檢測頭在這一步的作用，是保證輸出端給出的每個分數都經過幾何精度的約束。

## 檢測頭就位之後：爲何仍需多尺度特徵調度

回顧檢測頭的演進：通過 Focal Loss 抑制簡單背景的累積梯度，使稀少的困難目標能夠得到正常學習；通過解耦頭拆分分類與定位通道，避免兩類任務在特徵提取上的梯度干擾；通過任務對齊機制將定位質量引入分類目標，使輸出分數能夠反映定位準確程度。

然而，這些機制成立的前提是輸入檢測頭的特徵圖本身保留了必要的信息。

以深層高倍率下采樣爲例：當特徵圖壓縮到步長爲 $32$ 時，整張特徵圖只剩 $20\times 20$ 個特徵點，小目標在空間上已經不足一個完整的特徵點，其空間輪廓在主幹網絡的深層輸出中基本丟失。

如果在到達檢測頭之前，淺層的定位細節無法傳遞給深層，深層的語義無法傳遞迴淺層，那麼特徵圖本身就是不完整的。面對在特徵圖上已經丟失位置信息或者缺乏判別性特徵的位置，無論檢測頭的損失函數設計得多麼精細、分支結構多麼合理、對齊度量多麼嚴密，都無法輸出可靠的預測分數。

特徵圖應當如何在不同分辨率之間建立有效的信息流動，使淺層獲得識別目標所需的語義，使深層保留定位所需的邊緣精度，這不是檢測頭單獨能夠解決的問題，而是負責在骨幹網絡與檢測頭之間調度信息的特徵融合模塊的職責，相關內容屬於[第 6 篇：多尺度特徵與 Neck 架構](./neck-architecture)。
