# I3D（膨脹 3D 卷積網路）

**論文：** Joao Carreira and Andrew Zisserman, Quo Vadis, Action Recognition? A New Model and the Kinetics Dataset, CVPR 2017.

**論文連結：** https://arxiv.org/abs/1705.07750

**程式碼：** https://github.com/deepmind/kinetics-i3d

![DeepMind 與牛津大學作者的 I3D 論文標題欄](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image1.png)

## 背景：兩項貢獻

### 提出了新模型 I3D

這裡要回答的問題是，如何把成熟的 2D 圖像模型擴展為 3D 影片模型。好的擴展方法會沿用 2D 網路的結構和預訓練權重，這樣訓練仍然簡單，ImageNet 預訓練的成果也不會浪費。

### 設計了 Kinetics 資料集

此前的影片研究缺少一個規模與 ImageNet 相當的大資料集。作者發佈了 Kinetics-400：400 個人體動作類別，每個類別有 400 多個影片片段，總計約 30 萬個片段，每個片段長約 10 秒，取自 YouTube。作者還指出，影片模型應當在影片資料上預訓練，而不能只依賴圖像預訓練，Kinetics 資料集讓這種預訓練成為可能。

![缺少周圍幀時動作標籤存在歧義的單幀畫面](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image2.png)

單張圖像常常無法確定動作標籤。周圍幀提供的運動資訊可以消除這種歧義，這也是論文把影片建模看作時空聯合建模問題的原因。

## 預備知識：光流

光流估計相鄰幀之間每個像素的位移，是一種顯式的運動信號。當任務取決於物體隨時間如何運動，而不是靜態長相時，光流很有用。

標準的光流計算建立在三個假設上：

- 亮度不變：被跟蹤的點在幀與幀之間保持亮度不變。
- 運動很小：相鄰兩幀之間的位移不大。
- 空間一致：相鄰像素的運動方式接近。

由此可以直接看出它的侷限。光流場不一定等於真實的物體運動，因為演算法跟蹤的只是表面的亮度變化。它對光照也很敏感：光照一變，亮度不變的假設就不再成立，識別效果隨之下降。密集光流的計算開銷也很大，因為幾乎每個像素都要估計一個位移向量。

![跑步人物身上的光流向量，以及補償相機運動之後的光流向量](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image5.jpeg)

## I3D 模型

在得出 I3D 之前，論文在同一基準下對比了五種結構。

![論文對比的五種影片結構：LSTM、3D 卷積網路、雙流網路、3D 融合網路和雙流 I3D](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image6.png)

### 結構 a）CNN 加 LSTM

每一幀先經過 2D CNN，得到的特徵序列再送入 LSTM 做時序建模。特徵提取和時序推理是分開的：CNN 從來看不到運動，LSTM 拿到的只是每幀的概要資訊。空間和時間在特徵學習階段沒有互動，在影片基準上的準確率也比較一般。

### 結構 b）3D 卷積網路

連續幀在時間、高和寬三個維度上組成一個 3D 體。3D 卷積同時學習空間和時間資訊，用池化控制 3D 特徵圖的大小，用全連接層完成分類。它的短板在預訓練：普通 2D 網路可以直接繼承 ImageNet 權重，這個 3D 網路只能從頭訓練，訓練更難，也更容易過擬合。

### 結構 c）雙流網路

兩個 2D 網路並行運行，一個處理 RGB 圖像幀，一個處理預先算好的光流。兩個分支都可以用 ImageNet 預訓練，運動資訊來自光流輸入，而不是 3D 卷積。這裡的光流不是真正的時間軸，而是預先算好的位移資訊，再送給 2D 網路。融合只發生在打分層面，兩個流從不共享特徵。

### 結構 d）和 e）

兩種結構都融合了 RGB 和光流，區別在於融合的位置和方式。

模型（d）保留了兩個 2D 流，但在高層把特徵圖融合成時空張量體，再送入一個小 3D 網路。融合提前到了最終決策之前，準確率有所提高，但整個流程仍然很重：還是要預先計算密集光流，又在上面疊了一個 3D 階段。

模型（e）就是 I3D。RGB 和光流各自進入一個獨立的 3D 網路，每個分支都同時對空間和時間建模，兩個流在末端融合：

> 每個分支獨立進行時空建模，再把兩路結果在末端融合。

下表取自原論文，給出了每種設計的計算代價。I3D 的參數量是 25M，而純 3D 卷積網路是 79M，同時 I3D 在測試時的時間覆蓋範圍達到了完整的 10 秒。

![五種結構的參數量和時間覆蓋範圍](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image7.png)

### ImageNet 預訓練與遷移

在 ImageNet 這樣的大資料集上預訓練，可以讓網路學到能遷移到小任務上的特徵。在 Kinetics 出現之前，影片領域沒有對應的資料集，影片模型通常只能在 UCF-101 或 HMDB-51 這樣的小資料集上從頭訓練。I3D 加上 Kinetics 補上了這一塊，讓影片領域也有了和圖像領域一樣的「先預訓練再微調」的流程。

## 方法實現

### 如何做膨脹

膨脹保持整體網路結構不變，只是把每個 2D 操作擴展為 3D：

- 2D 卷積變為 3D 卷積，2D 池化變為 3D 池化。$k \times k$ 的濾波器在時間、高和寬三個維度上變為 $k \times k \times k$。
- 時間步長和池化參數經過設置，使時間感受野隨深度逐漸增大，節奏與空間感受野的增大保持一致。

### 從 2D 濾波器初始化 3D 濾波器

目標是從預訓練好的 2D 網路初始化 3D 網路，使兩者在同一張靜止圖像及其重複構成的靜態影片上給出相同的輸出。

檢驗方法如下。把一張圖像沿時間軸重複，得到每一幀都相同的靜態影片。在原圖上運行 2D 網路，在這個靜態影片上運行膨脹後的 3D 網路。正確的初始化應當讓兩者的輸出一致。

具體做法是把每個 2D 濾波器沿時間軸重複 $N$ 次（$N$ 是膨脹後濾波器的時間尺寸），再把權重除以 $N$。這個除法很關鍵：不除的話，$N$ 個副本會把 $N$ 個相同的響應加起來，輸出會變成 2D 結果的 $N$ 倍。除以 $N$ 之後，3D 網路正好從 2D 網路結束的位置起步，再在 Kinetics 訓練中學習時序結構。

## 實驗結果簡述

在 Kinetics 上預訓練、再在小基準上微調之後，論文報道的雙流 I3D 在 UCF-101 上達到約 98.0% 的準確率，在 HMDB-51 上達到約 80.9%，明顯高於從頭訓練的同類結構。這個提升印證了論文的觀點：影片模型和圖像模型一樣，都極大受益於自身模態下的大規模預訓練。
