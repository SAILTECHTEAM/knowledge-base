# 只看一次（WOO）

**論文：** Shoufa Chen et al., Watch Only Once: An End-to-End Video Action Detection Framework, ICCV 2021.

**論文連結：** https://openaccess.thecvf.com/content/ICCV2021/papers/Chen_Watch_Only_Once_An_End-to-End_Video_Action_Detection_Framework_ICCV_2021_paper.pdf

**程式碼：** https://github.com/ShoufaChen/WOO

![WOO 的統一流程：一條主幹網路同時給出檢測框和動作標籤](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image1.png)

## WOO 的核心思想

WOO 用一個網路把影片片段看一遍，同時輸出其中每個人的檢測框和動作類別。測試時不需要單獨的人體檢測器，也不需要非極大值抑制之類的後處理。

## 問題背景

### 摘要

> 我們提出了名為 Watch Only Once（WOO）的端到端影片動作檢測流程。當時的方法要麼把動作檢測拆成定位和分類兩個獨立階段，要麼在一個階段裡訓練兩個獨立模型。相比之下，我們的方法在一個統一網路裡同時解決定位和分類。通過統一主幹網路並去掉大量手工設計的組件，整個流程大為簡化。WOO 用一條影片主幹網路同時提取定位和分類所需的特徵。另外，我們在框架裡引入了時空動作嵌入，並設計了時空融合模組，得到更豐富、更易區分的特徵，進一步提高了分類效果。在 AVA 和 JHMDB 上的大量實驗證明，WOO 達到了當時的最好效果，同時比已有方法最多節省 16.7% 的 GFLOPs。

- **FLOPs** 表示一次前向推理需要的浮點運算次數。
- **GFLOPs** 等於 $10^9$ 次浮點運算。數值越大，計算越重，推理越慢。

### 影片檢測包含兩個子任務

影片動作檢測要同時回答兩個問題：每個人在哪裡，每個人在做什麼。定位一般看單幀就夠了，判斷動作則需要多幀的運動資訊。這個不一致是主要的難點。

### 論文中對比的傳統方法

![雙主幹的動作檢測流程與統一的 WOO 流程之對比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image2.png)

YOWO 屬於訓練階段統一、主幹仍然分開的做法。它還是用一個 2D CNN 做檢測，用一個 3D CNN 做動作建模，特徵要從原始像素裡提取兩次。WOO 認為這種設計實際上還是兩個模型，目標是用一條主幹、一次前向傳播完成兩個任務。

### WOO 的創新

WOO 讓兩個檢測頭共用一條影片主幹網路。同一個片段只看一遍，網路同時給出定位和分類的輸出。

## WOO 的結構

:::info[三個組件]
WOO 由統一的主幹網路、時空動作嵌入，以及分類頭內部的時空融合模組組成。
:::

### 統一的主幹網路

一條主幹網路同時承載時間和空間資訊。關鍵設計是把關鍵幀特徵很早分離出來，這樣檢測分支保留乾淨的空間細節，分類分支保留完整的時間上下文。

![分開的 2D 加 3D 主幹，與帶關鍵幀早期分離的統一主幹之對比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image3.png)

在傳統的分開設計裡，2D 檢測器處理關鍵幀，3D 網路處理整個片段。3D 分支的最後一個階段常用空洞卷積（記作 DC5），在擴大感受野的同時保持空間解析度。WOO 去掉了這種空洞卷積，因為它解決不了更深層的問題：網路越深，時間卷積越是把相鄰幀混入關鍵幀，檢測需要的空間細節就被抹掉了。

於是 WOO 很早就把關鍵幀分離出來。形式上記

$$X \in \mathbb{R}^{C \times T \times H \times W}$$

為某一層的時空特徵圖，其中 $C$ 是通道數，$T$ 是時間長度。關鍵幀放在片段中間，記

$$X_t = X[T/2] \in \mathbb{R}^{C \times H \times W}$$

為關鍵幀特徵圖。

一個輕量的特徵金字塔網路從早期階段（res2 到 res5）取出關鍵幀特徵，組成多尺度空間特徵，送給定位頭。完整的片段特徵則繼續往上走，到最後一個階段送給分類頭。檢測分支用一個小金字塔代替了原來單獨的 2D 主幹網路，參數量和計算量的節省主要來自這裡。

### 時空動作嵌入

動作分類比定位更難。作者發現統一網路定位效果不錯，分類效果仍然受限，猜測是同一條主幹同時服務兩個任務時偏向了定位。為了加強分類，他們加了一個專用分支，包含空間和時間兩組動作嵌入，以及人物之間的互動步驟。

> 論文原文：「我們發現統一結構在定位上表現不錯，但動作分類仍然受限。因此我們猜測，同一條主幹同時服務兩個任務時，會偏向定位任務，從而影響分類效果。」

### 時空融合模組

融合模組放在分類頭內部。它把形狀、姿態一類的空間線索，和運動、持續時間一類的時間線索結合起來，生成最終用於分類的特徵。

### 動作人定位頭

- 這個檢測頭借鑒了 Sparse R-CNN，一種不需要手工錨框、測試時不需要抑制的端到端檢測器。
- 輸入是關鍵幀的多尺度金字塔特徵，輸出是固定數量的檢測框和置信度分數。
- 訓練使用集合預測損失加二分匹配，每個真實的人只匹配一個預測框。測試時直接使用預測的集合，不再做後處理。
- 檢測和分類共用主幹網路，所以不需要單獨預訓練一個檢測器。

集合預測的意思是，模型每次預測固定數量的框，匹配器給每個真實框找到最合適的搭檔：

```text
真實框：3 個人
模型輸出：例如 100 個框
匹配：3 個人各自分到恰好 1 個框，
  剩下的框都算作背景。
```

### 動作分類頭

![RoIAlign 把人物特徵裁出並分成空間和時間兩條分支](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image7.png)

對每個檢測到的人，RoIAlign 從最後一個階段的片段特徵裡裁出這個人所在的區域，並歸一化到固定的空間尺寸。裁出的特徵體再分成兩路：

```text
檢測到的人 -> RoIAlign 裁剪 ->
  空間分支（在時間上池化，保留佈局）和
  時間分支（在空間上池化，保留運動）->
  人物間互動 -> 融合 -> 分類
```

時間分支在空間維度上池化，保留隨時間的變化。空間分支在時間維度上池化，保留結構。兩路直接拼接的結果只作為基線，接下來介紹的嵌入互動用來讓特徵更易區分。

![空間嵌入和時間嵌入之間的人物間互動](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image9.png)

同一個片段裡的人常常互相影響，只看當前一個人的特徵容易產生歧義。互動模組用來刻畫人物之間的關係。對 $N$ 個檢測到的人，論文定義空間嵌入和時間嵌入 $E_s \in \mathbb{R}^{N \times d}$ 和 $E_t \in \mathbb{R}^{N \times d}$，經過線性層得到查詢、鍵和值，再計算人物之間的注意力分數。分數在 softmax 之前除以 $\frac{QK^{T}}{\sqrt{d}}$ 做縮放，以免維度很大時梯度飽和。互動後的嵌入再用 $1 \times 1$ 卷積投影回去，和人物特徵融合。

### 嵌入

為了節省計算，注意力只在輕量的人物嵌入之間進行，而不在完整的特徵圖之間進行。

> 論文原文：「嵌入比特徵圖輕得多，出於效率考慮，我們在嵌入之間而不是在特徵圖之間使用注意力機制。」

換句話說，關係建模始終留在緊湊的嵌入空間裡，只有得到的關係信號才寫回高維特徵。

:::caution[論文沒有寫清的地方]
論文只說 $N$ 個人物特徵各有自己的嵌入，沒有畫出這些嵌入的具體初始化方式。上面的描述依據論文的公式和文字，超出部分屬於解讀，不是論文原話。
:::

### 關於注意力的一點補充說明

注意力幫助模型決定突出什麼。權重越大，對輸出的影響越大。

CBAM 一類的通道注意力問的是，一張特徵圖裡哪些通道和區域更重要，不區分不同的人。WOO 一類的人物間注意力問的是，每個人應當參考其他人到什麼程度。後者是 transformer 式的、作用在人物上的注意力，形式上接近 token 之間的自注意力。
