# RT-DETR：延迟预算与算子约束（RT-DETR 与 RT-DETRv2）

在前面九篇的演进脉络中，DETR 体系的技术演变主要围绕一条**精度与训练收敛**的约束链展开：从解决全局密集注意力与多尺度计算开销（[Deformable DETR：稀疏采样与多尺度注意力](./deformable-detr)），到显式建立四维几何锚框以消除定位冷启动（[Conditional 与 DAB-DETR：查询空间化](./conditional-dab-detr)）；从去噪旁路抑制早期匹配震荡（[DN-DETR：查询去噪与早期匹配稳定化](./dn-detr)、[DINO：三处接口的联合设计](./dino)），再到训练期通过查询分组（[Group DETR：训练期查询分组](./group-detr)）与目标合成（[DEIM：密集匹配与匹配质量约束](./deim)）扩充正样本监督密度。

然而，所有上述改进在优化目标上存在一个共同的潜台词：**用更少或固定的训练轮数，换取更高的检测精度（AP）**。当模型被推向工业落地场景时，评估准则发生了本质切换——系统的核心目标函数从“训练多少轮收敛”变成了**“在硬件给定的毫秒级延迟预算内，模型能输出多高的 AP”**。

在实时目标检测（Real-Time Object Detection）领域，以 YOLO 体系为代表的卷积检测器长期占据主导地位。DETR 架构虽然在理论上具备“端到端集合预测、天然无需非极大值抑制（NMS）后处理”的结构优势，但在端到端推理速度上却长期处于严重劣势。

本篇聚焦于 **RT-DETR（Zhao 等人，CVPR 2024）** 与其后续技术更新 **RT-DETRv2（Lv 等人，2024）**。我们将深入物理硬件的前向计算图与算子执行层面，剖析传统 DETR 架构在推理延迟上的三处核心物理瓶颈，并解析作者团队如何通过重塑编码器计算分配、对齐初始查询质量、重构采样算子与精简训练配方，构建出工业级实时的端到端检测体系。

![RT-DETR 与 RT-DETRv2 在 T4 GPU 上的速度与精度边界对比](/img/cv_img/detr-series/rtdetr_speed_ap_curve.png)

## 研究动机：评测基准对齐与非实时 DETR 的三重延迟瓶颈

### 评估口径建立：TensorRT FP16 下包含 NMS 的端到端纪律

要讨论实时检测，必须首先统一度量衡。在以往学术论文的对比中，存在着广泛的口径不对齐现象：

1. **输入分辨率不对齐：** 传统 DETR 模型习惯使用 $(800, 1333)$ 的大分辨率输入以追求高 AP，而实时检测器普遍以 $640 \times 640$ 为标准测试基准；
2. **后处理耗时被刻意剔除：** 许多卷积检测器在汇报 FPS 时，仅统计网络骨干与预测头的前向时间，将 CPU 或 CUDA 上的 NMS 后处理耗时剔除在外。

RT-DETR 作者团队在建立基准时明确了严格的测试纪律：**在 NVIDIA Tesla T4 GPU 上，采用 TensorRT FP16 引擎，输入尺寸固定为 $640 \times 640$，batch size 设为 1，且测试耗时必须包含端到端完整链路。**

当这一标准被确立后，作者通过实测指出了一个长期存在的误区：**“DETR 没有 NMS，所以推理更快”这一论断在工程实践中并不能天然成立**。在 $640 \times 640$ 输入下，调优后的高效 NMS 算子（如 TensorRT 的 `EfficientNMS`）在常规场景下的执行时间通常仅占 $1.0 \sim 2.5\text{ ms}$。相比之下，传统 DETR 网络自身的模型前向耗时（如 DINO-Deformable-DETR-R50 耗时高达数十甚至上百毫秒，仅能达到 5 FPS 左右）才是阻碍其实时化的绝对主因。

要让 DETR 真正跑进实时区间，必须拆解模型前向计算图中吃掉计算时间和硬件带宽的具体瓶颈。

### 瓶颈解剖：编码器序列爆炸、解码器深度锁死与插值算子访存死穴

结合硬件 Profiler 分析，非实时 DETR 模型的推理延迟瓶颈精准分布在三个物理环节：

| 推理瓶颈位置 | 物理现象与性能损耗 | 结构层面的诱因 | RT-DETR / v2 改进切入点 |
| :--- | :--- | :--- | :--- |
| **1. 编码器：高分辨率特征处理冗余** | 编码器占全模型 **49% 的 GFLOPs**，却仅贡献 11% AP；多尺度序列长达数千，多层自注意力造成严重计算与访存拥堵。 | 尺度内全局交互（Intra-scale）与跨尺度特征融合（Cross-scale）混在一起全盘计算；浅层低语义 token 盲目参与密集自注意力。 | **高效混合编码器（AIFI + CCFM）**: 自注意力仅保留在最高语义层 $S_5$；浅层交互全盘交由卷积。 |
| **2. 解码器：6 层串行精修的延迟下限** | 解码器逐层串行执行，每层稳定消耗约 $0.5\text{ ms}$；无法压缩层数，直接砍减解码层会导致 AP 断崖式下跌。 | 查询初始化仅依赖分类分数，选出大量“分类虚高、几何极差”的低质候选，逼迫解码器必须依赖多层堆叠逐步纠偏。 | **IoU-aware Query Selection**: 优化目标引入 IoU 软标签对齐分类与几何，前移定位负担，使解码层数成为**免训练速度旋钮**。 |
| **3. 底层算子：非规则访存与部署死穴** | Deformable Attention 纸面 FLOPs 虽低，但实测跑不快；底层 `grid_sample` 算子在专用推理引擎与嵌入式 NPU 上严重受阻。 | 依赖浮点偏移量的双线性插值，属于非规则内存跳跃访问；缺乏通用算子融合支持，定点量化困难。 | **离散采样算子（`discrete_sample`）**:将浮点偏移取整为整型索引，消除插值开销，解决硬件部署壁垒。 |

## 架构机制：高效混合编码器解耦尺度内与跨尺度交互

### 结构演进消融：从全尺度多尺度注意力到尺度内局部交互

在 Deformable DETR 及其后继者（如 DINO）中，为了检测不同尺度的物体，骨干网络输出的 $\{S_3, S_4, S_5\}$ 特征图被拉平并拼接为一个长序列送入多尺度 Transformer 编码器。在 $640 \times 640$ 的输入下，各尺度的空间尺寸分别为：

- $S_3$（步长 8）：$80 \times 80 = 6400$ 个 token
- $S_4$（步长 16）：$40 \times 40 = 1600$ 个 token
- $S_5$（步长 32）：$20 \times 20 = 400$ 个 token

三者拼接后，序列总长度高达 $8400$。即使单层可变形注意力的理论复杂度降低为局部采样点数的线性函数，其高分辨率特征的自注意力映射、采样点坐标预测与特征聚合所涉及的内存搬运量（Memory Access Cost, MAC）依然极其庞大。

RT-DETR 论文设计了一组严格递进的编码器架构变体（Variants A 至 E），系统性地剥离了编码器中的冗余计算：

![编码器变体演化路径](/img/cv_img/detr-series/rtdetr_variants.png)

结合论文在 T4 GPU 上的消融数据，这一演进揭示了关键的物理规律：

| 变体代号 | 编码器结构设计 | AP (%) | 延迟 (ms) | 实验结论与机制归因 |
| :--- | :--- | :--- | :--- | :--- |
| **Variant A** | 完全移除 Transformer 编码器 | 43.0 | 7.2 | 失去编码器特征增强，基线性能偏低。 |
| **Variant B** | 引入共享单层自注意力，各尺度独立做尺度内交互 | 44.9 | 11.1 | 尺度内交互带来 +1.9 AP 提升，但序列处理使延迟暴增 54%。 |
| **Variant C** | 将多尺度拼接后直接做全尺度交互 | 45.6 | 13.3 | 跨尺度融合进一步带来 +0.7 AP，但多尺度全量注意力使延迟升至 13.3 ms。 |
| **Variant D** | **显式解耦**：先做尺度内自注意力，再用 PANet 卷积结构做跨尺度融合 | 46.4 | 12.2 | **解耦带来双赢**：AP 提升 0.8%，延迟反倒下降 8%。 |
| **Variant $D_{S_5}$** | **仅在最高层 $S_5$ 上保留尺度内自注意力**，其余尺度直接进入卷积融合 | 46.8 | **7.9** | **突破性拐点**：延迟暴降 35%（从 12.2 ms 降至 7.9 ms），AP 反而提升 0.4%！ |
| **Variant E (RT-DETR)** | 在 $D_{S_5}$ 基础上精细设计 RepBlock 融合块（即完整混合编码器） | **47.9** | 9.3 | 引入局部重参数化卷积，以合理延迟代价推高特征表征能力。 |

### 交互分工机制：S5 实体概念建模与浅层局部卷积聚合

Variant $D_{S_5}$ 的测试结果构成了 RT-DETR 编码器设计的核心理论依据：**为什么把浅层特征（$S_3, S_4$）上的自注意力全部砍掉，网络延迟大幅下降，检测精度反而不降反升？**

这源于深度卷积特征的固有层级属性：

1. **语义抽象度的差异：** 浅层特征图（如 $S_3$）的分辨率高，其内部 token 主要承载局部的低级几何纹理、边缘信息。这些 token 缺乏清晰的高层语义概念。让浅层的数千个 token 之间执行跨空间全局注意力，不仅计算代价呈二次方增长，而且极易在局部纹理与不相关背景之间引入大量虚假的高频注意力关联；
2. **高层特征承载概念实体：** 相比之下，最高层特征 $S_5$ 经过多次下采样，空间分辨率仅为 $20 \times 20 = 400$。此时每个 token 的感受野已覆盖全图大部分区域，表征的是高度抽象的实体语义概念。在这 400 个 token 之间执行自注意力，既能高效建模不同目标之间的全局共存关系与上下文约束，计算耗时又极低；
3. **跨尺度传递依赖局部卷积更高效：** 跨尺度的语义补充（如高层语义指导浅层定位，浅层细节回传高层）在本质上属于空间局部的特征复用。采用硬件高度优化、访存连续且具备局部归纳偏置的卷积神经网络（如类似 PANet 的自顶向下与自底向上融合路径）来完成跨尺度融合，在硬件执行效率上远胜于注意力算子。

基于此，RT-DETR 确立了**高效混合编码器（Hybrid Encoder）**的双模块架构：

- **AIFI（Attention-based Intra-scale Feature Interaction）：** 仅对 $S_5$ 特征执行单层标准多头自注意力（MHSA），输入输出维度保持一致；
- **CCFM（CNN-based Cross-scale Feature-fusion Module）：** 以卷积为基本单元，结合重参数化卷积块（RepBlock）和跳跃连接，完成 $\{S_3, S_4, F_5\}$ 之间的多尺度双向融合（详细张量流转推导见附录 A）。

## 机制重构：IoU 感知查询选择化解分类与定位脱节

### 缺陷定位：单纯依据分类置信度挑选候选框的分布失配

在 [DINO：三处接口的联合设计](./dino) 中，混合查询选择（Mixed Query Selection）确立了“从编码器顶层选出 Top-$K$ 个提案框来初始化解码器 4D 锚框”的有效范式。然而，在 DINO 乃至此前的所有 DETR 模型中，筛选这 Top-$K$ 个特征的标准，**完全取决于分类头的预测置信度（Classification Score）**。

RT-DETR 论文在分析检测头输出时指出：**分类预测得分与真实边界框定位质量（IoU）之间存在严重的分布不对齐（Inconsistent Distribution）**。

![分类分数与 IoU 分数分布散点图](/img/cv_img/detr-series/rtdetr_iou_aware.png)

观察散点图可以清晰地看到两种现象：

1. **分类虚高但几何极烂（图右下方密集的粉色点）：** 某些特征 token 的分类分数高达 0.8，但其预测边界框与真实目标的 IoU 甚至低于 0.1。这是因为分类头关注的是“是否存在显著的前景局部纹理”，而该纹理对应的回归框可能完全没有找准目标边界；
2. **定位精准但分类过低：** 许多在几何上与真实目标高度吻合（IoU $>0.8$）的特征，由于处于物体的非中心区域，分类得分偏低，在 Top-$K$ 排序中直接被遗弃。

这一脱节导致解码器在第 1 层接收到的初始锚框中，充斥着大量空间偏差极大的候选。解码器不得不依靠深度堆叠的 Cross-Attention 层，一层一层强行纠正这些偏航的锚框。

### 机制重构：将真实 IoU 作为目标值注入分类分支软损失

为了让编码器输出的 Top-$K$ 提案同时兼顾分类确定性与几何精度，RT-DETR 提出了 **IoU-aware Query Selection**。

该机制的核心是修改训练期针对编码器特征的分类分支优化目标，显式将预测框与真实框之间的交并比（IoU）作为连续的软标签注入监督损失中：

$$
\mathcal{L}_{\text{encoder}}(\hat{y}, y) = \mathcal{L}_{\text{box}}(\hat{b}, b) + \mathcal{L}_{\text{cls}}(\hat{c}, c, \text{IoU})
$$

在此之前，正样本的分类监督目标是一个确定性的 one-hot 标量（$c \in \{0, 1\}$）。而在 IoU-aware 监督下，当预测框 $\hat{b}$ 与真实框 $b$ 的重合度较低时，即便该特征正确命中了物体类别，分类损失也会因为目标值被缩放为真实的 $\text{IoU}$ 数值而产生惩罚；唯有当**类别预测正确且边界框高度贴合真实目标**时，分类分支才能获得满额奖励（具体数学损失公式见附录 B）。

### 验证证据：高置信高重合 Query 比例翻倍与零开销精度收益

这种一致性约束迫使编码器在特征空间中自主建立特征的综合可信度。在图 4 的散点图中，深蓝色的点（引入 IoU 感知约束）呈现出向右上角明显收拢的趋势：

- **高分类且高 IoU（双指标 $>0.5$）的优质 Query 占比：** 从传统机制的 **0.30% 暴增至 0.67%**（相对增幅达 120%）；
- **全模型最终精度收益：** 在 COCO val2017 上直接获得了 **+0.8% AP** 的纯算法增益，而这一机制在推理阶段完全没有引入任何额外的浮点运算或网络结构。

## 落地机制：定位负担前移与免重训弹性解码器

### 收益递减规律：初始 Query 质量提升带来的深层精修饱和

在传统检测器中，如果要调节推理速度，通常必须重新设计不同深度与宽度的骨干网络（如从 YOLOv8-N 换到 YOLOv8-X），每次切换都必须经历完整的训练流程。而在 DETR 体系中，解码器各层在训练期均挂载了独立的辅助预测头，并共享统一的输出空间。

由于引入了高质量的混合编码器特征与 IoU-aware Query Selection，**解码器从第 1 层开始就已经获得了极具置信度的空间寻址起点**。传统 DETR 中必须依靠前 3 层解码器完成的“粗略定位搜寻”负担，被实质性地转移到了单层 AIFI 编码器与前置筛选机制中。

这一转移直接改变了逐层解码器的收益曲线。RT-DETR 论文对 6 层解码器在推理阶段的表现进行了逐层消融：

| 推理使用的解码层截断 | AP (%) | 相比满层精度损失 | 推理总延迟 (ms) | 节省耗时 (ms) |
| :--- | :--- | :--- | :--- | :--- |
| **Layer 6 (满层基线)** | **53.1** | - | 9.3 | - |
| **Layer 5** | 53.0 | $\downarrow 0.1$ | 8.8 | $\mathbf{0.5}$ |
| **Layer 4** | 52.7 | $\downarrow 0.4$ | 8.3 | $\mathbf{1.0}$ |
| **Layer 3** | 52.4 | $\downarrow 0.7$ | 7.9 | $\mathbf{1.4}$ |
| **Layer 2** | 51.3 | $\downarrow 1.8$ | 7.5 | $\mathbf{1.8}$ |
| **Layer 1** | 49.1 | $\downarrow 4.0$ | 7.0 | $\mathbf{2.3}$ |

### 部署落地：运行时按需截断解码层数的动态换挡机制

从消融数据中可以提炼出两个关键工程结论：

1. **解码层时间消耗的线性确定性：** 在 T4 硬件上，Transformer 解码器每串行执行一层，耗时极其稳定地增加约 **0.5 ms**；
2. **高层解码的边际效应剧烈递减：** 随着层数加深，相邻两层之间的精修收益迅速收敛。从第 6 层回退到第 5 层，仅仅产生 0.1% AP 的统计波动，却能稳定释放出 0.5 ms 的计算时间。

这意味着在实际工程落地时，**使用者无需对模型进行任何重新训练或权重导出重构**。训练好的 6 层模型权重可以直接部署；在面对高吞吐突发流量或边缘轻量硬件时，推理运行时只需直接读取第 4 层或第 5 层辅助预测头的张量输出，并跳过后续注意力层的计算图前向，即可实现连续、平滑的“精度-延迟”动态换挡。

## 算子重构：离散采样消除连续网格插值的访存与部署死穴

如果说 RT-DETR v1 攻克了模型计算架构层面的 FLOPs 分配，那么一年后发布的 **RT-DETRv2** 则直接将刀刃切向了工程落地的底层暗礁——**硬件算子兼容性与物理内存访问瓶颈**。

### 算子瓶颈：连续双线性插值引发的非规则访存与硬件部署受阻

在学术研究中，可变形注意力（Deformable Attention）通常被视为一种高效的稀疏算子。网络通过线性层预测出浮点型的相对偏移量 $(\Delta x, \Delta y)$，然后利用双线性插值（Bilinear Interpolation，在 PyTorch 中通过 `torch.nn.functional.grid_sample` 或自定义 CUDA 算子实现）从特征图上连续采样。

然而，在工业界部署端（尤其是将 ONNX 导出为 TensorRT、OpenVINO，或部署到边缘嵌入式 NPU 芯片如瑞芯微 RKNN、地平线 BPU、昇腾 CANN 等场景）中，`grid_sample` 算子带来了极其棘手的工程灾难：

1. **显存访问不连续（Memory-Bound）：** 浮点偏移量导致采样点在物理显存地址中呈非规则跳跃分布，GPU L1/L2 缓存命中率极低，导致虽然其算术计算量（FLOPs）远小于常规卷积，但在芯片上的实际执行耗时居高不下；
2. **硬件算子库支持碎片化：** 大多数边缘 NPU 芯片对卷积算子具备极致的硬件硬化加速支持，但对带有双线性插值的动态网格采样算子缺乏硬件原生单元支持，常常被迫回退（Fallback）至通用 CPU 软解执行，导致整个流水线延迟瞬间崩塌；
3. **定点量化困难：** 连续插值计算在 INT8 对称/非对称量化时极易出现数值溢出与分布漂移，导致量化后精度断崖式下降。

### 离散整型采样：坐标取整与微调阶段截断偏移梯度的工程折中

针对这一痛点，RT-DETRv2 做出了一个极为果断的工程简化：**彻底抛弃双线性插值，引入离散采样算子（Discrete Sampling）**。

其计算逻辑非常直白：对预测头输出的连续相对偏移量进行四舍五入取整（Rounding），将其强制约束为整数像素索引：

$$
(\Delta x_{\text{int}}, \Delta y_{\text{int}}) = \text{Round}(\Delta x, \Delta y)
$$

采样过程直接从特征图对应整数坐标内存单元读取数值，完全跳过双线性插值的加权计算。

:::info[问题]

**取整操作不可微，反向传播的梯度如何更新偏移量预测头？**

取整函数的导数在实数域内处处为零，直接端到端训练会导致预测偏移量的线性层完全无法获取梯度。

RT-DETRv2 采取了一种实用的**两阶段训练方案**：

1. **全量预训练阶段：** 在前 72 个 epoch 中，模型依然沿用原版的 `grid_sample` 进行标准训练，让网络在连续空间内充分学习到物体周围的最佳采样几何拓扑；
2. **微调截断阶段：** 在最后 12 个 epoch（1x 配置）微调时，将算子替换为 `discrete_sample`，同时**直接切断偏移量预测线性层的梯度反向传播（Turn off gradient）**，仅允许分类头、内容注意力及其他主干参数根据离散特征进行参数自适应微调。

:::

测试表明，将连续采样替换为离散采样后，模型在最严苛的 COCO $\text{AP}_{\text{val}}$ 上仅产生极其轻微的精度回撤（各尺寸模型普遍仅下跌 $0.1 \sim 0.4\%$），在 $\text{AP}_{50}$ 上几乎完全没有损失，却彻底消除了依赖专用算子的部署壁垒。

### 采样预算重分配：高低分辨率非均匀采样与 75% 采样点削减

Deformable DETR 从初代沿袭下来的另一个隐含设定是：**在每一个特征尺度上分配完全相同数量的采样点（默认每头每尺度采 4 个点）**。

RT-DETRv2 指出，高分辨率特征与低分辨率特征在信息冗余度上存在巨大差异，强求均匀采样造成了不必要的显存带宽开销。通过在解码器中对不同尺度设置差异化的采样点数，作者将单次前向的总采样点数从基线的 86,400 点压缩到 21,600 点（缩减 75%），模型在 COCO 上的 AP 仅出现微小的 0.6% 下降，却在底层显著释放了内存访问带宽。

## 证据与归因：端到端速度精度对比与小模型欠拟合真相

除了结构与算子层面的修补，RT-DETRv2 还在训练配方上做出了两项关键调整，并在小型模型上取得了显著的增益：

### 动态数据增强：训练尾期停用几何与色彩强扰动

在单阶段检测器（如 YOLOv5、YOLOv8）的工程实践中，通常会在训练尾声关闭复杂的马赛克（Mosaic）与混合（Mixup）增强，以使网络权重适应当真实分布下的目标无畸变形态。

RT-DETRv2 将这一策略系统化引入 DETR 体系：

- **前周期强增强：** 在训练前段保持包含颜色畸变（RandomPhotometricDistort）、大范围缩放（RandomZoomOut）与随机裁剪（RandomIoUCrop）的高强度几何扰动，提升表征泛化性；
- **末两轮动态关闭：** 在最后 2 个 epoch 中，全面关闭上述四项强扰动，直接使用未畸变的原图尺度输入进行微调，帮助预测头与初始 Query 快速拟合目标领域的真实长宽比与纹理先验。

### 骨干学习率分级：针对不同模型容量的优化步长适配

在初代 RT-DETR 中，所有不同体量的模型（从轻量的 ResNet18 到庞大的 ResNet101）均采用完全相同的学习率超参数。v2 针对模型规模重新对齐了骨干学习率：

- 轻量级骨干（如 ResNet18）：特征提取能力天然较弱，预训练特征向检测任务迁移时需要更激进的更新步长，作者将其骨干学习率放大到 `1e-4`；
- 重量级骨干（如 ResNet101）：本身具备极高的数据拟合与表征能力，若采用大步长极易破坏预训练权重，其骨干学习率被严格压制至 `1e-6`。

### 收益归因：轻量化小模型的欠拟合修复与大模型增益收敛

观察 RT-DETR 与 RT-DETRv2 在不同模型规模下的精度跃迁（见下表），我们可以清晰地辨识出该训练配方的收益边界：

| 模型规格 | 骨干网络 | RT-DETR AP (%) | RT-DETRv2 AP (%) | 净提升绝对值 |
| :--- | :--- | :--- | :--- | :--- |
| **S 尺寸** | ResNet18 | 46.5 | **47.9** | **$\mathbf{+1.4}$** |
| **M 尺寸** | ResNet34 | 48.9 | **49.9** | **$\mathbf{+1.0}$** |
| **M\* 尺寸** | ResNet50 | 51.3 | **51.9** | $\mathbf{+0.6}$ |
| **L 尺寸** | ResNet50 | 53.1 | **53.4** | $\mathbf{+0.3}$ |
| **X 尺寸** | ResNet101 | 54.3 | **54.3** | **$\mathbf{+0.0}$** |

从 S 到 X 规格，增益呈现出从 $+1.4\%$ 一路收窄至 $+0.0\%$ 的单调递减趋势。

这一数据揭示了一个被工程报告通常掩盖的事实：**动态数据增强与分级学习率的引入，并不是带来了一种超越网络能力上限的普适性突破，其本质是在修补轻量化小模型在短周期训练下的欠拟合（Underfitting）缺陷**。对于参数充沛的 X 规格大模型，网络容量本身已经足够消化复杂的扰动分布，调整配方并不能进一步推高模型的精度天花板。

## 局限与启发：实时化取舍的代价边界与未闭环证据

RT-DETR 与 RT-DETRv2 在实时检测领域确立了新的标杆，但作为技术分析，我们必须客观看清其实时性背后的妥协与尚未解决的技术边界：

### 浅层注意力剥离对密集小目标的上下文损失

将浅层特征（$S_3, S_4$）上的自注意力彻底移除，虽然大幅消除了计算冗余，但在几何机理上也放弃了高分辨率特征上的全图长程关联建模。在极端密集的超小目标群（如微小无人机视角下的稠密人群）或极端长宽比物体的检测中，完全依赖局部卷积的 CCFM 在上下文感知范围上依然存在物理局限。

### 离散采样算子物理加速数据的证据缺口

虽然 RT-DETRv2 提出了离散采样算子，但在论文中，**作者仅展示了离散化之后精度的轻微波动（Table 4），却并未给出在具体 TensorRT 或 NPU 硬件上的实际延迟加速对比数据**。在缺少精确硬件 Profile 数据的支撑下，“彻底解除部署约束”更多是一项架构定性论断，使用者在迁移至特定嵌入式平台时，仍需逐芯片单独验证离散采样带来的实际吞吐改善。

### 多项工程技巧联合消融时的边际贡献未解耦

在 RT-DETRv2 的性能报告中，Table 2 的综合涨幅是动态数据增强、分级学习率、采样点缩减等多项改动共同作用的结果。论文并未对每一项独立改动给出严格的单变量消融拆账，这使得使用者难以精准剥离某一项独立技巧的边际贡献。

### 附录 A：混合编码器的数据流转与计算图

输入为骨干网络最后三个阶段输出的多尺度特征图 $\{S_3, S_4, S_5\}$。

1. **AIFI 处理高层特征：**
   高层特征 $S_5 \in \mathbb{R}^{B \times C \times H_5 \times W_5}$ 首先经过空间展平并转置为序列格式：
   $$
   \mathbf{X}_5 = \text{Flatten}(S_5) \in \mathbb{R}^{B \times (H_5 W_5) \times C}
   $$
   在 $\mathbf{X}_5$ 上施加标准单层多头自注意力（MHSA）与前馈网络（FFN）：
   $$
   \mathbf{F}_5 = \text{Reshape}\Big(\text{FFN}\big(\text{MHSA}(\mathbf{X}_5, \mathbf{X}_5, \mathbf{X}_5) + \mathbf{X}_5\big)\Big) \in \mathbb{R}^{B \times C \times H_5 \times W_5}
   $$

2. **CCFM 双向跨尺度融合：**
   - **自顶向下聚合（Top-down）：**
     高层特征 $\mathbf{F}_5$ 经由 $1 \times 1$ 卷积降维与最近邻上采样后，与 $S_4$ 沿通道拼接，输入 RepBlock（包含多分支可重参数化的 $3 \times 3$ 卷积网络）生成融合中间体；该中间体再次上采样并与 $S_3$ 拼接融合；
   - **自底向上聚合（Bottom-up）：**
     融合后的浅层特征经过下采样卷积步长操作，逐级向上通过跳跃连接与高层特征执行逐元素相加（Element-wise Add）融合；
   - 最终输出为具备统一隐层通道维度的多尺度特征序列 $\{O_3, O_4, O_5\}$，送入解码器与查询选择模块。

### 附录 B：IoU 感知分类损失的数学形式

在传统 Focal Loss 中，二值交叉熵的监督目标 $y \in \{0, 1\}$ 是离散的。在 IoU-aware Query Selection 中，模型为每个编码器特征预测一个类别概率向量 $\hat{c} \in (0, 1)^K$ 与一个边界框 $\hat{b} \in (0, 1)^4$。

对于被分配为正样本的候选特征，其对应的真实类别为 $c^*$，真实几何框为 $b^*$。该样本的几何重合度标量定义为：
$$
\text{IoU}^* = \text{IoU}(\hat{b}, b^*)
$$

正样本在真实类别通道 $c^*$ 上的连续分类监督损失构建为：
$$
\mathcal{L}_{\text{pos}}(\hat{c}_{c^*}, \text{IoU}^*) = -\Big|\text{IoU}^* - \hat{c}_{c^*}\Big|^\gamma \cdot \Big(\text{IoU}^* \log(\hat{c}_{c^*}) + (1 - \text{IoU}^*) \log(1 - \hat{c}_{c^*})\Big)
$$
其中：

- 当预测框与真值完全重合（$\text{IoU}^* \to 1$）时，损失函数退化为标准的硬正样本交叉熵；
- 当预测框完全偏离目标（$\text{IoU}^* \to 0$）时，即便类别判断属于前景，损失函数也会将目标强行下拉至 0，抑制虚高的分类激活；
- 调制系数 $|\text{IoU}^* - \hat{c}_{c^*}|^\gamma$ 动态降低了已经实现分类-定位高度吻合的样本的梯度权重，使模型聚焦于优化两者差异显著的矛盾特征。

对于背景或未匹配上的负样本，监督目标维持标准的硬负样本惩罚：
$$
\mathcal{L}_{\text{neg}}(\hat{c}_k) = -\hat{c}_k^\gamma \log(1 - \hat{c}_k)
$$
