# 目标检测解构（0）：架构拆解与核心部件

在计算机视觉中，目标检测（Object Detection）的核心诉求是在图像中同时完成“定位”（找出物体的边界）与“分类”（识别物体的属性）。这一任务看似直接，但在实际场景中，网络必须面对极端悬殊的尺度跨度、复杂的空间重叠遮挡、以及海量背景噪声的干扰。

经过十数年的演进，目标检测已经分化出两阶段、单阶段、Anchor-based、Anchor-free 以及 Transformer Query 等多种看似迥异的架构流派。然而，如果退回到底层机制，所有检测体系本质上都是由**五个可以独立替换的核心部件**装配而成的系统：

1. **预测载体（Prediction Carrier）**：网络在最底层向外界交出候选预测的基本载体，决定了每一个潜在猜测与图像几何空间如何绑定。
2. **特征采样（Feature Sampling）**：检测头从主干网络提取的空间特征图中提取具体特征表示的操作方式。
3. **Label Assignment（样本匹配）**：在训练阶段将真实标注框指派给特定预测载体的数学协议，决定正负样本的归属，并在推理端直接决定是否需要非极大值抑制（NMS）。
4. **框与类别的编码**：预测头输出数值的物理意义，以及坐标回归与分类判别的具体形式。
5. **多尺度融合**：在骨干网络与检测头之间搭建的特征金字塔管道，负责在不同分辨率与语义深度之间调度信息。

不同的网络体系在这五个核心部件上做出了不同的技术选择，形成了各自独特的行为模式。理解了这五个部件的作用和相互关系，就能看懂一个目标检测网络的设计逻辑，理论上的优缺点和行为偏好。

这是整个系列文章的第 0 篇。本篇的目标是建立一张覆盖主流检测体系的定位坐标图，厘清各个核心部件之间的装配逻辑。整个系列的阅读顺序为：本篇 → [第 1 篇：预测载体](./prediction-carrier) → [第 2 篇：特征采样](./feature-sampling) → [第 3 篇：Label Assignment](./label-assignment) → [第 4 篇：边界框表示与回归损失](./bbox-regression-loss) → [第 5 篇：分类置信度与 Detection Head](./classification-head) → [第 6 篇：多尺度特征与 Neck 架构](./neck-architecture)。

## 四套检测体系的部件装配

为了看清五个核心部件如何具体决定一个检测系统的运作行为，下表列出了四个具有代表性的经典检测体系在各个部件上的具体选择与机制推论：

<div className="wide-table">

| 检测体系 | 预测载体 | 特征采样 | Label Assignment（含 NMS 推论） | 头输出（框表示 / 分类头） | 多尺度融合 | 机制推论 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **YOLOv1** | $S\times S$ 离散空间网格（单尺度，如 $20\times 20$ 网格，每格承载固定数量候选框） | 全连接层全局展平映射（Dense FC Readout） | 目标中心落点几何硬分配（单网格负责单目标，多框竞争；因全图密集网格多重响应，推理依赖 NMS） | 网格内相对偏移归一化坐标 $(x, y, w, h)$ + 全局条件类别概率与框置信度乘积 | 无特征金字塔（仅依赖单张 stride 32 深层特征直接映射） | 空间网格硬绑定导致单网格多目标容量锁死，全连接采样破坏了空间平移不变性，缺乏浅层特征支持导致小目标无法有效召回。 |
| **Faster R-CNN** | 滑动窗口锚框模板（RPN 阶段）与二阶段候选区域（RoI Proposal） | 局部区域特征截取与重采样（RoI Pooling / RoIAlign） | 基于 IoU 阈值的静态一对多重叠匹配；由于同个目标被大量邻近锚框重复激活，推理阶段必须使用 NMS 抑制冗余 | 相对先验锚框的尺度对数偏移变换 $(\Delta x, \Delta y, \Delta w, \Delta h)$ + 独立全连接层 Softmax 类别分布 | 早期无跨尺度融合，后续引入自顶向下单向特征金字塔（FPN） | 二阶段 RoI 采样彻底解耦了局部特征与全图空间，密集锚框带来高召回率但制造了严重的背景负样本冗余，一对多分配决定了必须依赖 NMS 清理重叠框。 |
| **FCOS** | 金字塔多层特征图上的密集像素点（三层金字塔共约 8400 个逐点观测站） | 全卷积密集滑动逐点采样（全图共享卷积核在各空间位置局部提取） | 空间点落入真实边界框内部判定结合多尺度距离分流（一对多分配）；因目标内部大量像素点同时被激活，推理阶段必须依赖 NMS | 四向绝对边界物理距离 $(l, t, r, b)$ + 中心度标量（Centerness）与逐类别二值分类（BCE / Focal Loss） | 自顶向下特征金字塔（FPN）结合跨层最大回归距离硬约束 | 剥离了人工预设的锚框尺寸超参数，将几何回归简化为像素距离测量，多尺度分流化解了空间重叠冲突，但其密集空间绑定与一对多分配依然保留了 NMS 负担。 |
| **DETR** | 固定数量（如 100 或 300 个）全局可学习目标查询向量（Object Queries） | Transformer 解码器跨注意力机制（Cross-Attention）从全图特征中全局寻址采样 | 基于二分图匹配（Hungarian Algorithm）全局最小代价的严格一对一分配；推理端天然不需要 NMS | 整图归一化绝对中心坐标与长宽 $(c_x, c_y, w, h)$ + 包含背景空类别（$\varnothing$）的全局类别分布 | 早期仅使用单层特征展平自注意力，后续演进为多尺度可变形注意力或混合编码结构（AIFI+CCFM） | 预测载体与像素网格彻底解绑，一对一匹配在训练目标函数中从源头杜绝了多重响应，使检测网络首次摆脱了对手工设计 NMS 后处理的依赖。 |

</div>

从这张表中可以看出，每一个具体检测器的特性，并不是某种模糊的风格，而是它在五个核心部件上所做技术选择的联立解。改变其中某一个部件的选择，整个系统的输入输出协议和性能边界就会随之重构。

## 锚框与非极大值抑制不是绑定的概念

在阅读检测文献时，一种常见的误解是将锚框与非极大值抑制（NMS）视为不可分割的孪生结构，甚至推导出无锚框（Anchor-free）就等于摆脱了 NMS 的错误结论。

事实恰恰相反。锚框与 NMS 分属于完全不同的两个部件：锚框是**预测载体**这一部件中的几何参数化模板，用来解决局部空间容量与长宽比例先验的问题；而 NMS 则是**Label Assignment**这一部件在选择了一对多分配协议之后的必然推论。

回顾四套体系的组合便能看清两者的独立性：

- **YOLOv1** 是典型的无锚框设计，它只使用空间网格和无模板的偏移预测，但在推理时依然必须运行 NMS。因为全图相邻的网格在面对同一目标时，依然会在边界处产生多个高分预测框。
- **FCOS** 彻底抛弃了锚框，改用纯粹的特征像素点作为预测载体。然而在 Label Assignment 阶段，只要一个特征点落在真实目标的几何内部，该点就会被标记为正样本。对于中央那名大尺寸行人，其包围盒内部可能包含数百个特征像素点，这意味着网络在训练时命令这数百个点同时对同一个行人发出正向预测。到了推理阶段，这数百个点自然会交出数百个高度重合的检测框，必须依靠 NMS 强行压制，只保留中心得分最高的一个。
- 真正能够移除 NMS 的，是 **DETR** 以及后续的 **YOLOv10**。DETR 通过匈牙利二分图匹配，在损失计算前强制规定：画面中的每一个真实目标，在全网所有候选槽位中只能且必须匹配唯一一个损失最小的槽位，其余槽位一律按背景惩罚。由于网络在训练时就受到了单目标单响应的强约束，推理时各个查询向量之间通过自注意力互相排斥，输出的集合中天然不存在重叠预测。YOLOv10 则是在逐点密集预测的基础上，引入双 Label Assignment 机制，在推理分支采用一对一匹配，同样达成了无 NMS 推理。

:::note[决定 NMS 存废的唯一因素]
决定推理流程中是否存在 NMS 的唯一因素，是 Label Assignment 协议究竟采用了一对多还是一对一。预测载体采用锚框、网格还是像素点，与 NMS 的存废没有直接因果关系。
:::

## 不要把 YOLO 当作脱离体系的独立路线

工业界和部分初学者常将目标检测划分为三条互不相干的流派：二阶段网络、YOLO 系列以及 Transformer 检测器。这种按项目代码库来割裂体系的视角，掩盖了底层机制的演变规律。

YOLO 从来不是一条拥有独立物理法则的技术路线。拆解 YOLO 从初代到最新版本的演变，其本质是在五个基础部件之间进行组合迁移：

- **YOLOv1** 占据的是密集网格预测载体、全局展平特征采样、静态几何分配与无多尺度融合的原始组合。
- **YOLOv2 到 YOLOv7** 整体迁移并深耕于密集锚框预测载体、全卷积局部特征采样、特征金字塔多尺度融合（自顶向下 FPN 与自底向上 PANet 的结合），以及基于 IoU 的动态一对多 Label Assignment（例如 OTA 与 SimOTA）。在这个漫长的阶段中，网络骨干更深、特征融合拓扑更密集、动态正样本分配策略更平滑，但五个部件的根本组合形式始终停留在密集锚框加一对多分配的区间内。
- **YOLOv8 与 YOLOv9** 做出的最核心结构调整，是将预测载体部件中的预设锚框模板剔除，换成了与 FCOS 类似的逐点回归与分布式边界表示（Task-Aligned Assigner 与 DFL 机制）。这一步标志着该系列在预测载体部件上全面转向无锚框。
- **YOLOv10** 则进一步向 Label Assignment 部件动刀，引入一致性双重分配策略，在保留一对多训练引导的同时，让推理分支运行在一对一分配协议下，从而切掉了推理后处理中的 NMS。

## 预测载体的选择决定了检测系统的整体设计

在目标检测系统的各个模块之间，存在明确的依赖关系：**预测载体如何与空间坐标关联，决定了后续特征提取与样本匹配的具体形式。**

如果预测载体与特征图的空间网格直接绑定（无论是基于网格、锚框还是特征点），特征采样就必须采用与之对应的局部窗口卷积，Label Assignment 就需要在空间邻域内按几何规则或动态指标挑选正样本，并处理密集采样带来的背景样本冗余，推理阶段也需要依赖 NMS 抑制重叠检测框；如果预测载体与空间网格解绑，采用目标查询向量（Query），特征采样就需要借助全局注意力机制聚合上下文，Label Assignment 则通过二分图匹配实现一对一预测，从而省去 NMS 后处理。
