# 目标检测解构（5）：分类置信度与 Detection Head

按分类分数从高到低排，分数 $0.95$ 的框常常卡在前面那两个人中间，谁都没套住；远处那块牌的分数可能只有 $0.15$，初筛就被丢掉。

这反映了目标检测预测头长期面对的两大矛盾：在密集的候选空间里，纯背景区域的数量远远压倒真实目标，微弱的目标信号极易被海量简单负样本的累积梯度淹没；而分类分支给出的高置信度分数，根本无法代表这个框在几何定位上到底画得有多准。

预测头（Head）是检测网络中直面损失函数、直接产出预测结果的末梢。它必须在每个候选位置上回答两个问题：这里存在什么类别的物体，以及物体的几何边界究竟在哪里。这两个子任务在底层的表征需求与优化方向上处处存在排斥。

## 为什么分类分数不能当定位质量用

在纯粹的图像分类任务中，模型追求平移不变性。无论一只猫出现在画面的左上角、正中央还是右下角，分类器都希望深层特征能够激活“猫”这一类别的高响应。

但目标检测不仅要识别物体的语义属性，还要输出具体的几何边界框坐标 $[x, y, w, h]$。检测头对空间几何位置具有天然的平移敏感性：只要目标在画面中平移了两个像素，或者预测框向外扩张了三个像素，网络输出的边界坐标偏移量就必须产生相应的数值变化。

当系统直接拿分类分支计算出的得分作为衡量整个检测框优劣的唯一依据时，隐患就此埋下。

回到画面中央那两位重叠的行人。当一个预测框恰好卡在两人中间时，该位置对应的特征感受野同时覆盖了左侧行人的头部轮廓与右侧行人的躯干边缘。对于专门寻找判别性纹理的分类分支而言，这个感受野内部包含了极其浓烈的人体视觉模式。分类卷积层并不关心这些特征究竟属于同一个人还是两个人，只要确认视野内存在大量符合人体特征的结构，就会给出接近 1.0 的极高置信度。

但在空间几何层面，这个预测框与真实标注框之间的交并比（IoU）极其糟糕。它既没有对准左边的行人，也没有包住右边的行人，与两者的交并比甚至都低于 0.3。

相反，在某一位行人的精确边界周围，可能存在另一个预测框，它的四条边严密贴合了行人的身体轮廓，交并比高达 0.9。然而，生成这个框的特征网格恰好位于行人的边缘轮廓或者光照较暗的外衣褶皱处。这里的局部特征缺乏全局的典型性，导致分类分支给它打出的置信度只有 0.45。

在依赖分类分数排序的后处理中，那个交并比只有 0.3 的畸形框会凭借 0.95 的高分排在最前；而交并比高达 0.9 的精准预测框反而会因低分排在末尾，甚至在初筛阶段被直接剔除。

分类头只对局部特征的语义丰富度负责，不对边界框的几何重合度负责。要让检测头正常工作，必须先解决海量背景带来的梯度失衡，再化解分类与定位在特征表示与优化目标上的内在冲突。

## 一千比一的背景淹没：从 Objectness 到 Focal Loss

在一张 $640\times 640$ 的输入图像上，现代密集预测检测头通常会在不同下采样倍率的特征图上铺设预测点。假设网络使用步长为 8、16 和 32 的三层特征图：

- 步长 8 的特征图尺寸为 $80\times 80$，提供 6400 个预测位置；
- 步长 16 的特征图尺寸为 $40\times 40$，提供 1600 个预测位置；
- 步长 32 的特征图尺寸为 $20\times 20$，提供 400 个预测位置。

三层特征图累加在一起，单张图像就会生成 $6400 + 1600 + 400 = 8400$ 个候选网格。

在这 8400 个位置中，真正包含目标的网格极其稀少。街景尽头那块 $16\times 16$ 的小路牌在步长 8 的图上最多只占 $2\times 2$ 共 4 个网格；中央的两个行人加起来也只占据数十个网格。整张图像中能够被划归为正样本的网格通常不足数十个，而剩下的 8300 多个网格全部是纯粹的背景——大片的天空、平整的沥青路面、建筑物的空白墙面。

在密集预测场景中，正负样本的比例极易达到几十比一乃至一千比一以上。

早期的检测器为了应对这种悬殊差距，尝试在类别预测之前引入一个名为 objectness 的独立分支。objectness 的本义是“目标存在性”，它是一个二分类标量，专门评估某个候选区域到底是一块包含物体的区域，还是纯粹的背景。在早期单阶段检测算法中，最终的类别置信度被拆成 $P(\mathrm{Class}_i) = P(\mathrm{Object}) \times P(\mathrm{Class}_i \mid \mathrm{Object})$。第一项由 objectness 分支输出，代表该位置存在物体的先验概率；第二项由类别分支输出，代表在已知存在物体的前提下属于第 $i$ 类的条件概率。

这种拆分在概念上将“有没有”与“是什么”分开了，但并没有从数学底层解决梯度淹没的问题。因为无论是 objectness 还是多分类分支，只要损失函数沿用标准的二值交叉熵（Binary Cross-Entropy），海量背景带来的累积效应就会压垮训练过程。

对于标准的二值交叉熵损失，单个样本的损失和与标签对齐的概率 $p_t$ 写成：

$$
\begin{aligned}
\mathrm{CE}(p, y) &= \begin{cases} -\log(p) & \text{当 } y = 1 \\ -\log(1 - p) & \text{当 } y = 0 \end{cases} \\
p_t &= \begin{cases} p & \text{当 } y = 1 \\ 1 - p & \text{当 } y = 0 \end{cases}
\end{aligned}
$$

其中 $y \in \{0, 1\}$ 是真实标签，$p \in [0, 1]$ 是模型预测该位置为正样本的概率。交叉熵因此可以简写为 $\mathrm{CE}(p_t) = -\log(p_t)$。

在这一公式下审视那 8300 多个背景网格。绝大多数背景区域极易判断，比如大片纯净的蓝天，卷积网络能够轻易给出 $p = 0.01$ 的预测，即 $p_t = 1 - 0.01 = 0.99$。单个简单背景的损失是 $\mathrm{CE}(0.99) = -\log(0.99) \approx 0.010$。单独看这一个数值确实微小。然而，当 8300 个简单负样本同时进行反向传播时，它们所产生的损失累加起来就会达到 $8300 \times 0.01 \approx 83$。

再看街道尽头那块 $16\times 16$ 的小路牌。由于路牌极小、边缘模糊，网络给出的正样本预测概率可能只有 $p = 0.2$（即 $p_t = 0.2$）。这个困难正样本产生的单个损失是 $\mathrm{CE}(0.2) = -\log(0.2) \approx 1.61$。单个难样本的损失虽然比单个易分样本大了上百倍，但在数千个简单背景样本的绝对数量优势面前，负样本累加产生的梯度总和依然占据了统治地位。在反向传播的过程中，优化器的更新方向完全被海量的简单背景推着走，网络参数被不断调整去压低那些早已分类正确的天空与路面，而真正需要模型集中精力攻克的小路牌正样本信号，直接被淹没在背景梯度的噪声海洋里。

为了打破这种数量悬殊带来的干扰，Focal Loss 改变了损失函数的加权机制。它在标准交叉熵的前面增加了一个基于置信度的调制项：

$$
\mathrm{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t)
$$

公式中的 $\gamma \ge 0$ 是论文给定的调制超参数（在通用实践中通常固定取 $\gamma = 2$）。

:::tip[Focal Loss 的调制机制]
调制项通过预测概率 $p_t$ 的高低，动态抑制已经学好的样本贡献的梯度权重。易分样本（如大片天空背景，$p_t = 0.99$）的调制项 $(1 - 0.99)^2 = 0.0001$，原本 0.01 的损失被削弱上万倍，梯度几乎不再更新；难样本（如小路牌，$p_t = 0.2$）的调制项 $(1 - 0.2)^2 = 0.64$，损失被大部分保留。检测头在极端样本失衡下仍能将更新方向集中在少数难分辨的真实目标上。
:::

## 特征冲突：耦合头与解耦头

海量背景带来的梯度失衡被压制之后，检测头内部的物理结构差异成为了影响精度的关键。

早期单阶段检测器普遍采用耦合头（Coupled Head）：来自特征金字塔的特征图直接送入两到三层共享卷积层，随后在末端引出两个并行的 $1\times 1$ 卷积，分别输出类别预测分数与边界框坐标偏移量。

这种结构隐含了一个底层假设：在深层表征中，用于语义分类的特征与用于几何定位的特征是高度重合且完全通用的。

然而在特征分析中，分类与定位对特征表征的需求在本质上是相互排斥的：

1. **分类任务要求语义抽象与平移不变性**。分类分支希望卷积核忽略空间上的微小扰动，专注于提取人脸、肩膀、躯干等高阶语义。即便部件在特征图上轻微平移，分类分支也希望深层特征保持稳定的强激活。
2. **定位任务要求空间精细与平移敏感性**。边界回归分支需要极其精确地确定目标外围边缘所在的绝对坐标。它唯一关心的是物体的边缘轮廓在哪一个像素点发生阶跃。如果特征图过度平滑并抹去了高频空间细节，回归分支就无法确定边缘的精确截断位置。

当两项任务共享卷积层时，反向传播的梯度在共享层内发生拉扯。分类损失要求扩大感受野以聚合人体轮廓；定位损失则要求死守边缘像素的高频跳变。共享层被迫折中，分类梯度直接打在用于框回归的特征提取通道上，影响了边界回归的精度。

为了终结这种内耗，解耦头（Decoupled Head）成为了现代检测头的标准设计。左侧是耦合头：分类和定位共用卷积，只在最后 $1\times 1$ 处分叉。右侧是解耦头：特征一进头就分成两条私有卷积。

![耦合头与解耦头的结构对比：耦合头共享卷积只在末端分叉，解耦头在入口处即分流为分类与定位两条私有支路](/img/cv_img/object-detection/coupled-vs-decoupled-head.png)

在解耦头架构中，输入特征图进入预测头后立即分流至两条独立的物理支路：分类分支使用私有卷积提取高阶语义，定位分支使用私有卷积保留空间边缘细节。

解耦之后，分类损失的反向传播梯度被限制在分类分支内部，定位损失的梯度也只在定位分支中流动。分类梯度不再直接打到框回归特征上，定位分支得以专心保留行人边缘的细微像素变化，分类分支也可以放开手脚去聚合判别性语义。

解耦头消除了梯度层面的内耗，但也带来了新的结构性断层。

## 解耦后的断层：两条分支各自为政

当分类分支与定位分支在物理上被完全拆开后，它们各自在独立的轨道上运行，彼此失去了沟通的途径。

分类分支独立计算，只看分类特征并输出置信度分数 $s$；定位分支独立计算，只看定位特征并输出坐标（对应交并比 $\mathrm{IoU}$）。分类分支打分时不知道定位分支把框画成了什么形状，定位分支微调边界时也不知道当前位置的分数高低。

这种各自为政的状态，直接加剧了开头提到的“高分低质”现象：

1. **高分低质框**：在两名行人交错的核心区域，特征丰富，分类分支给出 $s = 0.95$ 的高分。但定位分支受双重轮廓干扰，回归出的边界框卡在两人中间，与真实目标的交并比只有 $\mathrm{IoU} = 0.35$。
2. **低分高质框**：在单侧行人的边缘网格，分类特征不够典型，分类分支给出 $s = 0.40$ 的低分。但此处外侧边缘清晰，定位分支回归出了与真实目标重合度极高的框，交并比达到 $\mathrm{IoU} = 0.90$。

在现有的推理管线中，后处理筛选机制只能依赖分类分数 $s$ 降序排列候选框。排序的结果显而易见：那个 $s = 0.95$ 但 $\mathrm{IoU} = 0.35$ 的破损框排在最前；而 $s = 0.40$ 但 $\mathrm{IoU} = 0.90$ 的精准框因分数过低排在末尾甚至被直接抹杀。

:::note[解耦的代价]
物理上的解耦治好了反向传播时的梯度冲突，却在正向预测时撕裂了分类与定位的协同性。如果分类分数不能反映定位好坏，解耦头就只是把矛盾从特征层转移到了决策层。
:::

## 任务对齐：让头产出反映定位质量的分数（TOOD）

要解决解耦后的割裂问题，检测头产出的分类分数必须能够与定位质量保持步调一致。

任务对齐（Task Alignment，指在检测头内部建立分类与定位的协同机制，使分类置信度与定位交并比紧密关联）这一概念正是在这种背景下被引入检测头设计的。在任务对齐单阶段目标检测网络（Task-aligned One-stage Object Detection, 简称 TOOD）中，核心思路是在保持解耦的前提下，让两项任务在特征层进行动态交互，并重塑分类分数的优化目标。

TOOD 对检测头进行了两个关键改造：

第一，**任务对齐预测头（Task-Aligned Head）**。网络不再让分类与回归分支处于完全孤立的状态，而是设计了轻量级的跨任务交互机制。分类分支在输出最终特征之前，会通过注意力机制读取定位分支的空间分布特征；定位分支在计算边界偏移之前，也会引入分类分支的语义激活信息。通过特征层面的相互感知，分类分支能够提前获知当前位置在空间几何上的边界可信度。

第二，**显式的对齐度量指标**。为了让网络在训练时有据可依，TOOD 提出了一个统一衡量分类与定位综合质量的度量 $t = s^\alpha \times \mathrm{IoU}^\beta$。各项的含义如下：

- $s \in [0, 1]$ 是分类分支针对某个真实类别预测出的置信度分数；
- $\mathrm{IoU} \in [0, 1]$ 是当前位置回归出的预测边界框与真实标注框之间的交并比；
- $\alpha$ 和 $\beta$ 是调节两者相对重要程度的超参数。

这个度量公式采用严格的乘法逻辑：只有当分类置信度 $s$ 极高，**并且** 预测框与真实框的重合度 $\mathrm{IoU}$ 也极高时，综合对齐度量 $t$ 才会逼近 1.0。任何一项出现短板，在乘法的作用下，$t$ 的数值都会被大幅拉低。

获得这个对齐度量 $t$ 之后，TOOD 做出了一个决定性的优化改动：**它废弃了传统分类训练中非 0 即 1 的离散硬标签，直接将标量 $t$ 归一化后作为分类分支优化的软目标标签。**

在任务对齐机制下，分类分支的学习目标被直接替换成了动态计算出的 $t$：

- 如果某个网格预测出的边界框画得非常粗糙，哪怕它内部的语义纹理再丰富，由于其计算出的 $\mathrm{IoU}$ 极低，$t$ 的目标值可能只有 0.2。分类分支在损失函数的拉扯下，就会主动降低该位置的置信度，不再给它虚高的分数；
- 只有当定位分支逐渐学会收紧边界，将预测框的 $\mathrm{IoU}$ 逐步推高到 0.85 以上时，对齐度量 $t$ 才会上升到 0.85，分类分支才被允许向更高的分数学习。

这一机制改变了分类分数的物理含义。经过任务对齐训练后的检测头，其输出的“分类分数”不再仅仅是局部像素属于某个类别的概率，而是演变成了一个**综合了类别属性与几何定位质量的可靠评估指标**。

在两个行人交错的重叠区域，那个卡在两人中间的畸形框由于 $\mathrm{IoU}$ 极低，其分类分数会被系统性压制；而在行人清晰边缘处生成的精准框，由于同时具备合格语义与极高交并比，其分类分数被顺畅推向高位。推理阶段的后处理排序由此恢复正常。

需要指出的是，TOOD 这里的对齐度量 $t$ 不仅在检测头内部重塑了分类分数的损失目标，它还为后续挑选正负样本提供了依据。至于这个分数如何进入代价矩阵挑选网格，属于更为宏大的动态分配机制，必须交由专门的[第 3 篇：Label Assignment](./label-assignment)来展开。检测头在这一步的使命，是确保输出端给出的每一个分数都经得起几何精度的检验。

## 检测头就位之后：为何仍需多尺度特征调度

回顾检测头的演进：通过 Focal Loss 压制简单背景的累积梯度，使稀缺的小目标能够被正常学习；通过解耦头拆分分类与定位通道，避免两类任务在特征提取上的梯度干扰；通过任务对齐机制将定位质量引入分类目标，使输出分数能够反映定位优劣。

然而，这些机制的前提是输入检测头的特征图本身保留了必要的信息。

回到街道尽头那块 $16\times 16$ 像素的小路牌：在卷积网络的逐层下采样中，当特征图压缩到 stride 32 时，整张图只剩 $20\times 20$ 个点，小路牌在数学上甚至占不到一个完整的像素点，其空间轮廓早在主干网络的深层就被下采样彻底抹平了。

如果在到达预测头之前，浅层的定位边缘无法快速输送给深层，深层的丰富语义无法顺畅倒灌回浅层，那么特征图本身就会沦为残缺不全的信息碎片。面对一块在特征图上已经彻底丢失了位置信息或者根本不具备辨识特征的网格，无论检测头的损失函数设计得再精妙、解耦结构再合理、对齐度量再严密，也根本无从落笔打分。

特征图究竟该如何在不同分辨率之间搭建起无损流动的桥梁，让浅层拥有看懂物体的语义、让深层保留定位边缘的精度，这并不是检测头单兵作战能够解决的问题，而是属于负责在骨干与检测头之间调度信息的特征中枢——[第 6 篇：多尺度特征与 Neck 架构](./neck-architecture)。
