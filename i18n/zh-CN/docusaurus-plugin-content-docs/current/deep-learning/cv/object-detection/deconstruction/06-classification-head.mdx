# 分类置信度与 Detection Head

在密集预测的排序输出中，经常出现两类错位：分类分数高达 $0.95$ 的预测框与真实目标的重合度很低，而与真实目标精确对齐的预测框分类分数只有 $0.15$，在阈值筛选阶段就被丢弃。

这反映了检测头长期面对的两类问题：在密集的候选空间中，背景区域的数量远多于真实目标，少数困难正样本的梯度容易被大量简单负样本的累积梯度淹没；分类分支输出的高置信度分数无法代表预测框在几何定位上的准确程度。

检测头（Head）是检测网络中直接连接损失函数、输出预测结果的模块。它必须在每个候选位置上回答两个问题：这里存在什么类别的物体，以及物体的几何边界在哪里。这两个子任务在特征表示需求与优化方向上存在冲突。

## 为什么分类分数不能代表定位质量

在图像分类任务中，模型追求平移不变性。无论目标出现在图像的左上角、中央还是右下角，分类器都希望深层特征给出稳定的类别响应。

但是目标检测不仅要识别物体的语义属性，还要输出具体的几何边界框坐标 $[x, y, w, h]$。检测头对空间位置具有平移敏感性：目标在图像中平移两个像素，或者预测框向外扩张三个像素，网络输出的边界坐标都应当产生相应的数值变化。

当系统直接使用分类分支的得分作为衡量检测框整体质量的唯一依据时，错位就会出现。

考虑空间上相互靠近的两个目标。当一个预测框落在两个目标之间时，该位置对应的感受野同时覆盖了两个目标的局部结构。对于分类分支，只要感受野内存在充足的类别判别性纹理，分类卷积就会输出接近 $1.0$ 的置信度，而不关心这些特征是否属于同一个物体实例。

但是在空间几何层面，这个预测框与两个真实标注框的交并比（IoU）都很低，可能都低于 $0.3$。

相反，另一个预测框的四条边与某个真实目标的轮廓精确对齐，交并比达到 $0.9$。但是生成这个预测框的特征位置恰好处于目标边缘或者光照、纹理变化较大的区域，局部特征缺乏典型性，分类分支给出的置信度只有 $0.45$。

在依赖分类分数排序的后处理中，交并比只有 $0.3$ 的预测框会凭借 $0.95$ 的高分排在前面，而交并比高达 $0.9$ 的精确预测框会因为分数偏低排在后面，甚至在阈值筛选阶段被直接丢弃。

分类分支只反映局部特征的语义丰富程度，不反映边界框的几何重合程度。要使检测头正常工作，必须先解决背景样本带来的梯度失衡，再解决分类与定位在特征表示与优化目标上的冲突。

## 背景样本的数量优势：从 Objectness 到 Focal Loss

在一张 $640\times 640$ 的输入图像上，密集预测检测头通常在多个下采样倍率的特征图上设置预测点。假设网络使用步长为 $8$、$16$ 和 $32$ 的三层特征图：

- 步长为 $8$ 的特征图尺寸为 $80\times 80$，提供 6400 个预测位置；
- 步长为 $16$ 的特征图尺寸为 $40\times 40$，提供 1600 个预测位置；
- 步长为 $32$ 的特征图尺寸为 $20\times 20$，提供 400 个预测位置。

三层特征图累加在一起，单张图像生成 $6400 + 1600 + 400 = 8400$ 个候选位置。

在这 8400 个位置中，真正包含目标的位置很少。通常只有数十个位置能够划归为正样本，其余 8300 多个位置全部是背景。

在密集预测场景中，正负样本的比例很容易达到几十比一甚至上千比一。

早期的检测器为了应对这种数量差异，尝试在类别预测之前引入名为 objectness 的独立分支。objectness 表示目标存在性，它是一个二分类标量，用于判断某个候选区域包含物体还是纯背景。在早期单阶段检测算法中，最终的类别置信度被拆成 $P(\mathrm{Class}_i) = P(\mathrm{Object}) \times P(\mathrm{Class}_i \mid \mathrm{Object})$。第一项由 objectness 分支输出，表示该位置存在物体的概率；第二项由类别分支输出，表示在存在物体的条件下属于第 $i$ 类的条件概率。

这种拆分在概念上将是否存在物体与属于哪个类别分开，但是没有从根本上解决梯度被背景主导的问题。无论是 objectness 分支还是多分类分支，只要损失函数沿用标准的二值交叉熵（Binary Cross-Entropy），大量背景样本的累积效应都会主导训练过程。

对于标准的二值交叉熵损失，单个样本的损失和与标签对齐的概率 $p_t$ 写成：

$$
\begin{aligned}
\mathrm{CE}(p, y) &= \begin{cases} -\log(p) & \text{当 } y = 1 \\ -\log(1 - p) & \text{当 } y = 0 \end{cases} \\
p_t &= \begin{cases} p & \text{当 } y = 1 \\ 1 - p & \text{当 } y = 0 \end{cases}
\end{aligned}
$$

其中 $y \in \{0, 1\}$ 是真实标签，$p \in [0, 1]$ 是模型预测该位置为正样本的概率。交叉熵因此可以简写为 $\mathrm{CE}(p_t) = -\log(p_t)$。

在这一公式下分析 8300 多个背景位置。多数背景区域容易判断，网络能够给出 $p = 0.01$ 的预测，即 $p_t = 1 - 0.01 = 0.99$。单个简单背景的损失是 $\mathrm{CE}(0.99) = -\log(0.99) \approx 0.010$。单独看这个数值很小，但是当 8300 个简单负样本同时反向传播时，它们产生的损失累加起来达到 $8300 \times 0.01 \approx 83$。

再看一个困难正样本。假设网络对该位置的预测概率只有 $p = 0.2$（即 $p_t = 0.2$），单个损失是 $\mathrm{CE}(0.2) = -\log(0.2) \approx 1.61$。单个困难样本的损失虽然比单个简单背景样本大上百倍，但是在数千个简单背景样本的数量优势面前，负样本累加产生的梯度总和依然占据主导。在反向传播过程中，优化器的更新方向主要由大量已分类正确的背景样本决定，真正需要学习的困难正样本信号被淹没。

为了缓解这种数量差异带来的影响，Focal Loss 改变了损失函数的加权机制。它在标准交叉熵前面增加了一个基于置信度的调制项：

$$
\mathrm{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t)
$$

公式中的 $\gamma \ge 0$ 是调制超参数（在通用实践中通常取 $\gamma = 2$）。

:::tip[Focal Loss 的调制机制]
调制项根据预测概率 $p_t$ 的高低，动态降低已经学习充分的样本所贡献的梯度权重。容易区分的样本（如均匀背景区域，$p_t = 0.99$）的调制项 $(1 - 0.99)^2 = 0.0001$，原本 $0.01$ 的损失被削弱四个数量级，梯度几乎不再更新；困难样本（如 $p_t = 0.2$）的调制项 $(1 - 0.2)^2 = 0.64$，损失得到大部分保留。检测头在样本数量极端失衡的情况下，仍能将更新方向集中在少数难以区分的真实目标上。
:::

## 特征冲突：耦合头与解耦头

背景样本带来的梯度失衡得到缓解之后，检测头内部的结构差异成为影响精度的主要因素。

早期单阶段检测器普遍采用耦合头（Coupled Head）：来自特征金字塔的特征图直接送入两到三层共享卷积层，随后在末端引出两个并行的 $1\times 1$ 卷积，分别输出类别预测分数与边界框坐标偏移量。

这种结构隐含了一个假设：在深层表示中，用于语义分类的特征与用于几何定位的特征是高度重合并且可以共用的。

然而在特征分析中，分类与定位对特征表示的需求存在实质冲突：

1. **分类任务要求语义抽象与平移不变性**。分类分支希望卷积核忽略空间上的微小扰动，关注目标整体的语义结构。即使目标的局部结构在特征图上轻微平移，分类分支也希望深层特征保持稳定的激活。
2. **定位任务要求空间精确与平移敏感性**。边界回归分支需要确定目标边缘所在的准确坐标，关注物体的边缘轮廓在哪个像素位置发生变化。如果特征图过度平滑并且丢失了高频空间细节，回归分支就无法确定边缘的准确位置。

当两类任务共享卷积层时，反向传播的梯度在共享层内相互干扰。分类损失要求扩大感受野以聚合整体语义，定位损失则要求保留边缘像素的高频变化。共享层被迫在两者之间折中，分类梯度直接影响用于边界回归的特征通道，降低了边界回归的精度。

为了解决这种内部干扰，解耦头（Decoupled Head）成为现代检测头的标准设计。左侧是耦合头：分类和定位共用卷积，只在最后 $1\times 1$ 处分叉。右侧是解耦头：特征进入检测头后分为两条独立卷积支路。

![耦合头与解耦头的结构对比：耦合头共享卷积只在末端分叉，解耦头在入口处即分流为分类与定位两条独立支路](/img/cv_img/object-detection/coupled-vs-decoupled-head.png)

在解耦头架构中，输入特征图进入检测头后分流到两条独立的支路：分类分支使用独立卷积提取高阶语义，定位分支使用独立卷积保留空间边缘细节。

解耦之后，分类损失的反向传播梯度限制在分类分支内部，定位损失的梯度也只在定位分支中流动。分类梯度不再直接影响边界回归的特征提取，定位分支能够保留目标边缘的像素级变化，分类分支也可以集中聚合判别性语义。

解耦头消除了梯度层面的相互干扰，但是带来了新的结构性问题。

## 解耦后的分离：两条分支独立运行

当分类分支与定位分支在结构上完全分开后，它们在各自的支路上独立运行，相互之间缺少信息交换。

分类分支独立计算，只根据分类特征输出置信度分数 $s$；定位分支独立计算，只根据定位特征输出坐标（对应交并比 $\mathrm{IoU}$）。分类分支打分时不知道定位分支输出的边界形状，定位分支调整边界时也不知道当前位置的分类分数。

这种相互独立的状态加剧了开头提到的高分低质现象：

1. **高分低质框**：在目标密集或者相互靠近的区域，局部特征丰富，分类分支给出 $s = 0.95$ 的高分。但是定位分支受到多个相邻目标轮廓的干扰，回归出的边界框落在目标之间，与真实目标的交并比只有 $\mathrm{IoU} = 0.35$。
2. **低分高质框**：在目标边缘特征清晰但是语义典型性不足的位置，分类分支给出 $s = 0.40$ 的低分。但是该位置的外侧边缘清晰，定位分支回归出了与真实目标重合度很高的预测框，交并比达到 $\mathrm{IoU} = 0.90$。

在现有的推理流程中，后处理筛选只能依赖分类分数 $s$ 降序排列候选框。排序结果是确定的：$s = 0.95$ 但 $\mathrm{IoU} = 0.35$ 的预测框排在前面，而 $s = 0.40$ 但 $\mathrm{IoU} = 0.90$ 的精确预测框因为分数过低排在后面甚至被直接过滤。

:::note[解耦的代价]
结构上的解耦解决了反向传播时的梯度干扰，但是在正向预测时割裂了分类与定位的协同。如果分类分数不能反映定位质量，解耦头只是把矛盾从特征层转移到了决策层。
:::

## 任务对齐：使输出分数反映定位质量（TOOD）

要解决分支解耦后的分离问题，检测头输出的分类分数必须与定位质量保持一致。

任务对齐（Task Alignment，指在检测头内部建立分类与定位的协同机制，使分类置信度与定位交并比相互关联）这一概念正是在这种背景下引入检测头设计的。在任务对齐单阶段目标检测网络（Task-aligned One-stage Object Detection，简称 TOOD）中，核心思路是在保持分支解耦的前提下，使两类任务在特征层面进行交互，并重新定义分类分数的优化目标。

TOOD 对检测头进行了两个关键改造：

第一，**任务对齐预测头（Task-Aligned Head）**。网络不再让分类与回归分支完全孤立，而是设计了轻量级的跨任务交互机制。分类分支在输出最终特征之前，通过注意力机制读取定位分支的空间分布特征；定位分支在计算边界偏移之前，也引入分类分支的语义激活信息。通过特征层面的相互感知，分类分支能够提前获得当前位置在空间几何上的边界可信度。

第二，**显式的对齐度量指标**。为了让网络在训练时有明确的优化依据，TOOD 提出了一个统一衡量分类与定位综合质量的度量 $t = s^\alpha \times \mathrm{IoU}^\beta$。各项的含义如下：

- $s \in [0, 1]$ 是分类分支针对某个真实类别预测出的置信度分数；
- $\mathrm{IoU} \in [0, 1]$ 是当前位置回归出的预测边界框与真实标注框之间的交并比；
- $\alpha$ 和 $\beta$ 是调节两者相对重要程度的超参数。

这个度量公式采用乘法形式：只有当分类置信度 $s$ 较高，并且预测框与真实框的重合度 $\mathrm{IoU}$ 也较高时，综合对齐度量 $t$ 才接近 $1.0$。其中任何一项偏低，在乘法作用下 $t$ 的数值都会明显下降。

获得这个对齐度量 $t$ 之后，TOOD 做出了一个关键的优化改动：**它不再使用传统分类训练中非 $0$ 即 $1$ 的离散硬标签，而是直接将标量 $t$ 归一化后作为分类分支优化的软目标标签。**

在任务对齐机制下，分类分支的学习目标被替换成动态计算出的 $t$：

- 如果某个位置预测出的边界框不够准确，即使它内部的语义纹理丰富，由于其计算出的 $\mathrm{IoU}$ 较低，$t$ 的目标值可能只有 $0.2$。分类分支在损失函数的约束下，会降低该位置的置信度，不再给出虚高的分数；
- 只有当定位分支逐渐收紧边界，将预测框的 $\mathrm{IoU}$ 推高到 $0.85$ 以上时，对齐度量 $t$ 才会上升到 $0.85$，分类分支才被允许输出更高的分数。

这一机制改变了分类分数的含义。经过任务对齐训练后的检测头，其输出的分类分数不再仅仅是局部像素属于某个类别的概率，而是综合了类别属性与几何定位质量的评价指标。

在目标重叠区域，落在目标之间、定位质量较差的预测框由于 $\mathrm{IoU}$ 较低，其分类分数会被系统性压低；而在目标边缘清晰处生成的精确预测框，由于同时具备语义响应与较高的交并比，其分类分数会被推向高位。推理阶段的后处理排序因此恢复正常。

需要指出的是，TOOD 的对齐度量 $t$ 不仅在检测头内部重新定义了分类分数的损失目标，它还为后续选择正负样本提供了依据。这个分数如何进入代价矩阵并参与样本选择，属于动态匹配机制的内容，由[第 3 篇：Label Assignment](./label-assignment)展开。检测头在这一步的作用，是保证输出端给出的每个分数都经过几何精度的约束。

## 检测头就位之后：为何仍需多尺度特征调度

回顾检测头的演进：通过 Focal Loss 抑制简单背景的累积梯度，使稀少的困难目标能够得到正常学习；通过解耦头拆分分类与定位通道，避免两类任务在特征提取上的梯度干扰；通过任务对齐机制将定位质量引入分类目标，使输出分数能够反映定位准确程度。

然而，这些机制成立的前提是输入检测头的特征图本身保留了必要的信息。

以深层高倍率下采样为例：当特征图压缩到步长为 $32$ 时，整张特征图只剩 $20\times 20$ 个特征点，小目标在空间上已经不足一个完整的特征点，其空间轮廓在主干网络的深层输出中基本丢失。

如果在到达检测头之前，浅层的定位细节无法传递给深层，深层的语义无法传递回浅层，那么特征图本身就是不完整的。面对在特征图上已经丢失位置信息或者缺乏判别性特征的位置，无论检测头的损失函数设计得多么精细、分支结构多么合理、对齐度量多么严密，都无法输出可靠的预测分数。

特征图应当如何在不同分辨率之间建立有效的信息流动，使浅层获得识别目标所需的语义，使深层保留定位所需的边缘精度，这不是检测头单独能够解决的问题，而是负责在骨干网络与检测头之间调度信息的特征融合模块的职责，相关内容属于[第 6 篇：多尺度特征与 Neck 架构](./neck-architecture)。
