# I3D（膨胀 3D 卷积网络）

**论文：** Joao Carreira and Andrew Zisserman, Quo Vadis, Action Recognition? A New Model and the Kinetics Dataset, CVPR 2017.

**论文链接：** https://arxiv.org/abs/1705.07750

**代码：** https://github.com/deepmind/kinetics-i3d

![DeepMind 与牛津大学作者的 I3D 论文标题栏](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image1.png)

## 背景：两项贡献

### 提出了新模型 I3D

这里要回答的问题是，如何把成熟的 2D 图像模型扩展为 3D 视频模型。好的扩展方法会沿用 2D 网络的结构和预训练权重，这样训练仍然简单，ImageNet 预训练的成果也不会浪费。

### 设计了 Kinetics 数据集

此前的视频研究缺少一个规模与 ImageNet 相当的大数据集。作者发布了 Kinetics-400：400 个人体动作类别，每个类别有 400 多个视频片段，总计约 30 万个片段，每个片段长约 10 秒，取自 YouTube。作者还指出，视频模型应当在视频数据上预训练，而不能只依赖图像预训练，Kinetics 数据集让这种预训练成为可能。

![缺少周围帧时动作标签存在歧义的单帧画面](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image2.png)

单张图像常常无法确定动作标签。周围帧提供的运动信息可以消除这种歧义，这也是论文把视频建模看作时空联合建模问题的原因。

## 预备知识：光流

光流估计相邻帧之间每个像素的位移，是一种显式的运动信号。当任务取决于物体随时间如何运动，而不是静态长相时，光流很有用。

标准的光流计算建立在三个假设上：

- 亮度不变：被跟踪的点在帧与帧之间保持亮度不变。
- 运动很小：相邻两帧之间的位移不大。
- 空间一致：相邻像素的运动方式接近。

由此可以直接看出它的局限。光流场不一定等于真实的物体运动，因为算法跟踪的只是表面的亮度变化。它对光照也很敏感：光照一变，亮度不变的假设就不再成立，识别效果随之下降。密集光流的计算开销也很大，因为几乎每个像素都要估计一个位移向量。

![跑步人物身上的光流向量，以及补偿相机运动之后的光流向量](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image5.jpeg)

## I3D 模型

在得出 I3D 之前，论文在同一基准下对比了五种结构。

![论文对比的五种视频结构：LSTM、3D 卷积网络、双流网络、3D 融合网络和双流 I3D](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/I3Dimg/image6.png)

### 结构 a）CNN 加 LSTM

每一帧先经过 2D CNN，得到的特征序列再送入 LSTM 做时序建模。特征提取和时序推理是分开的：CNN 从来看不到运动，LSTM 拿到的只是每帧的概要信息。空间和时间在特征学习阶段没有交互，在视频基准上的准确率也比较一般。

### 结构 b）3D 卷积网络

连续帧在时间、高和宽三个维度上组成一个 3D 体。3D 卷积同时学习空间和时间信息，用池化控制 3D 特征图的大小，用全连接层完成分类。它的短板在预训练：普通 2D 网络可以直接继承 ImageNet 权重，这个 3D 网络只能从头训练，训练更难，也更容易过拟合。

### 结构 c）双流网络

两个 2D 网络并行运行，一个处理 RGB 图像帧，一个处理预先算好的光流。两个分支都可以用 ImageNet 预训练，运动信息来自光流输入，而不是 3D 卷积。这里的光流不是真正的时间轴，而是预先算好的位移信息，再送给 2D 网络。融合只发生在打分层面，两个流从不共享特征。

### 结构 d）和 e）

两种结构都融合了 RGB 和光流，区别在于融合的位置和方式。

模型（d）保留了两个 2D 流，但在高层把特征图融合成时空张量体，再送入一个小 3D 网络。融合提前到了最终决策之前，准确率有所提高，但整个流程仍然很重：还是要预先计算密集光流，又在上面叠了一个 3D 阶段。

模型（e）就是 I3D。RGB 和光流各自进入一个独立的 3D 网络，每个分支都同时对空间和时间建模，两个流在末端融合：

> 每个分支独立进行时空建模，再把两路结果在末端融合。

下表取自原论文，给出了每种设计的计算代价。I3D 的参数量是 25M，而纯 3D 卷积网络是 79M，同时 I3D 在测试时的时间覆盖范围达到了完整的 10 秒。

### ImageNet 预训练与迁移

在 ImageNet 这样的大数据集上预训练，可以让网络学到能迁移到小任务上的特征。在 Kinetics 出现之前，视频领域没有对应的数据集，视频模型通常只能在 UCF-101 或 HMDB-51 这样的小数据集上从头训练。I3D 加上 Kinetics 补上了这一块，让视频领域也有了和图像领域一样的“先预训练再微调”的流程。

## 方法实现

### 如何做膨胀

膨胀保持整体网络结构不变，只是把每个 2D 操作扩展为 3D：

- 2D 卷积变为 3D 卷积，2D 池化变为 3D 池化。$k \times k$ 的滤波器在时间、高和宽三个维度上变为 $k \times k \times k$。
- 时间步长和池化参数经过设置，使时间感受野随深度逐渐增大，节奏与空间感受野的增大保持一致。

### 从 2D 滤波器初始化 3D 滤波器

目标是从预训练好的 2D 网络初始化 3D 网络，使两者在一张静止图像及其重复构成的静态视频上给出相同的输出。

检验方法如下。把一张图像沿时间轴重复，得到每一帧都相同的静态视频。在原图上运行 2D 网络，在这个静态视频上运行膨胀后的 3D 网络。正确的初始化应当让两者的输出一致。

具体做法是把每个 2D 滤波器沿时间轴重复 $N$ 次（$N$ 是膨胀后滤波器的时间尺寸），再把权重除以 $N$。这个除法很关键：不除的话，$N$ 个副本会把 $N$ 个相同的响应加起来，输出会变成 2D 结果的 $N$ 倍。除以 $N$ 之后，3D 网络正好从 2D 网络结束的位置起步，再在 Kinetics 训练中学习时序结构。

## 实验结果简述

在 Kinetics 上预训练、再在小基准上微调之后，论文报道的双流 I3D 在 UCF-101 上达到约 98.0% 的准确率，在 HMDB-51 上达到约 80.9%，明显高于从头训练的同类结构。这个提升印证了论文的观点：视频模型和图像模型一样，都极大受益于自身模态下的大规模预训练。
