# 只看一次（WOO）

**论文：** Shoufa Chen et al., Watch Only Once: An End-to-End Video Action Detection Framework, ICCV 2021.

**论文链接：** https://openaccess.thecvf.com/content/ICCV2021/papers/Chen_Watch_Only_Once_An_End-to-End_Video_Action_Detection_Framework_ICCV_2021_paper.pdf

**代码：** https://github.com/ShoufaChen/WOO

![WOO 的统一流程：一条主干网络同时给出检测框和动作标签](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image1.png)

## WOO 的核心思想

WOO 用一个网络把视频片段看一遍，同时输出其中每个人的检测框和动作类别。测试时不需要单独的人体检测器，也不需要非极大值抑制之类的后处理。

## 问题背景

### 摘要

> 我们提出了名为 Watch Only Once（WOO）的端到端视频动作检测流程。当时的方法要么把动作检测拆成定位和分类两个独立阶段，要么在一个阶段里训练两个独立模型。相比之下，我们的方法在一个统一网络里同时解决定位和分类。通过统一主干网络并去掉大量手工设计的组件，整个流程大为简化。WOO 用一条视频主干网络同时提取定位和分类所需的特征。另外，我们在框架里引入了时空动作嵌入，并设计了时空融合模块，得到更丰富、更易区分的特征，进一步提高了分类效果。在 AVA 和 JHMDB 上的大量实验证明，WOO 达到了当时的最好效果，同时比已有方法最多节省 16.7% 的 GFLOPs。

- **FLOPs** 表示一次前向推理需要的浮点运算次数。
- **GFLOPs** 等于 $10^9$ 次浮点运算。数值越大，计算越重，推理越慢。

### 视频检测包含两个子任务

视频动作检测要同时回答两个问题：每个人在哪里，每个人在做什么。定位一般看单帧就够了，判断动作则需要多帧的运动信息。这个不一致是主要的难点。

### 论文中对比的传统方法

![双主干的动作检测流程与统一的 WOO 流程之对比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image2.png)

YOWO 属于训练阶段统一、主干仍然分开的做法。它还是用一个 2D CNN 做检测，用一个 3D CNN 做动作建模，特征要从原始像素里提取两次。WOO 认为这种设计实际上还是两个模型，目标是用一条主干、一次前向传播完成两个任务。

### WOO 的创新

WOO 让两个检测头共用一条视频主干网络。同一个片段只看一遍，网络同时给出定位和分类的输出。

## WOO 的结构

:::info[三个组件]
WOO 由统一的主干网络、时空动作嵌入，以及分类头内部的时空融合模块组成。
:::

### 统一的主干网络

一条主干网络同时承载时间和空间信息。关键设计是把关键帧特征很早分离出来，这样检测分支保留干净的空间细节，分类分支保留完整的时间上下文。

![分开的 2D 加 3D 主干，与带关键帧早期分离的统一主干之对比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image3.png)

在传统的分开设计里，2D 检测器处理关键帧，3D 网络处理整个片段。3D 分支的最后一个阶段常用空洞卷积（记作 DC5），在扩大感受野的同时保持空间分辨率。WOO 去掉了这种空洞卷积，因为它解决不了更深层的问题：网络越深，时间卷积越是把相邻帧混入关键帧，检测需要的空间细节就被抹掉了。

于是 WOO 很早就把关键帧分离出来。形式上记

$$X \in \mathbb{R}^{C \times T \times H \times W}$$

为某一层的时空特征图，其中 $C$ 是通道数，$T$ 是时间长度。关键帧放在片段中间，记

$$X_t = X[T/2] \in \mathbb{R}^{C \times H \times W}$$

为关键帧特征图。

一个轻量的特征金字塔网络从早期阶段（res2 到 res5）取出关键帧特征，组成多尺度空间特征，送给定位头。完整的片段特征则继续往上走，到最后一个阶段送给分类头。检测分支用一个小金字塔代替了原来单独的 2D 主干网络，参数量和计算量的节省主要来自这里。

### 时空动作嵌入

动作分类比定位更难。作者发现统一网络定位效果不错，分类效果仍然受限，猜测是同一条主干同时服务两个任务时偏向了定位。为了加强分类，他们加了一个专用分支，包含空间和时间两组动作嵌入，以及人物之间的交互步骤。

> 论文原文：“我们发现统一结构在定位上表现不错，但动作分类仍然受限。因此我们猜测，同一条主干同时服务两个任务时，会偏向定位任务，从而影响分类效果。”

### 时空融合模块

融合模块放在分类头内部。它把形状、姿态一类的空间线索，和运动、持续时间一类的时间线索结合起来，生成最终用于分类的特征。

### 动作人定位头

- 这个检测头借鉴了 Sparse R-CNN，一种不需要手工锚框、测试时不需要抑制的端到端检测器。
- 输入是关键帧的多尺度金字塔特征，输出是固定数量的检测框和置信度分数。
- 训练使用集合预测损失加二分匹配，每个真实的人只匹配一个预测框。测试时直接使用预测的集合，不再做后处理。
- 检测和分类共用主干网络，所以不需要单独预训练一个检测器。

集合预测的意思是，模型每次预测固定数量的框，匹配器给每个真实框找到最合适的搭档：

```text
真实框：3 个人
模型输出：例如 100 个框
匹配：3 个人各自分到恰好 1 个框，
  剩下的框都算作背景。
```

### 动作分类头

![RoIAlign 把人物特征裁出并分成空间和时间两条分支](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image7.png)

对每个检测到的人，RoIAlign 从最后一个阶段的片段特征里裁出这个人所在的区域，并归一化到固定的空间尺寸。裁出的特征体再分成两路：

```text
检测到的人 -> RoIAlign 裁剪 ->
  空间分支（在时间上池化，保留布局）和
  时间分支（在空间上池化，保留运动）->
  人物间交互 -> 融合 -> 分类
```

时间分支在空间维度上池化，保留随时间的变化。空间分支在时间维度上池化，保留结构。两路直接拼接的结果只作为基线，接下来介绍的嵌入交互用来让特征更易区分。

![空间嵌入和时间嵌入之间的人物间交互](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/WOOimg/image9.png)

同一个片段里的人常常互相影响，只看当前一个人的特征容易产生歧义。交互模块用来刻画人物之间的关系。对 $N$ 个检测到的人，论文定义空间嵌入和时间嵌入 $E_s \in \mathbb{R}^{N \times d}$ 和 $E_t \in \mathbb{R}^{N \times d}$，经过线性层得到查询、键和值，再计算人物之间的注意力分数。分数在 softmax 之前除以 $\frac{QK^{T}}{\sqrt{d}}$ 做缩放，以免维度很大时梯度饱和。交互后的嵌入再用 $1 \times 1$ 卷积投影回去，和人物特征融合。

### 嵌入

为了节省计算，注意力只在轻量的人物嵌入之间进行，而不在完整的特征图之间进行。

> 论文原文：“嵌入比特征图轻得多，出于效率考虑，我们在嵌入之间而不是在特征图之间使用注意力机制。”

换句话说，关系建模始终留在紧凑的嵌入空间里，只有得到的关系信号才写回高维特征。

:::caution[论文没有写清的地方]
论文只说 $N$ 个人物特征各有自己的嵌入，没有画出这些嵌入的具体初始化方式。上面的描述依据论文的公式和文字，超出部分属于解读，不是论文原话。
:::

### 关于注意力的一点补充说明

注意力帮助模型决定突出什么。权重越大，对输出的影响越大。

CBAM 一类的通道注意力问的是，一张特征图里哪些通道和区域更重要，不区分不同的人。WOO 一类的人物间注意力问的是，每个人应当参考其他人到什么程度。后者是 transformer 式的、作用在人物上的注意力，形式上接近 token 之间的自注意力。
