# 时间移位模块（TSM）

**论文：** Ji Lin, Chuang Gan, Song Han, TSM: Temporal Shift Module for Efficient Video Understanding, ICCV 2019.

**论文链接：** https://openaccess.thecvf.com/content_ICCV_2019/papers/Lin_TSM_Temporal_Shift_Module_for_Efficient_Video_Understanding_ICCV_2019_paper.pdf

**代码：** https://github.com/mit-han-lab/temporal-shift-module

![TSM 总览：把一部分通道在时间上移位，再做 2D 卷积](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image1.png)

2D CNN 一次只从一帧提取空间特征，3D CNN 同时对空间和时间建模，能抓住更丰富的时空结构。

**3D 卷积**

![在空间和时间上做的 3D 卷积](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image2.png)

**2D 卷积**

![在单帧上做的 2D 卷积](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image3.png)

3D 卷积在时间维度上增加了计算，代价和参数量随之上升，在实时或资源受限的场景下难以部署。这里的问题是：

> 能否在保持 2D CNN 效率的同时，加上时间建模能力？

## 解决方法

### TSM 把一部分通道在时间上移位

特征有四个维度，其中 $C$ 是通道维度，$T$ 是时间维度。

![通道沿时间维度的移位](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image4.png)

核心操作是把一小部分通道沿时间前移或后移。移位之后，每一帧都带有一部分相邻帧的通道，接下来的普通 2D 卷积在混合这些通道时就混入了时间信息，而计算本身仍然是二维的。

### 移位的作用

![离线双向移位与在线单向移位的对比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image5.png)

以图（b）为例，当前帧从 $t-1$ 帧和 $t+1$ 帧各取来一部分移位通道。论文在每个方向上只移动一帧。

- 图（b）的离线移位是双向的。整个视频已经在手，当前帧可以用过去和未来的信息。
- 图（c）的在线移位是单向的。未来帧还没有出现，通道只能从过去传到现在。这个操作只改变数据的存放位置，不增加 FLOPs，也不增加参数。

### 核心思想

先移位，再卷积。移位之后，2D 卷积负责把混在一起的通道融合起来。哪些通道在时间上更重要，留给网络自己学，因为不同层、不同任务的答案不一样。

重的运算仍然是 2D 卷积，所以可以沿时间做批量并行。移位提供时间混合，后面的卷积完成融合。

## 移多少、在哪里移

![不同移位比例下的延迟开销和准确率](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image6.png)

图（a）是数据搬运带来的延迟开销。移动全部通道在 CPU 上带来约 13.7% 的额外延迟，不容忽视。只移动例如 1/8 的通道，开销降到约 3%。所以论文只移动一部分通道。

图（b）是准确率对比。残差移位在各种比例下都好于原地移位。移得越多，时间推理先变好，当前帧的空间表达随后变差，准确率先升后降。残差移位的峰值出现在移动四分之一通道处。

:::tip[默认设置]
论文默认使用四分之一通道的残差移位：离线双向建模里，1/8 前移，1/8 后移。
:::

### 模型设计：残差 TSM 与原地 TSM

![残差块之前的原地移位，与残差分支内部的移位之对比](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image7.png)

原地移位把操作插在卷积层或残差块之前。被移走的通道把信息带离了当前帧，当前帧就拿不到这些通道原来携带的内容。移动的通道越多，主干表达当前画面的能力退化越严重。

残差移位把操作放在残差分支内部。恒等路径仍然完整传递当前帧的激活，时间信息是加上去的，原来的内容并没有被拿走。即使分支里的通道全部移位， shortcut 也保住了空间表达能力。这就是残差移位在论文的 Kinetics 对比里全面好于原地移位的原因。

## 离线 TSM 视频模型

![带双向时间交换的离线 TSM 视频模型](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image8.png)

离线推理面对的是已经录好的完整视频，未来帧是可见的。模型把一部分通道前移、一部分后移，实现双向的时间信息交换。视频采样先得到各帧，早期的普通 ResNet 卷积提取空间结构，后面的 2D 卷积融合移位后的混合特征。移位本身没有参数，所有的学习都发生在后面的卷积里。

## 在线时间移位

在线推理用不到未来帧，所以移位是单向的。

![带特征缓存的在线单向 TSM 流程](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image9.png)

![在线移位的细节：缓存的过去通道替换当前帧的一部分](https://raw.githubusercontent.com/SAILTECHTEAM/knowledge-base/main/static/img/cv_img/TSMimg/image10.png)

对每一帧、每个残差块，模型把前 1/8 的特征图存入内存。下一帧到来时，它的前 1/8 被缓存的内容替换。这样每一层处理的是 7/8 的当前帧加上 1/8 的过去帧。这种设计有三个实际好处：

- 推理延迟低：每帧只做一次小规模的替换和缓存，每帧延迟接近 2D 基线。
- 内存占用小：只缓存一小部分特征（论文报道 ResNet-50 只多用约 0.9 MB）。
- 时间融合发生在每一层：同样的操作在网络的各个阶段重复，时间混合贯穿始终。

1/8 这个数字直接来自离线的结论。离线双向移位总共移动 1/4：

```text
离线双向 TSM：总共 1/4 = 前移 1/8 + 后移 1/8
在线单向 TSM：总共 1/8 = 只用过去帧
```
