# DINO：从无标签自蒸馏到视觉基础模型

> **名称说明：** 本文件介绍的是 Meta 的自监督 DINO 系列；它与名为 **DINO** 的目标检测器（*DETR with Improved DeNoising Anchor Boxes*）无关。

## DINO v1：无标签自蒸馏

### 自监督学习

自监督学习不需要人手标注的类别标签，而是从资料本身建立学习信号。在 DINO 中，同一张图像经不同数据增强后得到的视图，会分别送入学生模型与教师模型。教师模型的概率分布会成为学生模型的软目标。

自监督目标常被概略分为 **对比式** 与 **非对比式**；这是一个有用的高层分类方式，但并非穷尽所有方法的分类法。

#### 对比式目标

对比式目标会把同一张原始图像的两个增强视图视为 **正样本对**，把来自其他原始图像的视图视为 **负样本对**。

例如：

- 猫 A₁ ↔ 猫 A₂：正样本对
- 猫 B₁ ↔ 猫 B₂：正样本对
- 狗 C₁ ↔ 狗 C₂：正样本对
- 猫 A₁ ↔ 猫 B₁：负样本对，即使两者都是猫

训练时会拉近正样本对的表示，并推远负样本对的表示。负样本对有助于防止模型崩溃，但其中可能含有 **伪负样本**：两张图像在语义上相近，却仍被推远。

#### 非对比式目标

像 DINO 的非对比式方法，不会明确地把不同图像的表示推远。相反地，学生模型会匹配教师模型对同一张原始图像另一个视图的输出。

只移除明确的负样本，**不足以** 防止模型崩溃。DINO 结合了以下机制：

- 以指数移动平均（EMA）更新的动量教师；
- 教师端的停止梯度；
- 对教师 logits 进行居中；
- 使用较低教师温度进行锐化；
- 多裁剪训练。

论文的消融实验显示：居中与锐化配合动量教师使用时，是防止崩溃的关键机制。不能只用 EMA 与停止梯度来完整解释其稳定性。

### 什么是模型崩溃？

模型崩溃是指自监督模型找到了一条没有意义的捷径：无论输入什么图像，它都输出几乎相同的表示或概率分布。

例如：

```text
猫图像 → [0.5, 0.5, 0.5]
狗图像 → [0.5, 0.5, 0.5]
汽车图像 → [0.5, 0.5, 0.5]
```

虽然输入不同，它们的表示几乎没有可区分的信息。因此，这些特征无法有效用于分类、检索或分割等下游任务。

当学习目标只要求同一张图像的两个增强视图输出相似结果时，就可能出现这个问题。模型只要对所有图像都输出同一个常数，就能完美满足该规则：

```text
图像 A，视图 1 → X
图像 A，视图 2 → X  ✓

图像 B，视图 1 → X
图像 B，视图 2 → X  ✓
```

即使模型没有学到任何有用信息，训练损失仍可能很低。因此，崩溃被称为 **平凡解**。

对比式学习通过负样本对来防止这个情况：不同图像的表示会被推远，因此所有图像都输出相同结果会受到惩罚。DINO 不使用明确的负样本对；它通过动量教师、停止梯度、居中、锐化及多裁剪训练的共同作用来防止崩溃。

### 监督式学习与自监督学习

在监督式学习中，每个输入都配有外部提供的目标，例如图像类别或翻译后的句子。DINO 的预训练不提供语义类别标签；其目标是教师模型从同一张图像另一个视图产生的分布。

### 动机与涌现特性

原始 DINO 工作探讨：自监督预训练能否令 Vision Transformer 学到比一般图像级监督训练更丰富的视觉表示。

主要观察包括：

1. 自监督 ViT 最后一层 `[CLS]` 的自注意力图，常会对齐显著物体及其边界，即使训练时没有使用分割标注。
2. 冻结的 DINO 特征配合简单的加权 k 最近邻分类器已经表现良好。ViT-S/8 在没有微调、没有学习式线性分类器、也没有测试时数据增强的情况下，于 ImageNet 获得 **78.3% top-1 准确率**。

![DINO 注意力图显示的物体区域](/img/cv_img/DINOimg/image-1.png)

> 注意力图可以显示类似物体的区域，但不代表 DINO 直接完成了语义分割或为物体赋予类别名称。仍需要下游方法把特征或注意力转换成指定任务的预测。

## 核心 DINO 训练方法

### 教师—学生自蒸馏

![DINO 教师—学生架构](/img/cv_img/DINOimg/image-1.png)

两个网络使用相同架构，但参数不同：

1. 为一张图像产生多个经数据增强的视图。
2. 将所有视图送入学生模型，但只将两个全局视图送入教师模型。
3. 以温度缩放 softmax，将两个网络的 logits 转成概率分布。
4. 对教师 logits 进行居中及锐化，并停止教师输出的梯度。
5. 最小化教师模型对某一视图的分布，与学生模型对另一视图的分布之间的交叉熵；不匹配完全相同的视图。
6. 以梯度下降更新学生模型。
7. 以学生模型参数的 EMA 更新教师模型。

对教师视图 `(x)` 与不同的学生视图 `(x')`，损失包含：

$$
H\left(P_t(x), P_s(x')\right).
$$

教师目标是 **软伪标签**，并不是一般有标注资料意义下的真实标签。

### 骨干网络与投影头

网络可以写成：

$$
g = h \circ f,
$$

其中 `(f)` 是骨干网络，`(h)` 是 DINO 投影头。对 ViT 而言，投影头会套用在最终 `[CLS]` token 上。在常见设定中，投影头会将骨干表示映射到高维输出空间，通常为 `(K=65,536)` 维，然后才进行温度 softmax 及交叉熵计算。

这个输出不应被理解为 65,536 个语义类别。它是一个供自蒸馏目标使用的学习式投影空间；下游任务一般使用骨干网络的特征，而不是投影头的概率。

### 多裁剪输入

![DINO 多裁剪输入](/img/cv_img/DINOimg/image-2.png)

标准设定会产生：

- 两个 `224 × 224` 全局裁剪，同时送入学生与教师；
- 多个 `96 × 96` 局部裁剪，只送入学生。

这会鼓励 **局部对全局的对应关系**：学生模型必须让局部裁剪的结果，与教师模型看到的较完整全局视图一致。

### 动量教师（EMA）

教师模型由学生模型初始化，并以下式更新：

$$
\theta_t \leftarrow m\theta_t + (1-m)\theta_s,
$$

其中动量 `(m)` 在训练期间依 cosine schedule 从约 `0.996` 逐步趋近 `1.0`。

因此，教师模型可视为近期学生状态的平滑集成，提供较稳定的目标；教师模型不接收梯度更新。

### 居中与锐化

教师概率计算如下：

$$
P_t(x) = \operatorname{softmax}\left(\frac{g_t(x)-c}{\tau_t}\right),
$$

其中 `(c)` 是从教师 logits 以 EMA 更新得到的中心值，`(\tau_t)` 是教师温度。

- **居中（Centering）** 可避免少数输出维度在整个 batch 中持续主导，但单独使用会倾向产生均匀分布。
- **锐化（Sharpening）** 使用较低温度来降低输出熵，但单独使用可能使输出过度集中而崩溃。
- **两者结合** 可平衡这两种失败模式。

![DINO 崩溃消融实验](/img/cv_img/DINOimg/image-3.png)

熵本身并非通用的崩溃侦测器。在这个特定分析中，极高熵与均匀输出相关，而极低熵可能代表输出过度集中。右图使用教师与学生输出之间的 KL divergence；若它迅速降至零，可能表示两个网络都收敛至相同的平凡输出。

## DINOv2

DINOv2 将这个方法扩展为通用视觉特征提取器。其训练配方结合了图像级 DINO 自蒸馏、patch 级 iBOT 遮罩图像建模、KoLeo 正则化、策展数据集、训练稳定化方法及模型蒸馏。

![DINOv2 训练架构](/img/cv_img/DINOimg/image-4.png)

### 训练目标

1. **DINO loss：** 对齐学生与教师在不同视图上的 `[CLS]` 输出。
2. **iBOT loss：** 遮罩部分学生模型的 patch token，并要求其输出匹配教师模型对应未遮罩 patch token 的分布。它预测的是教师特征／分布，而不是 RGB 像素。
3. **KoLeo regularization：** 通过惩罚 batch 内过小的最近邻距离，鼓励嵌入向量分散。相比「让所有向量均匀分布」，它更适合被理解为特征扩散或熵正则化。

![DINOv2 损失函数](/img/cv_img/DINOimg/image-5.png)

DINOv2 也加入四个 **register tokens**，以减少 patch token 特征图中的高范数伪影。

### 高分辨率适应

在预训练接近结束时，DINOv2 将输入分辨率从 `224 × 224` 提升到 `518 × 518`，而不是 `416 × 416`。这段短暂的高分辨率训练，比从一开始全程以高分辨率训练更省成本，同时能改善像素级任务。

![DINOv2 分辨率比较](/img/cv_img/DINOimg/image-6.png)

### 模型扩展

- DINO v1 的实验包括 ViT-S 与 ViT-B；ViT-B 的骨干网络约有 **85–86M 参数**。
- DINOv2 最大的教师模型是 ViT-g/14，约有 **1.1B 参数**。
- 较小的 ViT-S/14、ViT-B/14 及 ViT-L/14 均由大型教师模型蒸馏而来。

### LVD-142M 资料策展

DINOv2 的流程从约 **1.2B 张未策展图像** 开始，最后产生约 **142M 张图像** 的 LVD-142M 策展数据集。

简化流程如下：

1. 从多个既有数据集建立一个策展种子集，并准备未策展的网络图像池。
2. 使用预训练的自监督 ViT-H/16，为两个数据池计算嵌入。
3. 对未策展图像池进行去重。
4. 以策展种子集作为查询，从未策展图像池中进行最近邻检索。
5. 对检索结果进行取样，形成在视觉分布上受策展来源引导的多样化数据集。

![LVD-142M 资料策展流程](/img/cv_img/DINOimg/image-7.png)

这是 **以检索为基础的视觉资料策展**，而不是一般的监督式分类。策展种子集定义了应被涵盖的视觉特征空间区域。

### 蒸馏较小模型

训练完 ViT-g/14 后，DINOv2 会把其表示蒸馏到较小的模型，让较轻量的骨干网络也能受益于大型教师模型较强的特征。

![DINOv2 蒸馏结果](/img/cv_img/DINOimg/image-8.png)

## DINOv3

DINOv3 进一步扩展自监督视觉预训练的规模，并处理长时间训练时稠密 patch 特征退化的问题。

### 规模

- 最大的 ViT 教师模型约有 **6.7B 参数**，通常四舍五入为 7B。
- 主要策展数据集 **LVD-1689M** 包含约 **1.689B 张图像**。
- 论文描述了来自更大原始数据池的训练。除非来源明确支持，否则不应写成所有原始图像均来自 Instagram。

![DINOv2 与 DINOv3 模型比较](/img/cv_img/DINOimg/image-9.png)

### 稠密特征退化

在延长的 DINO 类训练中，图像级表现可能持续提升，但 patch 特征的空间一致性可能变差，从而损害分割与深度估计等稠密任务。DINOv3 引入 **Gram anchoring** 来保留 patch 特征之间有用的关系。

![DINOv3 稠密特征退化](/img/cv_img/DINOimg/image-10.png)

![DINOv3 patch 相似度演变](/img/cv_img/DINOimg/image-11.png)

### Gram anchoring

Gram anchoring 使用一个冻结的较早期模型作为参考。它比较目前学生模型的 patch 特征之间的成对相似度，与参考模型中对应特征之间的相似度。

若 `(X_S)` 与 `(X_R)` 分别是学生及参考模型的归一化 patch 特征矩阵，则其简化形式为：

$$
\mathcal{L}_{\text{Gram}}
=
\left\|X_SX_S^\top-X_RX_R^\top\right\|_F^2.
$$

其中 `(X_SX_S^\top)` 与 `(X_RX_R^\top)` 是 **Gram matrices**；`(X_S)` 与 `(X_R)` 本身则是特征矩阵，不是 Gram matrix。此外，锚点是冻结的参考模型，而不是当前的 EMA 教师模型。

参考阶段的目标可概括为：

$$
\mathcal{L}_{\text{Ref}}
=
w_D\mathcal{L}_{\text{DINO}}
+\mathcal{L}_{\text{iBOT}}
+w_{DK}\mathcal{L}_{\text{DKoLeo}}
+w_G\mathcal{L}_{\text{Gram}}.
$$

Gram anchoring 是在较后期的训练阶段套用，而不是在整个基础预训练期间持续使用。

### 高分辨率 Gram anchoring

在高分辨率适应中，参考模型会处理高分辨率视图；其 patch 特征会先在空间上进行池化或下采样，以对齐学生模型较低分辨率的 token 网格，再计算 Gram loss。这提供了更强的空间参考，而不需要从一开始就以高分辨率训练整个模型。

![DINOv3 Gram anchoring 结果](/img/cv_img/DINOimg/image-12.png)

## 版本摘要

| 版本 | 核心概念 | 重要新增项目 | 最大 ViT 约略规模 |
| --- | --- | --- | --- |
| DINO v1 | 非对比式教师—学生自蒸馏 | EMA 教师、居中、锐化、多裁剪 | 主 ViT 实验中的 ViT-B，85–86M |
| DINOv2 | 大规模通用视觉特征 | iBOT、KoLeo、register tokens、LVD-142M、蒸馏、高分辨率适应 | ViT-g/14，约 1.1B |
| DINOv3 | 扩展规模并保留稠密特征 | LVD-1689M、约 7B ViT、Gram anchoring、高分辨率 anchoring | ViT-7B，约 6.7B |
