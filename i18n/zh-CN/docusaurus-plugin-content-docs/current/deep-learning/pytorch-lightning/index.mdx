# PyTorch Lightning 教程

PyTorch Lightning 是一个轻量级的 PyTorch 包装器，它抽象了繁琐的工程样板代码，同时保留了对研究逻辑的完全控制。它标准化了训练循环，只需更改一行配置即可启用分布式训练，并与现代 MLOps 工具无缝集成。

本节涵盖了 Lightning 的核心理念、心智模型和核心组件。学完之后，您将了解 Lightning 如何组织您的 PyTorch 代码，并准备好以最少的样板代码构建、训练和扩展模型。

## 预备知识

本教程假定您熟悉原生的 PyTorch：

- 张量 (Tensors)、设备 (devices) 和自动求导 (autograd)
- `torch.nn.Module` 和模型构建
- `Dataset`、`DataLoader` 和数据管道
- 优化器、学习率调度器和损失函数
- 基本的训练循环实现

如果您需要复习这些基础知识，请先从 [PyTorch 教程](../pytorch-tutorial/) 开始。
